# 颜色搭配参考

> 用于立绘提示词中的服装、鞋靴、首饰、配饰整体配色设计。

## 1. 色彩三要素

- **色相（Hue）**：颜色的类别，如红、蓝、黄。
- **明度（Value）**：颜色的深浅/明暗，如深蓝、浅蓝。
- **纯度/饱和度（Saturation）**：颜色的鲜艳程度，如灰蓝、亮蓝。

搭配不能只看“颜色不同”，还要看明度与纯度的关系。

## 2. 常见配色方案

| 方案 | 原理 | 例子 |
|---|---|---|
| 单色搭配 Monochromatic | 同色相，靠明度/饱和度变化 | 深灰+浅灰+白 |
| 类似色 Analogous | 色相环相邻色，和谐统一 | 蓝+蓝绿+绿 |
| 互补色 Complementary | 色相环对面色，对比强烈 | 蓝+橙、红+绿 |
| 分裂互补 Split-complementary | 主色 + 对面色两侧的颜色 | 蓝 + 橙黄 + 橙红 |
| 三角色 Triadic | 色相环三等分，活泼平衡 | 红+黄+蓝 |
| 四色/矩形 Tetradic | 两对互补色，丰富但难控制 | 红+绿+蓝+橙 |
| 中性色 Neutral | 黑白灰棕米色，稳定基底 | 白+灰+黑+棕 |

## 3. 服装搭配常用规则

### 60-30-10 法则

- **60% 主色**：外套、裙子、大面积服装
- **30% 辅色**：内搭、下装、开衫、丝袜、鞋的一部分
- **10% 点缀色**：腰带、首饰、小配件、鞋的部分装饰

例子：

- 60%：象牙白连衣裙
- 30%：浅灰色开衫、深灰色丝袜
- 10%：黑色皮带、浅棕色靴子、银色手链

### 主色 / 辅色 / 点缀色

- 主色：控制整体印象。
- 辅色：制造层次和体积感。
- 点缀色：制造焦点，不能大面积使用。

## 4. 为什么禁止“白裙+白丝袜+白靴+白/银手链”

从色彩理论看，这是单色搭配失败：

- 色相全部相同（白/银）
- 明度几乎没有差异
- 饱和度几乎为零
- 没有辅色，也没有真正的点缀色
- 60-30-10 被破坏：100% 都是同一种颜色家族

即使材质有区别，画面仍会显得单调、扁平、像未完成底色，缺少视觉重心。

## 5. 应用示例

以“象牙白连衣裙”为例：

```text
象牙白连衣裙 + 浅灰开衫 + 黑色细腰带 + 深灰丝袜 + 浅棕麂皮及踝靴 + 银色手链
```

- 主色：象牙白
- 辅色：浅灰、深灰、黑
- 点缀色：浅棕、银
- 符合 60-30-10
- 有明度层次：白/浅灰/深灰/黑
- 有冷暖平衡：冷白 + 暖棕
- 有材质对比：雪纺 / 针织 / 皮革

## 6. 色彩与场景氛围 / 情绪 / 戏剧张力

颜色不只是好看，还要表达“这场戏是什么感觉”。

### 色彩情绪参考

| 颜色 | 常见情绪/氛围 | 适用场景示例 |
|---|---|---|
| 红 | 欲望、危险、血、暴力、羞耻、愤怒 | 性张力、冲突、施暴、血管暴露 |
| 黑 | 控制、压迫、神秘、死亡、屈服 | 支配、威胁、夜晚、隐秘 |
| 白/象牙白 | 纯洁、虚假纯洁、冷感、空白、暴露 | 妻子面、天使感、病弱、被观看 |
| 灰 | 压抑、疲惫、暧昧、中间态 | 过渡、秘密、阴沉、不安 |
| 蓝 | 冷静、距离、忧郁、理性 | 工作、控制、疏离、夜晚 |
| 紫 | 暧昧、异常、神秘、堕落 | 禁忌、欲望、幻觉 |
| 绿 | 不安、病态、嫉妒、自然 | 身体异常、嫉妒、旧物 |
| 棕/大地色 | 陈旧、卑微、日常、真实 | 旧楼、底层、朴素 |

### 明度与纯度表达情绪

- 高明度 / 低饱和：脆弱、病态、苍白、虚脱、洁净。
- 低明度 / 高饱和：强烈、压迫、欲望、危险。
- 低明度 / 低饱和：压抑、疲惫、绝望、阴暗。
- 高对比：冲突、张力、戏剧化。
- 低对比：日常、控制、平稳、隐藏。

### 场景氛围与服装颜色配合

- 控制面：深蓝制服、黑色腰带、银色首饰、整齐利落。
- 妻子面/日常：粉色、米白、浅灰、柔软材质。
- 失控/性张力：皮肤裸露、黑色/红色点缀、汗湿、衣物半脱。
- 病弱/创伤：苍白、灰白、湿透、低饱和、衣物宽大。
- 雨夜：冷灰、深蓝、湿透的白、泥污。
- 旧楼/底层：灰、棕、旧棉布、暗光。

### 戏剧张力原则

- 颜色对比强弱 = 冲突强弱。
- 大面积冷色 + 小面积暖色 = 压抑中的欲望。
- 大面积白色 + 小面积红/黑 = 纯洁表面下的危险。
- 湿透、脏污、破损 = 失去控制、秘密暴露、事后自厌。
- 配饰颜色可作“剧情暗示”：银手链代表身份/婚姻，红色马镫代表性控制。

## 7. 场景光线与氛围颜色设定

画面整体不是“人物颜色 + 背景颜色”，而是光线、氛围和人物服装共同构成一个颜色系统。

### 光线类型与情绪

| 光线 | 情绪/氛围 | 适用场景 |
|---|---|---|
| 暖黄灯 | 家庭、亲密、温暖、危险、压抑 | 家居、卧室、旧楼室内 |
| 冷白灯 | 控制、工作、医院、审问、暴露 | 家电卖场、画室、宾馆、警局 |
| 雨夜冷光 | 脆弱、秘密、逃亡、失控 | 雨夜、旧小学、废弃楼 |
| 霓虹/红蓝光 | 欲望、异常、堕落、直播 | 夜店、直播、色情空间 |
| 窗边自然光 | 日常、虚假平静、被观看 | 晨间、客厅、画室 |
| 强逆光/剪影 | 威胁、压迫、神秘 | 门口、窗帘后、危险人物出场 |
| 低照度暗光 | 隐秘、紧张、情欲、恐惧 | 偷窥、性场景、暗房 |

### 光色温度

- **暖光**（橙黄）：亲密、家庭、欲望、危险、暧昧。
- **冷光**（蓝白）：冷静、控制、病态、恐惧、疏离。
- **混合光**（暖+冷）：冲突、挣扎、秘密、戏剧张力。

### 场景氛围配色参考

| 场景 | 氛围色彩 |
|---|---|
| 日常家中 | 暖黄、米白、浅灰、木色 |
| 家电卖场 | 亮白、冷蓝、金属银 |
| 旧楼 | 灰、棕、旧白、暗黄 |
| 画室 | 冷白、深色木、颜料色点 |
| 宾馆/旅馆 | 冷白、深红、暗棕 |
| 雨夜 | 蓝灰、深蓝、泥棕、冷白灯 |
| 直播/混乱房间 | 灰暗、塑料色、屏幕蓝光、冷白光 |
| 医院/病弱 | 苍白、浅蓝、白、灰绿 |
| 性张力场景 | 低照度、皮肤色、红/黑点缀、汗湿反光 |

### 人物服装颜色与场景光线的关系

- 服装主色应尽量从场景氛围色中延伸，形成统一感。
- 用辅色或点缀色从场景中跳出来，把视线引向主人物。
- 不要让人物颜色与场景完全割裂，例如：
  - 暖黄家居场景里穿大面积冷蓝荧光服，除非故意制造冲突。
  - 冷白医院场景里穿大面积正红，除非是剧情焦点。
- 衣物颜色在光线下的变化也要写清：
  - 湿透后颜色变深/半透明
  - 灯光下缎面反光、皮革高光、丝袜珠光
  - 阴影中颜色变暗、失去饱和度

### 灯光写法要求

- 写清：光源在哪里、什么颜色、什么方向、造成什么阴影。
- 写清：人物身上哪些地方被照亮、哪些地方在阴影里。
- 写清：背景的主要色块和明暗分布。
- 不要只写“灯光昏暗”；要写“一盏暖黄色落地灯从人物左侧打来，照亮她的脸和肩膀，右侧落在阴影里，墙面是暗米色，地面有长影”。

- [ ] 是否有明度层次？
- [ ] 是否有冷暖平衡？
- [ ] 是否有材质对比？
- [ ] 点缀色是否只占小面积？
- [ ] 颜色是否符合当前场景氛围？
- [ ] 颜色是否表达当前情绪和戏剧张力？
- [ ] 配饰颜色是否承载剧情暗示？
- [ ] 是否写清了光源位置、颜色、方向和阴影？
- [ ] 人物服装颜色是否与场景光线/氛围形成统一或有意冲突？
