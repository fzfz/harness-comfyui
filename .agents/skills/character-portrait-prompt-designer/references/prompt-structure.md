# 立绘提示词结构与模板

> 场景、事件、开场立绘提示词均使用同一套结构。

## 文生图可理解性

- 只写画面内可见信息。
- 不要写“主人物”“女主”“她叫某某”等抽象称呼，也不要写任何具体人物名/昵称/关系称谓（如“林茜”“杨桃子”“王授军”“黑哥”“丈夫”）；所有角色用“年龄/年龄段 + 性别 + 体型/穿着/外貌特征”指代。
- 不要写“这是角色成为某花名之前”“此时尚未驯化”等剧情说明；把阶段转换成可见状态，如“没有项圈/贞操带，穿着素净的学生装，神情青涩”。
- 不要写“某山庄”“某村”“某温泉馆”等专名；写具体环境，如“近郊高档别墅：铁门、石墙、车道、草坪、玻璃门、石板台阶”。
- 心理动机、过去/未来、旁白、人物关系称谓等不可画信息，若需要传达，转换为表情、动作、服装、伤痕、配饰和环境细节。
- 不要写“没有项圈”“没有其他人”这类纯否定/缺失信息；不存在的东西直接省略，需要素净时写“脖颈光洁”“衣着素净”。

## 独立提示词通用骨架

> 整个 prompt 最终是一段连贯的画面说明，不要用 Markdown 小标题/分节/标签块拆开。

```text
{人物名可选，但必须紧跟完整外观描述}，{性别}，{年龄}，{身高体型}，{骨架/气质}。她有{脸型}，{眉型}，{眼型}，{睫毛}，{鼻梁}，{嘴唇/牙齿}；皮肤{肤质}，{脖颈/锁骨}。{发型描述}，发质{发质}。

她穿{服装：上衣/下装/鞋靴}，{配饰}。衣物勾勒出{胸/腰/臀/腿/脚踝}。

她{动作与姿势}，表情{眼睛、嘴唇、脸红、汗/泪}，情绪{性格侧面}。背景是{地点、光线、氛围}，动作定格在“{关键瞬间}”的瞬间。
```

上面的“她有{脸型}……{发型描述}”就是人物辨识度，必须自然写在正文里，不能抽出来单独写成“人物辨识度：……”的标签块。

除非用户明确要求，否则不要添加“全身立绘、电影感光影、精细面容、8k”等画风/画质词；提示词只负责画面内容。

## 非裸露场景示例骨架

```text
她穿{具体服装}，站在{地点}，{动作}。表情{情绪}，整体气质{性格侧面}。背景{光线}。动作定格在“{瞬间}”的瞬间。
```

## 整体造型设计

每个角色在具体场景中必须按整体造型设计：

- 服装：内搭/外搭/下装/丝袜/鞋靴/腰带/外搭/当前状态
- 色彩：主色、辅色、点缀色；禁止“白裙+白丝袜+白靴+银/白首饰”全身同色；至少 2-3 个明确不同色相；即使原文只写白色，也要调整丝袜/靴子/外搭颜色，例如白裙+灰色开衫+黑色腰带+深灰丝袜+棕色短靴；完整理论见 `color-theory.md`；同时颜色要符合场景氛围、情绪和戏剧张力
- 材质：至少两种材质层次，避免全软或全硬
- 鞋靴：鞋型、筒高、跟型/跟高、材质、颜色、装饰
- 首饰：金属色、款式、大小、位置、光泽
- 发型：造型类型、长度、发质、刘海/发缝、当前状态
- 发饰：大小、颜色、材质、位置
- 小配件：手机、眼镜、包、伞、围裙、丝袜等只要出现就要有可见形态

## 场景环境整体构建

避免只写抽象地点词，必须把场景当作整体描述：

- 空间类型：室内/室外、房间/街道/车内/雨地
- 时间与天气/光线：白天/夜晚/雨天/灯光类型/明暗方向
- 地面与材质：木地板、水泥地、瓷砖、地毯、泥地、柏油路等
- 墙面/门窗：墙皮状态、颜色、窗户/门的位置和状态
- 家具/道具/周围物体：床、桌、椅、柜、画架、旧木箱、手机、轮椅、吊具、花瓶、纸箱等
- 物体摆放关系：主人物/配角/家具之间的相对位置
- 环境细节：散落衣物、纸张、花瓣、液体、灰尘、雨水、反光等
- 光线与氛围颜色：光源位置、颜色、方向、阴影、环境主色调、人物受光/阴影位置
- 氛围必须从剧情/人物关系/情绪/张力推导，不能根据地点套“压抑/阴暗”等模板词

依据原文/证据：

- 原文出现“木地板”时写布满灰尘和旧木屑的老旧木地板，板缝里积着灰
- 原文出现“泥地”时写泥泞的深色泥地，地面有积水反光和湿泥
- 原文未明确材质时使用有原文线索支持的保守描述，并注明“设计补充”，不得与原文冲突
- 雨夜不能只写“雨夜”，要写雨幕、积水反光、湿透衣物、路灯、周围建筑/树/车等

## 场景建构流程

1. 先写场景描述：地点、时间、光线、环境、地面、关键物体。
2. 从证据包/人物文件/事件/开场中找该场景已有细节。
3. 证据有的直接用，证据不足再按剧情补充。
4. 补充必须合理且不冲突，可标注“设计补充”。

## 配角一致性

- 配角外观/性格/情绪/衣物/动作必须来自该配角自己的人设文件、调色盘、证据包、事件和开场。
- 资料不足时按剧情关系合理补充。
- 配角可以简略，但不能与人设冲突。

## 禁止模糊词

提示词中不得出现“或、也许、可能、或许、或者”等可选项/推测词。每个画面元素必须是唯一确定的。

- 不写：粉色上衣或白色上衣
- 写：粉色上衣
- 不写：可能站在门口
- 写：站在门口

## 多人空间关系（自然语言描述）

画面中有多人时，必须用自然语言写清三维关系，禁止出现“x轴/y轴/z轴”等术语：

- 左右：谁在谁的左侧/右侧
- 上下：谁在谁的上方/下方、谁高谁低
- 前后：谁在谁的前方/后方、距离多远、朝向哪里

示例：

```text
主人物位于画面中心偏左，距离镜头约2米；男配角位于主人物右侧后方约1米，身高比主人物矮半个头，面朝主人物。
```

## 同框人物写法

当画面中有其他人物时，在主人物完整描述之外追加：

```text
画面中还有{明确年龄或年龄段}的{性别}，{体型/穿着}，位于{站位}，正在进行{动作}，表情{表情}。主人物位于{中心/前景/焦点}，细节最完整；其他人物位于{后方/边缘/虚化}，只保留必要动作和轮廓。
```

## 裸露/性交场景必须额外写清

- 体位：站立后入/女上骑乘/跪趴后入/吊具固定/面对面等。
- 动作：插入、抽插、起落、抓握、撕扯、口交、射精、液体流动。
- 裸露程度：哪些部位裸露、哪些衣服残留、交合处是否可见。
- 身体反应：脸红、出汗、腿软、颤抖、乳房晃动、液体痕迹。
- 表情：忍耐、羞耻、兴奋、反抗、失控、冷静。
- 同框裸露配角：如果画面中有其他裸露/参与性交的角色，也要写清其裸露状态和性器外观，依据证据包/原文；不能只描写主人物。

## 人物辨识度融入正文规则

- 先在 `source/media/` 下建立该人物的外观基准文档（如 `{character_name}_外观与立绘提示词.md`），集中描述全书通用外观与阶段状态。
- 不要单独输出“人物辨识度：……”标签块；核心外观必须自然写进整段画面描述。
- 每张提示词都从外观基准文档中选取本阶段已成立的特征，结合当前场景剧情、服装、动作、情绪改写成新的正常描述；禁止整段照抄外观基准。
- 所有提示词共用同一组核心视觉锚点：脸型、眉眼/瞳色、鼻梁、唇形、发色/发型、肤色、身高体型。
- 阶段性的配饰/身体状态（项圈、贞操带、剃毛、裸露程度、身材丰满度）只在该阶段已成立时写入正文，未来物件不得提前出现。
- 视觉锚点来自人物设定 + 证据包原文；如果原文缺失，选择一种稳定设计并全项目复用。
- 不要在一份文件里写“黑长发”，另一份写“棕色长发”。

## 外观基准文档分章节模板

```markdown
## 章节/阶段：{阶段名}（{章节范围或事件范围}）

- 核心外观：{不可变的脸型/眼型/发色/发型/肤色/身高体型}
- 已成立服装/配饰：{例如素净学生装，无项圈}
- 禁止出现的未来特征：{例如不画贞操带、狗牌、剃毛}
- 身体状态：{例如自然阴毛、身材清瘦、无伤痕}
- 性格/气质与表情特征：{例如眼神拘谨、爱低头偷看、紧张时攥紧衣角、羞耻时脸红到耳根}
- 参考事件/场景：{事件编号或场景名}
```

每个阶段都按这个结构写，生成 prompt 时先查对应阶段，再从中选取特征融入画面。
