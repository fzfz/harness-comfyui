# 人物设计材料选择

## 1. 发现本次材料

1. 先核对用户提供的文件和目录，再列出项目内的材料路径。
2. 按内容用途识别小说原文、人物设定、性格调色盘、三面性、二次解释、证据包、事件和开场。文件所在目录与命名只用于定位。
3. 用户指定多类材料时，逐类定位目标人物与当前场景的内容。
4. 列表过长时，按已发现的材料目录分别列出。不得用截断后的全项目列表判断材料缺失。
5. 用户要求重新设计时，以本次指定的材料建立依据。用户指定复用既有外观基准或画面时，再读取对应产物。

## 2. 读取当前画面需要的内容

1. 用户指定小说原文时，必须实际读取目标章节或人物与场景对应的原文段落。长篇原文先检索人物名、别名和场景线索，再读取命中位置的上下文。
2. 建立外观基准时，读取人物设定与外貌证据。设计表情、动作和气质时，读取性格调色盘、三面性或二次解释中对应的内容。
3. 使用证据包时，先读取清单，再按人物、事件、物件和章节定位证据条目。核对条目的原文位置、成立阶段与不确定性。
4. 本次包含事件或开场立绘时，只读取目标人物直接出场且需要交付画面的事件或开场。
5. 文件输出截断时，读取工具返回的完整文件或分段补读。所需段落读取完整后，再据此设计画面。

## 3. 定位证据引用的原文

1. 证据中的原文路径不可用时，先查看用户指定的原文路径，再查看已发现的小说材料目录。
2. 历史文件名与现有文件名不同时，用证据摘录、章节名或人物与事件线索检索现有原文。核对命中段落后，记录实际路径与位置。
3. 完成用户路径核对、材料目录列举和内容检索后，仍找不到所需原文时，报告已经核对的范围与缺少的材料。只询问影响当前设计的缺失项。

## 4. 记录依据与设计补充

1. 在外观基准或对应画面文件中列出实际采用的材料路径、章节或证据条目标识。
2. 区分原文明示、人物资料设定、叙述者推测与设计补充。记录原文只支持疑似身份或远程事件等适用范围。
3. 用户明确要求改编时，保留改编要求。其余资料冲突先按人物与场景的剧情阶段核对，再回到原文确认。
4. 影响人物身份或画面事件的冲突仍无法消解时，列出冲突来源并请用户决定。用户已授权的构图、光线和造型选择由执行者决定。
5. 原文与人物资料未提供的细节，按 `SKILL.md`“场景建构方法：证据优先，补充有据”补充。
