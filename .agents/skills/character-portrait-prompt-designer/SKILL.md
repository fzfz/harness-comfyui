# Character Portrait Prompt Designer

## 查询历史 Generation Run

用户要求读取、核对或复用一个或多个 `run_id` 对应的生成参数或 Actual Workflow 时，Skill 执行者必须先完整读取 `references/generation-cli.md`，再按该文件调用历史 Generation Run 查询命令。该查询不要求用户提供 `book_dir`、`character_name` 或人物资料。

Skill 执行者必须按查询结果的 `runs[]` 顺序分别报告每个 `run_id`。一个 `run_id` 返回错误项时，Skill 执行者继续处理其余结果。用户只要求查询历史 Generation Run 时，Skill 执行者返回查询结果后结束本次执行；用户还要求设计立绘提示词时，Skill 执行者完成查询后继续执行本文件的设计流程。

为指定书籍/角色卡项目中的一个人物生成两套东西：

1. **外观基准文档**：一个独立的、全书通用的详细外观描述文件（如 `{character_name}_外观与立绘提示词.md`），定义该人物整本书稳定不变的视觉核心，并且按剧情章节/阶段分节写入外观变化，方便生成每张提示词时快速选用对应阶段特征。
2. **独立立绘提示词**：为每个有关该人物的场景/事件生成一份自包含、可直接用于生图的提示词。

核心原则：**生图时只认视觉特征，不认名字。** 每个提示词都必须独立完整，不能依赖“人物名”或“另见人物设定”来补全形象。

最终交付给生图模型的提示词应写成一段连贯的完整画面说明，不要用 Markdown 小标题、分节或列表把要素拆开；下面列出的要素都要融入同一段文字中。

**生成每张画面提示词前，必须先建立/读取该人物的外观基准文档；然后根据当前场景所属剧情阶段，从外观基准中选取本阶段已成立的特征，自然融入这段画面描述。禁止把外观基准整段照抄进每个提示词。**

---

## 文生图可理解性：只写画面内可见信息

最终 prompt 不是小说梗概或人物小传。文生图模型只能画“看得见的东西”，因此：

- **人物称呼**：不要写“主人物”“女主”“她叫某某”等抽象/命名，也不要写任何具体人物名/昵称/关系称谓（如“林茜”“杨桃子”“王授军”“黑哥”“丈夫”）。所有角色必须用“年龄/年龄段 + 性别 + 体型/穿着/外貌特征”来指代，例如“一个三十岁左右的中国女性”“一个四十多岁、身高不足一米六、半秃、皮肤皱缩的瘦小男人”。
- **剧情/阶段说明**：不要写“这是角色成为某花名之前”“此时尚未驯化”等。如果阶段有视觉后果，直接写成可见状态，例如“没有项圈/贞操带，穿着素净的学生装，皮肤无痕，神情青涩”。
- **地点/专名**：不要写“某山庄”“某村”“某温泉馆”等专名。要写具体视觉环境，例如“近郊高档别墅：铁门、石墙、车道、草坪、玻璃门、石板台阶”“乡村旧院：土墙、旧木门、泥地、昏暗门灯”。
- **其他不可画信息**：心理动机、过去/未来、旁白、人物关系称谓等，如果画面里看不见，就不要写；若需要传达，转换为表情、动作、服装、伤痕、配饰、环境细节。
- **否定/缺失信息**：不要写“没有项圈”“没有其他人”“没有伤疤”这类纯否定句。模型画的是画面中存在的东西；不存在的东西通常直接不写。如果确实需要排除误加，用正面可见描述代替，例如“脖颈光洁”“衣着素净”而不是“没有项圈”。

反例与正例：

| 反例（模型无法直接画） | 正例（模型可直接画） |
|---|---|
| 主人物第一次来到某山庄 | 一个成年女性角色站在近郊高档别墅的铁门外，铁门、石墙、车道、草坪、玻璃门、石板台阶清晰可见 |
| 这是角色成为“某花名”之前 | 她没有戴项圈，没有多余饰品，穿着素净的浅色衬衫和过膝半裙，神情青涩 |
| 某山庄 | 近郊高档别墅：铁门、石墙、修剪齐整的草坪、玻璃门、石板台阶、低矮灌木 |

## 输入

- `book_dir`：书籍/角色卡项目根目录，通常包含 `source/worldbook/` 和 `抽取证据/`。
- `character_name`：目标人物名，例如 `某人物名`。

## 读取哪些文件

**严格文件白名单：本技能只允许读取下面列出的文件类型，禁止读取、参考、引用或把未列出的文件作为设计依据。**

1. 人物基础文件，在 `book_dir` 下递归查找：
   - `{character_name}_人物设定.md`
   - `{character_name}_性格调色盘.md`
   - `{character_name}_二次解释.md`
   - `{character_name}_三面性.md`
   - `{book_dir}/source/worldbook/characters/**/*.md`（含 `supporting/` 等子目录中的人物基础/调色盘/三面性/二次解释文件）
2. 证据包：
   - `{book_dir}/抽取证据/evidence_manifest.yaml`
   - `{book_dir}/抽取证据/packet_*.yaml`
   - 优先搜索与 `character_name` 有关的“身份与外观”“裸体与性器官证据”“场景摘要”“源文细节”。
3. 事件目录：
   - `{book_dir}/source/worldbook/events/事件_*.md`
   - `{book_dir}/source/worldbook/events/日常事件_*.md`
   - 只处理与 `character_name` 直接相关且存在可画画面的文件。
4. 开场目录（如果存在）：
   - `{book_dir}/source/greetings/*.md`
   - 每个开场 `.md` 单独生成一个开场立绘提示词。

**明确禁止作为输入/依据的目录与文件（包括但不限于）：**

- `立绘封面图/`
- `人物列表/`
- `调色盘/`（除非其中存在上面第 1 条允许的 `{character_name}_性格调色盘.md` 且该文件在 `book_dir` 下）
- `封面图/`
- `中间产物/`
- `dist/`
- `notes/`
- `validation/`
- 任何未被上面白名单明确列出的 `.png`、`.jpg`、`.md`、`.yaml`、`.json` 等文件

输出文档的“设计依据”中也只能列出上述白名单内的文件；不得把白名单外的路径或文件名（如 `立绘封面图/小丹_基础脸型.md`、`人物列表/xxx.md`、`调色盘/xxx/调色盘.md`）写成参考来源。

## 分析：从资料中提取什么

- 从人物设定提取：年龄、身份、身高体型、发型、稳定穿着、固定配饰、声音气质；同时确认这些特征在时间线中的成立阶段。
- 从调色盘/三面性/二次解释提取：性格的不同视觉状态、身体反应、控制/失控时的表情与动作、羞耻与暴露规则。
- 从证据包提取：原文里明确写过的五官、皮肤、胸/腰/臀/腿/脚、鞋靴、发质、服饰、身体反应、性交姿势与裸露程度。
- 从事件提取：每个事件的具体场景、动作、体位、裸露程度、情绪状态、服装残留和背景；并判断该事件处于故事哪个阶段。
- 从开场提取：开场白对应的关键画面、人物状态、同框人物、情境氛围和镜头焦点；同样注意开场时哪些配饰/身体状态尚未成立。

如果原文没有给出某一项（例如脸型、眼型），可以基于已有气质做合理设计，但必须保持稳定，并在所有提示词中复用同一套设计。

## 场景建构方法：证据优先，补充有据

每个场景/事件/开场提示词都必须按以下顺序建构：

1. **先建场景描述**：先确定“画面发生在哪里、什么时间、什么光线、有哪些可见环境细节”。
2. **调研证据来源**：从人物设定、调色盘、二次解释、三面性、证据包、events、greetings 中找出该场景已有的明确信息。
3. **优先使用证据**：环境、地面、服装、动作、表情、同框人物等，凡是证据里写过的，直接采用。
4. **证据不足时合理补充**：只有在证据包/事件/开场资料不足时，才可以根据剧情逻辑、人物性格和前后文做补充；补充内容必须与已知信息一致，不能无理由瞎编。
5. **补充内容可标注**：如果某处细节是设计补充而非原文证据，可以在提示词中保留自然描述，但在工作记录/README 中说明“该处为合理补充”即可。

禁止行为：

- 不能读取、参考或在输出中引用“读取哪些文件”白名单之外的任何文件/目录（例如 `立绘封面图/`、`人物列表/`、`调色盘/`、`封面图/`、`中间产物/`、`dist/`、`notes/`、`validation/` 等）。
- 不能凭空编造与原文冲突的环境材质、服装、动作。
- 不能把“合理补充”伪装成“证据确认”。
- 不能因为该人物已有统一底模，就跳过具体场景的证据调研。

## 输出位置

在 `book_dir` 下写入：

```
source/media/
├── {character_name}_外观与立绘提示词.md          # 可选：总览/底模
├── {character_name}_场景立绘/
│   ├── README.md
│   └── {character_name}_场景NN_*.md
├── {character_name}_事件立绘/
│   ├── README.md
│   └── {character_name}_事件NN_*.md
└── {character_name}_开场立绘/
    ├── README.md
    └── {character_name}_开场NN_*.md
```

- 场景文件：按“日常/工作/特殊场景/裸露性交场景”分类。
- 事件文件：按 `events` 中与人物有关的事件逐个生成。
- 开场文件：按 `source/greetings/` 下每个 `.md` 逐个生成。
- 每个提示词一个文件：**不要把所有提示词堆在一个文件里**。

## 每个提示词必须包含

每个立绘提示词都必须是独立的、完整的、且以一段连贯画面说明呈现，至少包含：

1. **人物辨识度融入正文**：不写名字，也不单独输出“人物辨识度：……”这一段；把核心视觉锚点（脸型、眉眼、鼻梁、唇形、发色/发型、肤色、身高体型）自然写进整段画面描述，让不同提示词看到同一张脸。
2. **完整外观**：身高体型、脸型、眉眼、睫毛、鼻梁、嘴唇牙齿、皮肤、头发、上身、下身、脚/鞋。
3. **该阶段固定配饰/状态**：例如手链、戒指、项圈、贞操带；只写本场景剧情阶段已经出现的配饰，未出现的未来物件不能写进本张提示词。
4. **该场景服装**：具体到上衣、下装、鞋靴、是否裸露。
5. **表情情绪**：具体眼神、脸红、咬牙、流泪、喘息等。
6. **性格侧面**：控制、妻子、失控、反抗、脆弱等。
7. **动作姿势**：身体姿态、手脚位置、与他人互动。
8. **背景光线**：地点、光源、氛围。
9. **同框人物**：如果画面中有其他角色，也要写出他们的明确年龄/年龄段、性别、体型/穿着、动作、表情，并明确主次关系。
10. **禁止模糊词**：提示词中不得出现“或”“也许”“可能”“或许”“或者”等可选项/推测词；必须给出唯一确定的画面状态。
11. **多人空间关系**：如果画面中有多人，用自然语言写清左右、上下、前后、距离、朝向；不出现“x轴/y轴/z轴”术语。
12. **画风/画质不自动添加**：除非用户明确要求，否则不要在提示词末尾添加“全身立绘、电影感光影、精细面容、8k”等画风/画质词；提示词只负责画面内容。

## 人物辨识度融入正文（不单独输出固定句）

**不要**在提示词末尾单独追加“人物辨识度：……”这样的文字块。人物辨识度必须直接融入整段画面描述，让生图模型在阅读画面时自然获得这个人的稳定长相。

写法要求：

1. **先有外观基准文档**：在项目 `source/media/` 下先生成一份 `{character_name}_外观与立绘提示词.md`（或同名外观基准文档），把全书通用的人物外观核心、阶段状态、可复用底模都写清楚。
2. **每张提示词都从外观基准中选用本阶段特征**：核心锚点（性别、年龄段、身高体型、脸型、眉眼/睫毛、鼻梁、唇齿、皮肤、发色/发型、身型比例）要在正文中自然出现；但不要整段照抄，而是根据当前场景的剧情、光线、动作和服装，改写成符合该画面的正常描述。
3. **本阶段状态（只写当前场景已成立的）**：配饰、身体状态、裸露/毛发/疤痕/项圈/贞操带等，只写该场景所处剧情阶段已经出现的内容；尚未出现的未来物件不能写进这张提示词。
4. 不要使用“人物辨识度：”“核心锚点：”“本阶段状态：”“同框人物：”“动作与姿势：”这类标签式开头；应写成例如“她有着偏窄长鹅蛋脸，深棕色内双杏眼，自然黑色齐肩侧分短发……”这样的正常画面描述。
5. 如果某个阶段确实没有固定配饰，就不要写配饰；需要表现素净时用正面描述，如“脖颈光洁”“衣着素净”，不要写“没有项圈/贞操带/多余饰品”这类否定句。

一致性规则：

- 同一人物的所有提示词，核心外观描写必须保持一致：同样的脸型、同样的眼型/瞳色、同样的发色/发型、同样的鼻唇、同样的肤色和身型比例；但允许用不同句子、不同详略自然融入各自场景。
- 阶段变化只允许发生在服装、配饰、身体状态、裸露程度、身材丰满度、表情情绪等随剧情发展的部分。
- 判断阶段必须依据该场景对应的事件/开场/证据，不能把后期才出现的物件提前写到早期画面里。

## 性格与灵魂的视觉化

人物图片不能只有“脸+衣服”，还要有性格和情绪带来的“活人感”。外观基准文档必须包含一套性格/表情特征库，至少覆盖：

- **核心气质**：例如清冷、自卑、骄傲、依赖、倔强、麻木、羞耻、脆弱等；同一角色在不同阶段可以有气质变化，但要能看出是同一个人。
- **眼神特征**：同一双眼睛在不同阶段应有不同神色，例如早期拘谨观察、中期湿亮闪躲、后期麻木又依赖；瞳孔、眼睑、视线方向都要写具体。
- **表情微动作**：咬唇、垂眼、皱眉、脸红到耳根、泪在眼眶打转、嘴唇颤抖、手指攥紧衣角、肩颈紧绷、膝盖内扣等。
- **身体语言习惯**：低头偷看、跪坐时肩背僵硬、站立时双腿并拢、被命令时先停顿再动作、紧张时手指反复摩挲裙边等。
- **情绪-表情映射**：把“羞耻”“恐惧”“依恋”“争宠”“麻木”等抽象情绪翻译成可见的眉眼嘴角和身体姿态。

## 外观基准文档的分章节要求

外观基准文档不能只写一个笼统的“最终外貌”。它应该按剧情章节/阶段分节，至少包含：

- **章节/阶段名称与范围**：如“第1-3章：校园初见”“第4-9章：项圈驯化”“第10章后：狗场/温泉圈养”，或对应事件编号范围。
- **该阶段已成立的核心外观**：发型、脸型、眼型、肤色、身高体型等不可变项；身材丰满度若有变化也写清。
- **该阶段允许出现的服装/配饰**：如素净学生装、开裆裤、真空裙、项圈、贞操带、狗牌、兔女郎装、博士袍等。
- **该阶段禁止出现的未来特征**：例如早期不画项圈/贞操带/剃毛，中期不画狗牌/犬籍档案等后期物件。
- **该阶段的身体状态**：自然阴毛、剃净、胸臀曲线、伤痕、贞操带、裸露程度等。
- **性格/气质与表情特征**：该阶段的眼神、眉形状态、嘴角、脸红/泪/喘息、身体语言、姿态习惯等；这是让画面有“灵魂”的关键，不能只写外貌和衣服。
- **参考事件/场景**：列明哪些事件或场景使用这一阶段，方便生成提示词时直接查表。

## 整体造型设计（服装/鞋靴/首饰/发型/发饰/小配件）

每个角色在具体场景中必须按“整体造型”设计，不能只罗列单件衣服。

### 服装整体搭配
- 每套服装必须写清：内搭、外搭、下装、丝袜/裤袜、鞋靴、腰带/外搭/开衫、当前状态（整齐/湿透/半脱/撕开）。
- 不能只写“白裙+白靴”；要写出版型、长度、领口、袖型、材质、颜色、细节、穿着状态。
- 同一件常用服装必须在全项目保持统一规格，并在外观基准文档中建立“服装规格锚点”。

### 色彩搭配
- 每套造型必须有主色、辅色、点缀色，不能盲目同色堆叠。
- 禁止出现“白色裙子+白色丝袜+白色靴子+银色/白色首饰”这种全身同色系搭配。
- 整体造型中至少要有 2-3 个明确不同色相，例如：白/象牙白 + 灰 + 黑 + 棕 + 银。
- 即使原文只写了“白色裙子+白色靴子”，也要调整丝袜、靴子或外搭的颜色，不能把“白+白+白+银”直接当成可接受搭配。
- 例子：
  - 白色雪纺连衣裙 + 浅灰色针织开衫 + 黑色细皮带 + 深灰色丝袜 + 浅棕色麂皮及踝靴 + 银色手链
  - 白色高领蕾丝裙 + 深蓝色腰带 + 米白色丝袜 + 黑色短靴
- 如果剧情确实要求纯白/同色造型，必须同时满足：有材质对比、有明度层次、有明确美学理由（如新娘/天使感），并且不能大面积白色+银色堆叠。
- 完整色彩理论、60-30-10 法则、明度/饱和度/冷暖平衡和检查清单见 `references/color-theory.md`。
- 颜色搭配还必须符合当前场景的氛围、情绪和戏剧张力：例如控制面用深蓝/黑/银，失控面用红/黑/汗湿暴露，病弱面用苍白/低饱和/宽大衣物；小面积点缀色可承载剧情暗示。

### 材质搭配
- 全身至少有两种材质层次。
- 避免全软无骨（纱裙+纱裙）或全硬无柔（皮衣+皮裤+皮靴）。
- 材质对比可表达角色状态：柔软裙子+硬挺靴子=温柔与掌控并存；湿透雪纺+哑光皮靴=脆弱与凌乱。

### 鞋靴规格
每双鞋必须写清：
- 鞋型：尖头/圆头/方头、短靴/及踝靴/及膝靴/过膝靴
- 筒高：到脚踝/小腿中/膝盖
- 跟型：平底/粗跟/细高跟，跟高约多少
- 材质：皮革/麂皮/漆皮/帆布/缎面
- 颜色与装饰：流苏、搭扣、系带、铆钉、刺绣等

### 首饰/发型/发饰/小配件
- 首饰：写清金属色、款式、大小、位置、光泽；不能只写“手链”“戒指”。
- 发型：写清造型类型、长度、发质、刘海/发缝、当前状态（顺滑/湿透/汗湿/散乱）。
- 发饰：写清大小、颜色、材质、固定位置。
- 小配件：只要画面中出现，就要有可见形态，例如手机颜色/屏幕状态、眼镜框型、包袋材质/背法、伞是否打开/收拢、围裙花纹/系带。
- 所有配饰必须与服装整体颜色、材质、风格协调，并符合该场景剧情阶段。

## 场景环境整体构建

生图模型无法只凭“旧楼”“房间”“雨夜”这类概括词生成完整画面。每个提示词都必须把场景当成一个整体来描述，而不只是补一句地面。

每个场景必须写清：

1. **空间类型**：室内/室外、房间/街道/车内/雨地等。
2. **时间与天气/光线**：白天/夜晚/雨天/灯光类型/明暗方向。
3. **地面与材质**：木地板、水泥地、瓷砖、地毯、泥地、柏油路等；颜色、纹理、污渍、积水。
4. **墙面/门窗**：墙皮状态、颜色、窗户/门的位置和状态。
5. **家具/道具/周围物体**：床、桌、椅、柜、画架、旧木箱、手机、轮椅、吊具、花瓶、纸箱等。
6. **物体摆放关系**：主人物站在哪里，配角在哪里，家具在人物前方/后方/侧方，物体之间如何相对摆放。
7. **环境细节**：散落的衣物、纸张、花瓣、液体、灰尘、雨水、反光等。
8. **光线与氛围颜色**：光源位置、颜色、方向、阴影、环境主色调、人物受光/阴影位置；场景光线与氛围配色理论见 `references/color-theory.md`。

场景氛围必须从该场景的具体剧情、人物关系、情绪和戏剧张力中推导，不能根据地点类型套模板词。例如旧楼不等于“压抑”，要看是掌控、偷情、失落、威胁还是对抗，再写出对应氛围。

具体化时必须从原文/证据包提取真实细节；不能凭空编造与证据冲突的材质或物体。例如原文出现“木地板”时，就写“布满灰尘和旧木屑的老旧木地板，板缝里积着灰”，不能擅自改成“水泥地面”。

- 原文若出现“木地板”：布满灰尘和旧木屑的老旧木地板，板缝里积着灰
- 原文若出现“泥地”：泥泞的深色泥地，地面有积水反光和湿泥
- 原文未明确材质时：使用有原文线索支持的保守描述，并在提示词中注明“设计补充”，不得与原文已知信息冲突。
- 雨夜不能只写“雨夜”，要写：雨幕、积水反光、湿透的衣物、路灯灯光、周围建筑/树/车等。
- 房间不能只写“房间”，要写：床/桌/椅/柜/画架/窗帘/地毯等可见物体及其相对位置。

场景环境整体描述是每个提示词的必填项，不能省略；具体物体和材质必须来自证据或明确标注为合理补充。

## 配角一致性

同框人物不能只作为“背景工具人”随意安排。配角的性格、情绪、衣物、动作、表情也必须符合其对应的人设文件、调色盘、证据包、事件和开场资料。

- 每个配角在出场前，先查找该配角自己的 `*_人物设定.md`、`*_性格调色盘.md`、`*_三面性.md`、`*_二次解释.md`，以及证据包/events/greetings 中关于他的描写。
- 配角的外貌、服装、动作、情绪必须来自这些资料；资料不足时，只能根据剧情关系合理补充，不能脱离人设。
- 例如：一个“瘦小、懦弱、卑微”的配角，不能无理由写成高大强势；一个“控制欲强、冷静”的配角，不能无理由写成完全失控的夸张表情。
- 在提示词中，配角描述可以比主人物简略，但简略不等于随意。

## 同框人物怎么设计

当事件/场景中有其他人物时，不能只写主人物：

- 每个同框人物至少写清楚：明确年龄或年龄段（如18岁、25岁、40多岁）、性别、体型、穿着、站位、动作、表情。
- 同框人物可以比主人物简略，但必须足够让生图模型知道“画面里还有谁、在做什么、站在哪里”。
- 如果同框人物在画面中裸露或参与性交，也必须写清其裸露部位和性器外观，不能只写主人物。
- 配角的性器外观应依据证据包/原文；证据不足时按剧情合理补充。
- 同框人物应先参考外观基准文档中的同框角色速查，或该配角自己的人设/调色盘/证据资料，再写入画面；不能凭空设定配角。
- 必须明确主次关系，避免生图模型把配角当成主角。可以在提示词中直接写明：
  - “主人物位于画面中心/前景，其他人物位于后方/边缘/虚化”
  - “镜头焦点在主人物面部/身体上”
  - “配角只保留必要动作和轮廓”
- 画面中有多人时，必须用自然语言写清空间关系，禁止出现“x轴/y轴/z轴”术语，也不写无意义的厘米数。
  - 空间关系以“戏剧性视觉关系”为主，而不是测量数据：
    - 俯视/仰视/平视
    - 高位/低位
    - 笼罩/蜷缩
    - 前方/后方、左右、远近
    - 谁主动、谁被动、谁被压制
  - 示例：“她高高坐在高脚椅上，俯视着跪伏在脚边的男人；那个男人缩成一团，只到她的膝盖附近，仰起整张脸才能看见她。”
  - 同一组人物的高度/位置描述必须前后一致，禁止同时写“只到膝盖”和“高出半个身子”这类互相矛盾的短语。
  - 每个动作必须有明确主谓宾：谁的什么部位，接触/压住/抓住/插入谁的什么部位。
- 禁止只写“旁边/身后/面前”而不说明俯视/仰视、高位/低位、前后和主从关系。

示例：

```text
画面关系：一个三十岁左右的中国女性高高坐在高脚椅上，俯视着跪伏在脚边的瘦小男人；那个男人蜷缩在她脚下，仰起脸才能看见她，整个人处于她的阴影里。
```

多人空间示例（融入正文）：

```text
一个三十岁左右的中国女性被吊具固定在画面中心，骨盆位置最高，俯视着跪在她前后的两个男人；一个老年男性跪伏在她身后低处，另一个瘦小男人跪在她前方低处，两人都需要仰头看她。
```

## 裸露/性交场面怎么写

涉及裸露或性交的事件/场景，必须写清楚生图所需的信息：

- **身体姿势**：站/坐/跪/躺/趴/骑乘/后入/吊具固定等。
- **具体动作**：插入、抽插、起落、抓握、撕扯、口交、射精等。
- **裸露程度**：哪些部位裸露、哪些衣服残留、交合处是否可见。
- **身体反应**：脸红、出汗、腿软、颤抖、乳房晃动、液体痕迹。
- **表情情绪**：忍耐、羞耻、兴奋、反抗、失控、冷静。
- **同框裸露配角**：如果画面中有其他裸露/参与性交的角色，也要写清其裸露状态和性器外观，依据证据包/原文；不能只描写主人物。

不要因为“人物设定里已经写过”就省略；每个提示词都要让生图模型只凭这段文字生成完整画面。

## 跳过规则

以下事件/开场可以不生成提示词，但要在对应 `README.md` 中说明跳过原因：

- 人物没有直接出场。
- 只有内心活动、技术操作、无画面内容。
- 场景完全由他人视角构成，无法画出该人物的有效画面。

## 方法论要点

1. **先立底模，再拆场景。** 先确定人物不可动摇的视觉核心，再为每个场景做服装和状态变化。
2. **独立性优先。** 生图模型没有“跨文件记忆”，每个提示词都要能单独工作。
3. **证据优先，设计补缺。** 先构建场景描述并调研证据；原文写明的必须遵守，原文缺失的才允许基于剧情合理补充，不能无理由瞎编。
4. **配角也必须符合人设。** 配角的性格、情绪、衣物、动作、表情都要与其人物设定/调色盘/证据包一致；资料不足时按剧情合理补充。
5. **辨识度靠正文中的稳定视觉锚点。** 同一个角色的所有提示词都要在正常画面描述里重复同一组核心外观：同样的脸型/五官/发色/发型/肤色/身型比例；配饰和身体状态只在该阶段出现时写入。
6. **越裸露越要写清。** 性交/裸露场面不能只写氛围，必须写清动作、姿势和可见范围。
7. **只写可见画面。** 把“主人物”“成为某花名之前”“某山庄”这类抽象/专名/剧情说明转换成可直接画的人物主体、服装状态、场景材质和空间关系。
