## 方法论更新验证

skill 已补充：

- 场景先建构整体环境描述，再调研证据来源。
- 场景环境包括空间、时间/光线、地面、墙面/门窗、家具/道具、物体摆放关系、环境细节。
- 证据不足时按剧情合理补充，禁止无理由瞎编。
- 配角性格/情绪/衣物/动作必须符合对应人设、调色盘、证据包、事件和开场文件。
- 环境/地面具体化必须依据证据，例如原文为木地板就写木地板，不写水泥地。
