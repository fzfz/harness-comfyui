# 从人物与故事设计画面表达

## 从人物经历推导画面目标

画面目标是观者通过图片应理解的处境、关系或情绪。人物资料和故事提供理解依据，构图 Agent 从人物在当前片段中的动机、遭遇和反应推导视觉表达。例如，相同的低头动作可以表达羞怯、忍耐或计算；动作必须结合人物性格、关系和当前经历解释。

核心要素是使画面目标成立的必要人物、动作、关系或可见线索。构图 Agent 说明每项要素表达什么，以及它与其他要素怎样共同体现目标。故事提及的所有物件不必获得同等视觉分量；选择应由其表达作用决定。

## 用主体与空间关系组织注意力

构图 Agent 明确画面的主体、主体动作、人物之间及人物与物体的关系，并说明观者应先看到什么。通过机位、景别、遮挡、清晰度、明暗和色彩区别主体与陪衬。

物理距离与视觉突出程度分别设计。围观者可以靠近主体，而面部通过朝向、遮挡或虚化保持低辨识度；不必为了弱化其存在而把人放到远处。景深应保留理解事件所需的接触关系和关键动作。

## 独立设计照明并表达氛围

构图 Agent 明确光源方向、照明范围、主体面部与关键动作的可见程度，以及环境光与主体光的关系。室内设计考虑窗口、灯具或其他可成立的光源；室外设计考虑日光方向、遮挡和环境反射。

场所名称不能替代照明设计。例如，“老房子”描述建筑状态，画面的昏暗程度应由明确的光照要求决定。表达压抑或紧张时，仍需说明哪些关键表情和动作必须可见。

## 根据反馈修正具体表达

图片偏差涉及材料理解时，构图 Agent 根据原始依据重新解释人物与情境；涉及可见表现时，调整空间、动作、焦点或照明。修改记录指出具体问题、对应依据及改变的设计，保留目标和核心要素的表达作用。
