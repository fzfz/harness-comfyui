# 比较子任务提示词与完成条件

```text
读取 <iteration-method.md路径> 和 <本阶段记录要求>。本阶段为 <Prompt改动检查、图像比较或复验评估>，输入产物为 <具体文件路径及用途>。
Prompt 改动检查时，核对 Builder 输出是否符合已确认构图；修改已有基线时，另核对全部改动是否属于本轮假设。保存通过或冲突结论后结束。
图像比较或复验评估时执行以下步骤：
读取已确认目标、基线、候选请求和逐图原始观察。先核对每张图是否同时满足全部适用必需项和核心表达，再比较本轮目标改善、已有优点、人物关系、主体清晰度、照明和整体氛围。
区分观察事实、原因假设和已由对照支持的结论。一个局部细节改善但整体退步时回退；可试验元素的省略改善整体时，按表达作用判断，不机械恢复。
记录采用、回退、待二次观察或待用户决定。候选未达标且预算允许时提出一个下一轮假设，没有新假设或预算不足时记录未完成原因。
候选达标后，读取 task.json 的逐镜头交付数量和复验计划，并记录各份配置的冻结内容及复验建议。计划缺少新 Seed、图片数量或通过条件时，返回缺项。复验通过时返回选图建议；复验失败时记录达标图片及失败判据，有预算且有新假设时建议下一轮，否则建议归档未完成结果。
分别保存每批满足全部适用必需项和核心表达的图数、计划图数及各镜头的交付数量。不同配置可以共同提供交付图片，但分别报告复验状态。展示最终图片与未解决偏好，将选图建议交主 Agent 取得用户采用记录，或按此前明确授权的自主选图权限提出最终选择。

将完整判断、统计、下一轮假设或复验计划写入指定 round.json 和 review.md。向主 Agent 返回 next_action、简短原因、所需输入引用及待用户决定事项，不提交图片，不直接修改 task.json。
```

完成条件：每项结论都有产物依据；下一步是一个明确阶段或停止原因。主 Agent 按建议和剩余额度调度；需要改变已确认目标时先向用户转交问题。子任务向主 Agent 提供选图建议；主 Agent 取得用户的真实采用回复，或依据已有的明确自主选图授权记录最终选择。
