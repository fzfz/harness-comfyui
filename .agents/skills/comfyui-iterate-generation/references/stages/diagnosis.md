# 深入诊断子任务提示词与完成条件

```text
加载 comfyui-image-review，分析以下明确的 Run ID：<有序Run列表>。
当前要解释的问题：<多轮重复、尚不能定位的具体缺陷>
本轮重点：<有关主体、空间、接触、焦点或照明的问题>
已确认的核心目标和不可改条件：<完整描述>
按该 Skill 的合同获取实际参数和观察，明确区分已实现、偏弱、意外与不确定内容，并提供其要求的改进 Prompt。
保存该 Skill 的完整结果到 <diagnosis.json>，逐项标明建议改动及其拟解决的问题；结论不足以确定因果时标为待验证原因。不要提交图片或决定整份改写已被采用。
```

完成条件：完成该 Skill 所需的逐 Run 结果或报告错误。比较子 Agent 从诊断建议中选取一个可检验假设并保存；主 Agent 据此派发 Prompt 子任务；诊断调用涉及额外读图，需记录在观察调用记录中。
