# 观察子任务提示词与完成条件

```text
加载 local-image-reader，按输入顺序逐图读取这些本地图片：
<每张图的绝对路径，保留原顺序和重复项>

为每张图使用下面的完整观察要求：
“描述图中实际可见的内容。先说明第一眼最醒目的对象、主要人物可辨认与看不清的身体部位、主要人物的姿态和外在情绪，再说明空间位置、接触、遮挡、清晰与模糊区域、光线方向及明暗层次。
随后针对以下问题分别报告可见证据：<不预设答案的中性观察问题>。
不确定或无法看清时明确说明，不将没有提到的内容当作确定不存在。只依据图片，不猜测生成意图或故事背景。”

将每次实际调用的 prompt、路径、provider、model、原始 observation 或错误写入 <指定observations目录>。保留每张图的独立结果，返回有序的产物引用。不要生成改进 Prompt，不评价本轮应采用或回退。
```

主 Agent 不向首次观察子任务提供原始生成 Prompt、故事解释或预期成功结论；只提供从判据转换的中性问题，例如“人物右手与桌面是否接触，依据是什么”。视觉模型选择仍来自现有图片读取配置，不把主 Agent 的文本模型自动用作视觉模型。

完成条件：所有指定路径都有 observation 或错误；观察结果未被主 Agent 改写后覆盖。二次观察使用同一模板，只替换为影响采用决定的聚焦问题，并追加结果文件。
