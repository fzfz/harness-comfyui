# 归档子任务提示词与完成条件

```text
读取 <records.md路径>。根据 <任务、轮次和最终选择依据路径>，以及 <成功交付时的用户采用记录或自主选图授权及最终选择；未完成时的停止原因与已有成果记录>，写入 <final/selection.json> 和 <final/配方.md>。
配方使用相对链接引用实际请求与图片，写明适用条件、验证范围、取舍、失败经验和复现步骤。不把未验证原因写成事实；未完成任务如实保存停止原因和已有成果。
核对所引用的文件确实存在、Run 与图片对应。返回交付文件路径、最终状态和简短结论，完整材料保留在文件中。
```

完成条件：成功交付文件与真实采用记录或已授权的最终选择一致；未完成任务保存停止原因及已有成果，不声明最终采用。所有实际引用的图片和请求均可读取，复验失败或尚未完成不会写成成功。
