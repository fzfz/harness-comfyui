# Prompt 子任务提示词与完成条件

```text
加载 <prompt_builder_skill>，按其原生输入合同构建并校验一份本镜头的 Prompt 结果。
本次已确认的具体画面要求：<完整自然语言构图、表达、光线、焦点、必需项>
原始 Character/Style 上下文：<逐条原样附上可用记录；没有则明确写无，不伪造记录>
已明确选择的历史来源：<仅在符合该 Builder 历史来源合同的时候提供>
本任务基线 Prompt：<已有基线完整内容；建立基线时写无>
本轮唯一假设：<需要解决的问题、预期改善及原因；建立基线时写无>
允许修改：<修改基线时填写围绕本轮假设的具体描述或参数；建立基线时填写按已确认画面要求构建 Prompt>
必须保持：<已成立的要求和非试验配置>

基线是本轮对照内容，不自动成为 Character 或 Style 来源。将本次画面要求转换为该模型可用的表达，保留已确认目标。不要把阶段编号、文件路径、预算或工作指令写进生成 Prompt。
<builder-result.json> 的顶层内容必须是该 Builder 通过最终生成结果校验的原生 JSON 对象。中间槽位结果、来源说明和构图映射分别另存文件；<validation.json> 保存实际校验输入、退出码、stdout 和 stderr。建立基线时，说明 Prompt 如何表达已确认画面要求；修改已有基线时，列出全部内容改动及每项与本轮假设的关系。
原生 Skill 若产生多个方案，每个方案分别保存为独立原生 JSON 文件，另存差异说明，交比较子 Agent 选择本轮唯一待提交方案；不要自行批量生图。约束无法同时满足时返回冲突并结束，不扩大改动范围。
```

完成条件：Builder 原生校验通过，比较子 Agent 核对输出仍表达已确认构图。修改已有基线时，比较子 Agent 另核对全部改动属于本轮假设；建立基线时不检查假设归属。
