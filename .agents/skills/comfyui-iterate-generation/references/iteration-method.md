# 根据独立观察比较目标并提出修复方向

## 读取材料并核对要求来源

1. 比较 Agent 先完整读取本参考，再读取用户要求、构图文件和全部原始观察文件。构图文件提供画面目标和核心要素。
2. 比较 Agent 为每张图片记录 run_id、media_id 和实际图片路径。观察文件未能对应同一媒体时，比较 Agent 报告缺失的身份或不一致的记录，停止该图片的达成判断。
3. 比较 Agent 逐项保留用户要求的原文与来源。构图追加的条件单独列项，保留构图原文与文件位置。不得把构图追加的限定写入用户要求。
4. 比较 Agent 将复合要求拆成单个必要条件。每个条件写明对象、参照对象，以及需判断的动作、属性或关系。
5. 要求之间存在冲突或同一要求包含互斥条件时，比较 Agent 单列冲突各方的原文与来源。比较 Agent 不得自行选择或改写要求来消除冲突。

## 收集全部观察并核对对象关系

1. 比较 Agent 针对每个必要条件，收集全部观察文件中对应的描述。收集范围包含问答、详细描述、无法判断之处与补充观察；每段原文保留来源位置。
2. 比较 Agent 核对各段观察是否指向本条件的同一对象与参照对象，并逐项核对动作、属性或关系。对象无法对应时，记录缺少的身份或位置事实。
3. 判断空间或接触关系时，比较 Agent 列出双方相对位置、承托面或接触部位等具体事实。事实必须能够对应本条件的对象、参照对象及所要求的关系。不得用对象名称、对象存在或概括性肯定回答代替关系事实。
4. 观察相互冲突时，比较 Agent 保留冲突各方的原文与来源。比较 Agent 将无法对应或存在冲突的对象关系列为待补充事实。

## 按必要条件填写逐图证据表

1. 完成要求核对和观察收集后，比较 Agent 为每张图片填写下表。每个必要条件占 1 行。

   | 要求来源与原文 | 对象与参照对象 | 必要条件 | 全部对应观察与来源 | 结论 | 待补充事实 |
   |---|---|---|---|---|---|
   | 用户要求或构图追加条件的原文及位置 | 本条件的对象与参照对象；无参照对象时填无 | 单项动作、属性或关系 | 观察原文、关系事实及出处 | 满足、不满足或无法确定 | 缺少的具体事实；已充分观察时填无 |

2. 对应观察明确且一致支持必要条件时，比较 Agent 才将该条件标为满足；一致显示相反事实时，标为不满足。观察缺失、无法辨认、对象或关系无法对应、描述相互冲突时，标为无法确定。
3. 补充观察到达后，比较 Agent 将补充描述与全部已有观察合并核对，再更新对应条件。缺少的事实或冲突仍未解决时，保留无法确定。
4. 同一张图片的全部必要条件均为满足时，比较 Agent 才判定该图片达成目标。任一条件不满足时，该图片未达成；其余条件均满足但仍有无法确定时，该图片保留无法确定。比较 Agent 不得合并不同图片的证据判定达成。

## 根据可见偏差分析原因

1. 逐图证据表完成后，比较 Agent 再读取生成 Prompt、参数和此前比较结果。比较 Agent 根据已判定的可见偏差提出原因假设。
2. 比较 Agent 核对 Prompt 中的照明、空间距离和视觉焦点表达，指出可能造成偏差或相互冲突的具体表达。原因假设与可见证据分别记录。
3. 比较 Agent 记录各轮已改变的 Prompt 或参数，以及对应图片的可见变化。单轮变化保留为本轮结果，不得直接推导普遍因果规律。

## 指定后续任务与交付文件

1. 任一必要条件不满足时，比较 Agent 指出最影响画面目标的偏差。比较 Agent 给出具体修正方向，列出已满足且必须保留的表现。材料理解或构图关系需要修正时，比较 Agent 指出交给构图 Agent 的问题。
2. 任一必要条件无法确定时，比较 Agent 将待补充事实交给主 Agent。待补充事实只描述需要辨认的可见内容，不得写入期望答案。
3. 要求本身存在冲突时，比较 Agent 将冲突交给主 Agent。构图追加条件与用户要求冲突时，比较 Agent 指出需要修正的构图条件。
4. 比较 Agent 将逐图证据表、要求冲突、原因假设、已尝试的修改、可见变化和后续任务写入指定文件。比较 Agent 完成回复只返回文件路径。
