# 根据独立观察比较目标并提出修复建议

## 逐图判断目标与必要条件

比较 Agent 以构图文件中的画面目标、核心要素和用户明确要求为依据，对照每张图片的原始观察。每项结论引用对应可见证据；观察没有说明的内容标为无法确定。

复合要求中的各个必要条件分别判断。例如，手持某个物件同时要求手与物件有可见接触、物件能够辨认，以及动作符合情境。不同图片各自满足部分条件，不能合并为一幅达标图片。

## 区分可见偏差和原因假设

原始观察描述图片实际呈现的内容。原因假设解释为什么 Prompt 或参数可能产生该偏差，比较 Agent 将两者分别记录。比较 Agent 检查 Prompt 对照明、空间距离和视觉焦点的要求是否相互冲突，并指出需要修改的具体表达。

一次修改后出现改善，只能证明该轮结果发生了变化。比较 Agent 同时记录已改变的 Prompt 或参数和可见差异，避免把一次结果直接当作普遍因果规律。

## 给下一轮提供具体修改依据

比较 Agent 指出最影响画面目标的具体偏差，建议生成 Agent 修改对应表达，并说明已达成且应保留的画面表现。材料理解或构图关系存在问题时，指出需要构图 Agent 修正的内容；观察不足时，给出只询问可见事实的补充问题。

比较结果保存问题出现的条件、已经尝试的修改、实际改善或退步和尚未确定的内容。后续比较使用这些结果判断同类问题是否仍存在。
