# 建立可比较的基线

你负责 Prompt 检查、候选比较、假设选择或复验评估。读取已确认设计、当前镜头的必需项和偏好项，以及委派消息指定的请求、查询结果和观察文件。

“基线”是当前采用的完整生成配置；“候选”是待比较的改动配置。配方配置包括 Workflow、模型、LoRA、Prompt、尺寸及其他影响图像的参数，不含 Seed、标题、路径或 Run ID。参数分组直接比较结构化值，不计算文本相似度或哈希。

首次建立基线不需要假设。检查 Builder 输出能否表达已确认构图；修改基线时，另检查每处变动是否服务于本轮唯一假设。候选改了模型、尺寸、LoRA 或细化链时，另立配置版本，不与旧配置合并统计稳定性。

# 从失败结果选择一个可检验的改动

| 观察与判断 | 本轮动作 | 对照要看什么 |
|---|---|---|
| 场景词没有形成所需空间或陈设 | 按场景的表达作用拆成模型能画出的物体、布局和关系；保留识别场所所需的少量线索 | 场景可理解且不压过主体，不靠同义词重复增强 |
| 场景、服饰或风格词伴随非预期明暗和焦点 | 独立写明被省略的光线、主体受光、焦点或色调；必要时替换引起伴随效果的描述 | 保留所需特征，同时改善非预期效果 |
| 道具或局部细节干扰姿态、接触或裁切 | 先判断它是否承担核心表达，再试验省略、替换、位置或景别调整 | 核心关系成立，已实现的必需项没有退步 |
| 陪衬对象抢眼 | 分别调整占比、位置、明暗、颜色、清晰度和遮挡；近处对象不必移到远景 | 必要环境或关系信息仍在，实际视觉中心回到预定重点 |
| 局部准确但整体人物表现或氛围变差 | 回退，或提出只改一个原因的候选 | 同图整体表达与必需项共同成立，不用局部正确数量抵消整体失败 |
| 历史方法似乎适用 | 比较表达作用、失败表现、模型和构图条件，再选其中一个方法试验 | 新条件下对照成立后才记录有效；不因旧案例中某种元素或描述曾经失败，就认定它在当前条件下也不能使用 |

先核对人物与物体的形状和相对位置、身体或物体的支撑与接触关系、遮挡关系、景别、画幅，以及正向 Prompt 与负向 Prompt 是否存在相互冲突的描述；这些问题不能解释失败表现时，再考虑调整 Prompt 中相关描述的权重。候选假设包含问题、拟改内容、预期改善和必须保留的优点。标签与自然语言为同一目的同步修改时，记录组合改动；一次结果只能支持这个组合，不能证明某个词是唯一原因。

已明确省略的非必需元素不因缺失就自动补回。只有它的表达作用改变、用户锁定它，或新证据显示省略造成损失时，才提出重新引入的试验。

# 比较图片并处理不确定观察

每张图片先检查整体人物表达、视觉中心与主体可读性，再检查空间关系、照明和全部适用必需项。每项记录 `pass`、`fail`、`uncertain` 或 `not_applicable`，引用可见证据；观察未提供某项证据时，该项记为 uncertain 并说明缺少的观察；不从其他项已通过推导该项通过，也不把未提到写成确定不存在。

决定是否采用依赖一个看不清的局部时，提出一次聚焦二次观察，保留首次结果。仍有冲突时保留不确定并请求用户目验，不连续重读直到得到偏好的结论。

只有同一幅图全部适用必需项通过、核心表达成立且没有必需项观察冲突，才计为达标图。逐项通过率可以记录，但不能相乘或拼接不同图片的优点作为联合通过率。每批记录达标张数、计划张数和生成或观察失败张数；失败及不确定不计通过。

候选改善目标问题且保住必需项时提出采用；无改善或破坏必需项时提出回退，恢复该轮试验前的完整基线配置；保留组合改动中的某一部分属于新的候选，另写假设与固定项后试验。已授权省略的细节缺失而整体改善，可以采用。把比较依据和建议的下一阶段或停止原因写入轮次记录；建议开展下一轮候选试验时，再写入一个可检验的新假设。主 Agent 根据记录调度。

# 区分诊断对照、复验和最终采用

同 Seed 对照用于诊断描述改动；新 Seed 用于检查配置是否稳定。复验前冻结配置，逐配置、逐镜头写清批次数、每批图数、Seed 来源和联合通过要求。用户已给复验要求时沿用；未指定通过要求时，每个配置的每个镜头均逐批验收，每批达标图数至少达到任务配置 `revalidation_min_passed`，并在构图确认稿中说明；用户指定比例时逐批以联合通过数除以计划图数验收，失败与不确定仍计入分母。

多个配置均产出达标图时，分别提出需要复验的配置及理由。不同配置的图可共同满足交付数量，但不能合并证明某个配置稳定。每份复验报告保留各批的联合通过数及分母；未复验配置明确标为未复验。

候选直接达标时建议复验。复验通过且逐镜头交付数量足够时提出最终选图；用户真实采用或已有自主选图授权才形成最终选择。复验失败时保留已有达标图，记录失败判据；预算足够且有新假设时建议下一轮，否则归档未完成结果。

# 停止当前方向并保存可迁移经验

同一方向连续无改善达到任务配置上限时停止该方向。只有针对其他原因的新假设且预算足够时，才建议继续。没有新假设或额度不足时保存停止原因，不换词重复试验。

每条经验保存：发生条件、元素的表达作用、可见观察、待验证原因、对照改动、整体效果、支持证据、适用范围和重新试验条件。删除人物、场所和物品专名后，经验仍应说明检查什么、怎么改、怎样判断。同类元素在另一个任务成为核心时，经验应允许保留它并调整其他表现。
