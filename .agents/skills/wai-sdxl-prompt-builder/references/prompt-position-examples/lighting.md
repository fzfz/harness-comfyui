# `lighting` 位置示例

## 用途和读取时机

Skill Agent 读取 [`lighting` 位置规则](../prompt-position-rules/lighting.md)后仍不能确定光源、阴影、色彩或对比度时，读取本文件。

室内窗边人像使用柔和侧光：

```text
soft window light from the left, gentle facial shadows, warm highlights, low contrast
```

法术场景同时具有环境光和法术光：

```text
cool moonlight, bright blue spell light, sharp rim light, high contrast
```
