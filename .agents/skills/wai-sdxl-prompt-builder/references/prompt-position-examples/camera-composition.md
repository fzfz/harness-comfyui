# `camera_composition` 位置示例

## 用途和读取时机

Skill Agent 读取 [`camera_composition` 位置规则](../prompt-position-rules/camera-composition.md)后仍不能确定镜头与布局时，读取本文件。

双主体全身侧面镜头，女性位于左侧，男性位于右侧：

```text
full body, side view, woman on the left, man on the right, both subjects fully visible
```

门框遮挡左肩但脸部和右手仍然可见：

```text
medium shot, foreground doorframe occluding the left shoulder, face and right hand in focus
```
