# 空间关系规则

## 用途和读取时机

本文件规定 Skill Agent 如何确定画面中主体、道具、环境边界与相机之间的空间关系，以及这些关系分别进入哪些 WAI Prompt 位置。

画面包含以下任一内容时，Skill Agent 必须在设计十五位置内容前读取本文件：

- 两名或多名主体的相对位置；
- 前景、中景或背景的景深安排；
- 左右、上下、前后、远近、内外或包含关系；
- 主体与道具、家具、建筑、门窗、容器或其他环境对象的接触关系；
- 遮挡、裁剪、局部可见或完全出画；
- 相机位于室内、室外、主体后方、主体侧面或其他会改变画面方向的位置。

## 空间方向的判断依据

Skill Agent 必须先确定相机位置、相机朝向和画面边界，再判断主体之间的空间关系。

- `left` 与 `right` 表示对象在最终画面中的左右位置。
- `foreground`、`midground` 与 `background` 表示对象到相机的远近层级。
- `in front of` 与 `behind` 表示两个对象沿相机视线方向的相对前后位置。
- `above` 与 `below` 表示两个对象在画面或场景中的相对高低位置。
- `inside` 与 `outside` 表示对象是否位于房间、车辆、建筑、容器或其他明确边界之内。
- `near` 与 `far` 表示两个对象之间是否存在足以影响互动和构图的距离。

Skill Agent 不得把画面左右位置、景深层级、对象自身朝向和空间边界混为同一种关系。例如，角色位于另一名角色的画面左侧，不表示角色位于对方身体朝向的左侧；角色位于前景，也不表示角色一定面对镜头。

## 主体与目标

每一项空间关系都必须明确指出关系两端的具体对象。例如：

- 角色 A 位于角色 B 的画面左侧；
- 角色 A 位于前景，角色 B 位于中景；
- 角色 A 被门框部分遮挡；
- 角色 A 位于车辆内部，角色 B 位于车门外；
- 角色 A 的右手接触角色 B 的左肩。

同一画面包含多名相似主体时，Skill Agent 必须使用角色名称、稳定的外貌特征、服装特征、画面位置或其他已经确定的身份信息区分主体。空间关系不能依靠相邻标签暗示归属。

## 平面位置和景深

Skill Agent 必须分别确定以下内容：

1. 每名主体位于画面左侧、中央还是右侧。
2. 每名主体位于前景、中景还是背景。
3. 主焦点位于哪名主体、哪个动作或哪个物体。
4. 前景对象是否遮挡中景或背景对象。
5. 景深是否使非焦点对象清晰、轻度虚化或明显虚化。

多名主体位于同一景深层级时，Skill Agent 必须使用左右位置、上下位置、距离、朝向或遮挡关系继续区分主体。多名主体位于不同景深层级时，Skill Agent 必须确保相机角度、景别和焦点能够显示该层级差异。

## 朝向、视线和动作方向

Skill Agent 必须分别判断身体朝向、头部朝向、视线方向和动作方向：

- 身体朝向目标，不表示眼睛正在看向目标。
- 眼睛看向目标，不表示身体也朝向目标。
- 手、武器、法术或移动路线指向目标，不表示双方已经接触。
- 背对目标但回头看向目标时，身体朝向与视线方向必须分别表达。

身体朝向和动作方向进入 `action`；相机视角、主体画面位置和景深进入 `camera_composition`；标签不能准确区分主体与目标时，Skill Agent 使用 `relation_narrative` 写明关系。

## 接触、支撑和持有

Skill Agent 必须区分以下关系：

- `near`：两个对象距离接近，但没有发生接触；
- `touching`：两个对象存在明确接触点；
- `holding`：主体使用手、手臂或其他明确部位稳定控制目标；
- `supporting`：目标的姿态或位置依赖主体的承托或支撑；
- `leaning on`：主体把部分身体重量压在目标上；
- `sitting on`、`standing on` 或 `lying on`：主体与支撑面的姿态关系明确。

接触关系必须说明接触双方和接触部位。持有关系必须说明持有者和被持有对象。支撑关系必须说明支撑者、被支撑者和支撑部位。这些内容进入 `action`；主体归属或接触方向无法通过标签准确表达时，Skill Agent 在 `relation_narrative` 中补全。

## 内外、边界和包含关系

判断 `inside` 与 `outside` 前，Skill Agent 必须先确定作为边界的具体对象，例如房间、车辆、门、窗、柜体、水面或透明容器。

画面同时显示边界内外时，Skill Agent 必须确定：

- 相机位于边界内还是边界外；
- 每名主体位于边界内还是边界外；
- 门、窗、玻璃、水面或开口是否影响可见范围；
- 边界本身位于前景、中景还是背景；
- 边界是否形成遮挡、框景或反射。

地点、建筑、容器和边界对象进入 `environment`；相机位置、框景和透视关系进入 `camera_composition`；跨越边界的主体关系无法用标签准确表达时进入 `relation_narrative`。

## 遮挡、裁剪和可见范围

Skill Agent 必须区分以下情况：

- 部分遮挡：主体仍在画面内，但身体或物体的一部分被另一个对象覆盖；
- 画面裁剪：主体的一部分超出画面边界；
- 完全出画：主体本身不可见，但其动作结果、身体局部或与画面内主体的关系仍可能可见；
- 景深虚化：主体仍可见，但清晰度低于焦点对象；
- 介质阻隔：玻璃、水面、薄纱、屏幕或反射面改变主体的可见方式。

Skill Agent 必须确定遮挡者、被遮挡者、被遮挡部位和仍然可见的部位。画面裁剪必须与景别和画面边界一致。完全出画的主体不能同时被写成完整可见。

遮挡对象、裁剪方向、景深和可见范围进入 `camera_composition`；介质本身及其所在环境进入 `environment`；遮挡导致的主体归属或动作目标不清时进入 `relation_narrative`。

## 十五位置映射

| 空间内容 | WAI Prompt 位置 |
|---|---|
| 主体数量和主体类别 | `subject` |
| 每名主体的身体朝向、动作方向、接触、持有、支撑和姿态 | `action` |
| 相机位置、景别、角度、POV、画面左右位置、景深、遮挡、裁剪和可见范围 | `camera_composition` |
| 地点、前景物、中景物、背景物、房间、建筑、容器和其他空间边界 | `environment` |
| 光线穿过门窗、玻璃、水面或遮挡物后形成的照明结果 | `lighting` |
| 标签不能准确表达的主体归属、相对位置、接触方向、包含关系或跨边界关系 | `relation_narrative` |

## 完成检查

Skill Agent 必须在进入 Prompt 自检前确认：

- 每项关系都能确定具体主体和具体目标；
- 左右位置与最终画面方向一致；
- 前中后景与相机距离、遮挡和焦点一致；
- 身体朝向、视线方向、动作方向和接触状态没有互相替代；
- 内外关系具有明确的空间边界；
- 遮挡者、被遮挡者和可见部位明确；
- 裁剪结果与景别和画面边界一致；
- 同一主体没有同时处于互相排斥的位置或可见状态；
- 需要自然语言消除歧义的关系已经进入 `relation_narrative`。
