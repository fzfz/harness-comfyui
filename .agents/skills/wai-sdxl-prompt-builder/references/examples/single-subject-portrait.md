# 单主体肖像完整示例

## 用途和读取时机

Skill Agent 为单主体肖像生成的三个候选都不能形成完整画面时，读取本文件，然后重新设计三个候选。

## 用户要求

一名银发女性站在雨后的旧城街道，手持透明雨伞，安静地看向镜头。

## 选定画面

使用膝上景、平视角度和浅景深。主体位于中央中景，透明雨伞完整可见，湿润石板路和旧建筑形成环境层次。

## 位置内容

| 位置 | 英文内容 |
|---|---|
| `quality` | `masterpiece, best quality, ultra-detailed, highres` |
| `subject` | `1girl` |
| `appearance` | `long silver hair, blue eyes, pale skin` |
| `outfit` | `navy coat, white blouse, leather boots, transparent umbrella` |
| `action` | `standing, holding an umbrella with both hands, facing the camera` |
| `expression_reaction` | `calm expression, looking at the camera, relaxed shoulders` |
| `camera_composition` | `knee-up shot, eye level, centered composition, shallow depth of field` |
| `environment` | `rain-wet old town street, stone pavement, old buildings, puddles` |
| `detail_mood` | `subtle film grain, reflective wet surfaces, quiet atmosphere` |
| `lighting` | `soft overcast light, gentle reflections, low contrast` |
