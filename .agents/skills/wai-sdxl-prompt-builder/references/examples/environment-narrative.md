# 环境叙事完整示例

## 用途和读取时机

Skill Agent 为环境叙事主场景生成的三个候选都不能让地点、空间尺度、天气和光线共同承担画面叙事时，读取本文件，然后重新设计三个候选。

## 用户要求

暴雨刚停的废弃海边车站，没有人物，铁轨延伸到被雾遮住的远方。

## 选定画面

使用低机位广角镜头。积水铁轨从前景延伸到雾中背景，废弃站台和破损顶棚位于中景，海浪位于侧后方。

## 位置内容

| 位置 | 英文内容 |
|---|---|
| `quality` | `masterpiece, best quality, ultra-detailed, highres` |
| `camera_composition` | `low-angle wide shot, railway tracks leading from the foreground into the foggy distance, deep perspective` |
| `environment` | `abandoned seaside station, rain-soaked tracks, cracked platform, damaged roof, distant ocean, thick fog after a storm` |
| `detail_mood` | `wet metallic texture, drifting mist, lonely and desolate atmosphere` |
| `lighting` | `cold overcast light, pale reflections in puddles, muted blue-gray palette, low contrast` |
