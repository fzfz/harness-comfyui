# Prompt 自检

## 用途和读取时机

本文件规定 Skill Agent 在完成本轮十五位置内容后必须执行的语义与画面完整性检查。

Skill Agent 完成全部实际使用位置后、执行 Prompt 冲突规则前，必须完整读取并执行本文件。发现问题时，Skill Agent 返回产生该内容的画面设计步骤或位置规则修改内容，然后从本文件第一项重新检查。

## 用户要求与采用优先级

Skill Agent 必须确认：

- 用户本轮要求的主体、角色、动作、镜头、环境、画师、普通画风、光线和输出用途已经落实；
- 用户明确排除的内容没有重新出现；
- 内容采用顺序符合“用户本轮意图 > UI 已选内容 > 语义工具结果 > Skill Agent 自主设计内容”；
- Skill Agent 自主补充的内容没有改变用户明确要求的画面目的。

## 主场景与位置集合

Skill Agent 必须确认：

- 本轮只选择一个主场景；
- 主场景要求的位置全部具有实际内容；
- 用户明确要求、次要约束和已读取跨位置配方需要的位置已经加入；
- 没有实际内容的位置没有保留；
- 所有位置按照十五位置固定顺序排列；
- Skill Agent 新增的每项内容只出现在承担该职责的位置；
- Character 来源内容以外的位置没有重复该来源内容已经准确表达的外貌或服装。

## 主体、角色和外貌

Skill Agent 必须确认：

- `subject` 中的主体数量和类别与最终构图一致；
- Character 来源内容包含单角色数量标签时，`subject` 仍然准确表达整幅画面的主体总数；
- 每个被采用角色都能对应到画面中的具体主体；
- 多主体的外貌、服装、动作和反应具有唯一归属；
- 外貌与镜头可见范围一致；
- 角色提示词与新增外貌、服装或身体状态没有产生未处理冲突。

## 动作、反应和关系

Skill Agent 必须确认：

- 每个动作具有明确主体；
- 需要目标的动作具有明确目标；
- 姿态、动作方向、身体朝向、接触、支撑和结果能够同时成立；
- 每名主体的表情、视线和身体反应符合当前动作阶段；
- 标签无法准确表达的动作归属和主体关系已经进入 `relation_narrative`。

## 镜头、空间和环境

Skill Agent 必须确认：

- 景别能够容纳所有必须可见的主体、动作和环境对象；
- 相机角度、POV、焦点、主体位置、前中后景、遮挡和裁剪能够同时成立；
- 左右、前后、上下、内外、远近和包含关系以最终相机位置为判断依据；
- 环境具有支持动作、主体位置和相机位置的具体对象；
- 时间、季节、天气和环境状态一致。

## 画面表现与画师

Skill Agent 必须确认：

- `detail_mood`、`lighting` 和 `non_artist_style` 各自承担规定内容，没有互相重复；
- 光源、阴影方向、色彩和对比度能够支持主焦点、动作路径和空间层次；
- 每个被采用画师都已经按照画师采用规则和 WAI 画师语法处理；
- 具体画师内容没有进入普通画风、画面细节或光线位置。

## 权重设计

Skill Agent 必须确认：

- 每个显式权重来自用户、合法来源或 `prompt-weight-policy.json` 的一个策略档位；
- 选定构图只有明确的主视觉锚点使用强调档位，大部分 tag 保持未加权；
- 除用户明确提供权重以外，合法 UI Style、语义 Style、Character 来源权重和自主设计权重产生的高于中性强度视觉决定总数不超过 `recommendations.maximum_boosted_decisions`；
- 每个数组元素只有一层权重外层；
- 同一 payload 没有同时出现加权与未加权副本，也没有使用同义加权 payload 叠加强度；
- `recommendations.unweighted_quality.content` 中的默认质量段保持未加权；
- `relation_narrative` 没有 tag 权重外层。

## 分镜

画面包含多个画格时，Skill Agent 必须确认：

- 每个画格具有明确主体、状态、动作、镜头、环境和光线；
- 跨画格不变内容保持一致；
- 每项变化能够指出具体主体和具体内容；
- 画格顺序、时间、状态或因果关系已经进入 `relation_narrative`。

## 完成条件

以上全部内容成立后，Skill Agent 进入 [Prompt 冲突规则](prompt-conflict-rules.md)。
