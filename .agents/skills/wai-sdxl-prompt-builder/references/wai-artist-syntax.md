# WAI 画师语法

## 用途和读取时机

本文件规定 Skill Agent 如何把每个被采用画师的画师提示词转换为 `artist` 位置使用的 WAI 外层格式。

UI 已选 Style 的字段和选择顺序由 [当前轮输入合同](input-contract.md)定义。

Skill Agent 每次采用一个或多个画师时，必须在完成候选采用后完整读取本文件。画师查询和候选比较由[画师采用规则](artist-adoption.md)规定。

## 唯一输出格式

每名画师必须独立使用以下格式：

```text
(payload:weight)
```

单个平衡画师使用：

```text
(payload:1.0)
```

多个画师分别使用独立括号，并以英文逗号和一个空格分隔：

```text
(primary payload:1.1), (supporting payload:0.8)
```

多个画师不能放入同一个括号，也不能把画师 payload 作为没有权重的普通标签输出。

## 从画师提示词取得 payload

Skill Agent 必须按照以下顺序处理每个被采用画师的画师提示词：

1. 删除字符串首尾空白。
2. 字符串以不区分大小写的 `by` 加空白开头时，删除这一组开头内容。
3. 整个剩余字符串被一组 `(payload:number)`、`(payload)` 或 `[payload]` 完整包裹时，删除这一组最外层包裹；源字符串中的权重不进入最终结果。
4. 解除最外层包裹后，payload 以不区分大小写的 `artist:` 开头时，删除该前缀。
5. 再次删除首尾空白。
6. payload 非空时，为它应用本文件规定的项目权重并生成唯一输出格式。

Skill Agent 必须保留 payload 内部的空格、下划线、字母大小写和其他可见字符。payload 必须始终来自语义查询接口文档允许采用的画师提示词。

## 括号和方括号转义

payload 内部作为文字出现的 `(`、`)`、`[` 和 `]` 必须分别使用一个有效反斜杠转义。已经具有一个有效反斜杠的字符不重复转义。

Skill Agent 只保留本文件生成的最外层圆括号作为 WAI 权重语法。最外层圆括号内部开头和结尾不保留空白，冒号两侧不保留空白。

## 权重

| 画师作用 | 权重 |
|---|---:|
| 单个画师或平衡画师 | `1.0` |
| 主要画师 | `1.1` |
| 辅助画师 | `0.8` |

Skill Agent 必须按照以下顺序确定权重：

1. 用户提供数值权重时，使用该数值；允许范围为 `0.25` 至 `1.5`，超出范围时调整到最近边界。
2. 用户明确指定主要或辅助作用时，分别使用 `1.1` 或 `0.8`。
3. 单个画师没有明确权重或作用时，使用 `1.0`。
4. 多个画师没有明确主次时，每名画师都使用 `1.0`。
5. 完整画面设计明确需要主次关系时，主要画师使用 `1.1`，辅助画师使用 `0.8`。

权重使用英文数字。整数权重保留一位小数；其他权重删除多余的末尾零，但至少保留一位小数。

## 去重和顺序

Skill Agent 必须在删除源外层包裹和前缀后比较 payload，并删除完全相同的重复画师项。

用户明确指定顺序时，Skill Agent 保留用户顺序。用户没有指定顺序时，主要画师位于平衡画师之前，平衡画师位于辅助画师之前；同一作用内保持 UI 选择顺序或采用顺序。

完整 `artist` 位置必须连续放置在 `quality` 之后和 `subject` 之前。

## 完成检查

Skill Agent 必须确认：

- 每名画师使用独立的 `(payload:weight)`；
- payload 来自对应的被采用画师提示词；
- 源外层包裹、源权重、`by` 前缀和 `artist:` 前缀已经按规则处理；
- payload 内部字符和必要转义得到保留；
- 多个画师的权重、顺序和分隔格式正确；
- `artist` 中没有普通画风、媒介、摄影效果或光线内容。
