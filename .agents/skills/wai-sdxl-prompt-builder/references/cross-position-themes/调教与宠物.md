# 调教与宠物跨位置配方

## 用途和读取时机

用户要求调教、主人与宠物关系、服从表现、项圈、牵引、笼具、进食器具或动物化姿态时，Skill Agent 必须读取本文件。

本文件规定调教与宠物主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的关系

Skill Agent 必须确定：

- 谁是主人、训练者或支配者；
- 谁以宠物身份出现；
- 当前显示佩戴器具、牵引、爬行、进食、等待、展示、奖赏或其他具体训练内容；
- 项圈、牵引绳、笼具、食盆、尾部装置或其他器具由谁控制；
- 宠物主体当前处于学习、服从、等待、抗拒或用户指定的状态。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 主人、训练者、宠物主体和其他参与者的准确数量与身份类型 |
| `outfit` | 项圈、牵引绳、铃铛、笼具、食盆、尾部装置、束带和其他训练器具 |
| `action` | 四肢着地、爬行、跪姿、牵引、进食、等待、展示或其他具体训练动作 |
| `expression_reaction` | 主人与宠物主体各自的表情、视线和身体反应 |
| `camera_composition` | 能够显示器具连接、控制方向、主体姿态和主人—宠物关系的镜头 |
| `environment` | 笼舍、室内训练区、公共场所、地面器具或其他实际训练环境 |
| `relation_narrative` | 明确谁控制谁、谁牵引谁、器具连接关系和当前训练要求 |

## 完成检查

Skill Agent 必须确认主人—宠物关系、器具控制方向和训练动作清楚可见。宠物主题必须具有持续的主人—宠物关系；仅表现人物被当作设施或消耗品时，使用 RBQ 与物化配方。
