# 异种跨位置配方

## 用途和读取时机

用户要求非人主体、异种互动、体型差、数量差、非人身体结构或异种生存环境时，Skill Agent 必须读取本文件。

本文件规定异种主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的异种内容

Skill Agent 必须确定：

- 每名非人主体的种类、数量和可见身体结构；
- 人类主体与非人主体的体型、力量和数量关系；
- 非人肢体、触手、尾部、翅膀、黏液、机械部件或其他结构如何参与动作；
- 每项动作由哪名主体或哪个身体部位执行；
- 环境是否支持该异种的体型、运动方式和互动方式。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 人类与非人主体的准确数量、类别和组合 |
| `appearance` | 非人主体的身体结构、材质、体型、标记和与人类主体的尺寸差异 |
| `action` | 每条肢体、触手、尾部、机械部件或其他结构的动作主体、动作目标、接触点和结果 |
| `expression_reaction` | 各主体对当前互动、力量差、数量差和结果的表情与身体反应 |
| `camera_composition` | 能够显示异种全貌、尺寸差、数量差、接触关系和必要身体部位的镜头 |
| `environment` | 栖息地、巢穴、实验室、机械设施、水下空间或其他支持异种活动的具体环境 |
| `detail_mood` | 黏液、机械运动、孢子、碎屑、冲击或其他异种互动产生的画面效果 |
| `relation_narrative` | 明确非人结构属于哪名主体、作用于谁，以及多条动作的归属 |

## 完成检查

Skill Agent 必须确认非人主体的种类、身体结构、动作方式和环境能够同时成立；多条肢体或多个非人主体的动作不能共享无法判断归属的标签。
