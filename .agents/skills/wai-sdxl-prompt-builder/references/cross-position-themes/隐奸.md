# 隐奸跨位置配方

## 用途和读取时机

用户要求通过画面裁剪、上下分区、介质遮挡、伪媒介画面或暗示性构图隐藏正在发生的动作时，Skill Agent 必须读取本文件。

本文件规定隐奸主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 选择隐藏方式

Skill Agent 必须根据用户要求和选定构图采用一种主要隐藏方式：

- 画面裁剪：只显示身体局部、动作结果或超出画面的主体部分；
- 上下分区：上方或桌面以上显示正常活动，下方或桌面以下显示隐藏动作；
- 介质遮挡：使用被子、磨砂玻璃、帘幕、门板、柜体或其他介质遮挡关键内容；
- 伪媒介画面：使用手机画面、取景框、录制界面、聊天界面或其他媒介限制可见范围；
- 暗示性构图：只显示姿态、身体局部、运动、服装状态或结果线索，不完整显示动作本身。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 画面中实际可见的主体数量，以及完全出画但通过关系短句参与动作的主体 |
| `outfit` | 支持隐藏动作的服装状态、局部暴露、遮盖物和遗留物件 |
| `action` | 可见的日常动作、隐藏动作、局部动作和动作结果，并分别明确主体与目标 |
| `expression_reaction` | 当前可见主体的表情、视线和身体反应；上下分区时保持日常表层与隐藏动作的反差 |
| `camera_composition` | 裁剪方向、上下分区、遮挡介质、伪媒介边界、可见局部和焦点 |
| `environment` | 桌面、被子、玻璃、帘幕、门、柜体、屏幕或其他实际形成隐藏效果的对象 |
| `detail_mood` | 运动线索、液体线索、屏幕效果、轮廓或其他使隐藏动作能够被推断的画面效果 |
| `relation_narrative` | 明确被遮挡或出画主体、隐藏动作的主体与目标，以及画面上下或媒介内外的关系 |

## 与偷窥的区别

隐奸通过不完整展示让动作保持隐藏；偷窥通过观看方和观看渠道表现“谁在看谁”。同一请求同时包含两者时，Skill Agent 分别读取隐奸配方和偷窥与展示配方。

## 完成检查

Skill Agent 必须确认主要隐藏方式在镜头、环境和动作中使用同一组边界；可见线索足以说明正在发生的动作，但画面没有同时把被隐藏内容完整展示出来。
