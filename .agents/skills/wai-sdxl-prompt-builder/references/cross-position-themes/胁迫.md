# 胁迫跨位置配方

## 用途和读取时机

用户要求胁迫关系、权力来源、把柄、债务、职权、暴力、药物、录制威胁或由此产生的抗拒与屈服状态时，Skill Agent 必须读取本文件。

本文件规定胁迫主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的胁迫内容

Skill Agent 必须确定：

- 谁实施胁迫，谁受到胁迫；
- 胁迫来自职权、债务、秘密、把柄、武器、药物、人数优势或其他用户指定条件；
- 画面中哪些具体对象或动作使胁迫条件可见；
- 受到胁迫的主体处于拒绝、犹豫、抗拒、被控制、放弃抵抗或用户指定的其他阶段；
- 当前画面显示威胁提出、控制实施、被迫行动还是持续控制的结果。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 实施者、受胁迫者、协助者和其他参与者的准确数量与身份类型 |
| `outfit` | 武器、录制设备、药物容器、文件、制服或其他使权力关系可见的具体物件 |
| `action` | 威胁、控制、限制、递交证据、录制、压制或被迫完成的具体动作 |
| `expression_reaction` | 各主体在当前胁迫阶段中的表情、视线和身体反应 |
| `camera_composition` | 能够同时显示实施者、受胁迫者、胁迫手段和权力差异的镜头 |
| `environment` | 办公室、债务场所、房间、车辆、封闭空间或其他支持胁迫条件的环境 |
| `detail_mood` | 紧张、压迫、恐惧、无望或用户指定的整体画面情绪 |
| `relation_narrative` | 明确谁利用什么条件迫使谁完成什么动作，以及当前阶段 |

## 完成检查

Skill Agent 必须确认胁迫的实施者、受胁迫者、权力来源、具体手段和当前阶段都能从画面与关系短句中判断。仅有激烈动作但没有胁迫条件时，不使用本配方。
