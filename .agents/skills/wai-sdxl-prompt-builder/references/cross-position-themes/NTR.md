# NTR 跨位置配方

## 用途和读取时机

用户要求 NTR 关系、介入方、被夺方、伴侣、见证者、通话见证、现场观看或事后关系变化时，Skill Agent 必须读取本文件。

本文件规定 NTR 主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图，不把 NTR 当作新的主场景。

## 必须确定的关系

Skill Agent 必须确定：

- 介入方是谁；
- 与介入方发生互动的主体是谁；
- 被夺方或伴侣是谁；
- 被夺方是否入镜、通过电话或屏幕参与、从远处观看，或者完全不在画面中；
- 哪名主体知道当前关系，哪名主体尚未发现；
- 当前画面显示互动过程、被发现、观看反应还是事后结果。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 画面中实际出现的主体数量、性别组合和各方身份类型 |
| `action` | 介入方与互动主体的动作，以及被夺方正在通话、观看、靠近或离开的动作 |
| `expression_reaction` | 互动主体、介入方和被夺方各自的表情、视线和反应 |
| `camera_composition` | 同框、分屏、窗外视角、屏幕画面、电话画面或其他能够显示见证关系的构图 |
| `environment` | 酒店、卧室、住宅、窗户、电话、屏幕或其他使关系可见的具体场景对象 |
| `detail_mood` | 秘密、背叛、紧张、愧疚、绝望或用户指定的整体情绪 |
| `relation_narrative` | 明确谁与谁互动、谁是伴侣、谁正在观看或尚不知情，以及分屏或通话两端的对应关系 |

## 完成检查

Skill Agent 必须确认画面能够仅凭主体、动作、镜头和关系短句判断各方身份。普通双主体互动如果没有被夺方、伴侣或见证关系，不使用本配方。
