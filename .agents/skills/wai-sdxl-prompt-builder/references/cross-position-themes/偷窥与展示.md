# 偷窥与展示跨位置配方

## 用途和读取时机

用户要求偷窥、展示、观看方、被看方、观看渠道、偷拍、直播、自拍、被发现或尚未发现的状态时，Skill Agent 必须读取本文件。

本文件规定偷窥与展示主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 区分偷窥与展示

Skill Agent 必须先确定被看方是否知道并主动面向观看渠道：

- 偷窥：观看方通过窗户、门缝、孔洞、隐藏相机、屏幕或其他渠道观看，被看方不知道或尚未发现；
- 展示：被看方知道观看渠道，并主动向现场观看方、镜头、镜子、手机、网络直播或其他渠道展示；
- 被发现：画面显示被看方从不知道转为发现观看方或观看设备。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 画面中实际出现的观看方、被看方和其他参与者 |
| `action` | 偷看、躲藏、拍摄、直播、自拍、展示、转身发现或遮挡身体的动作 |
| `expression_reaction` | 观看方与被看方在知道、未知或被发现状态下的表情、视线和反应 |
| `camera_composition` | 窗外、门缝、孔洞、隐藏相机、手机屏幕、取景框、镜面或直播画面的具体视角 |
| `environment` | 窗户、门、孔洞、镜子、手机、摄像头、电脑屏幕和观看双方所在的空间 |
| `detail_mood` | 偷拍画面、取景框、屏幕界面、直播界面或其他属于观看渠道的摄影与数字效果 |
| `relation_narrative` | 明确谁在观看谁、通过什么渠道、被看方是否知道，以及发现状态的变化 |

## 完成检查

Skill Agent 必须确认观看方、被看方、观看渠道和知情状态明确。观看方不在画面中时，镜头和环境仍必须显示具体观看渠道；主动展示不能同时写成毫不知情。
