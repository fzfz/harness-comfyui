# 束缚与 BDSM 跨位置配方

## 用途和读取时机

用户要求束缚、BDSM、限制行动、束缚器具、固定装置、支配关系或束缚造成的身体痕迹时，Skill Agent 必须读取本文件。

本文件规定束缚与 BDSM 主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的束缚内容

Skill Agent 必须确定：

- 谁实施束缚，谁受到束缚；
- 哪些身体部位受到限制；
- 使用绳索、手铐、锁链、胶带、口具、固定架或其他具体器具；
- 器具固定到身体、家具、墙面、地面还是悬挂点；
- 被束缚主体能够进行哪些动作，哪些动作受到限制；
- 当前阶段是正在束缚、已经固定、挣扎、展示还是解除后的状态。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 画面中的实施者、被束缚者和其他参与者 |
| `appearance` | 束缚造成的压痕、红印、瘀痕或其他用户要求的身体痕迹 |
| `outfit` | 绳索、手铐、锁链、口具、眼罩、项圈和其他束缚器具及其材质、颜色和状态 |
| `action` | 束缚姿态、被限制部位、固定方向、挣扎、悬挂、牵引、施加或解除动作 |
| `expression_reaction` | 实施者与被束缚者各自的表情、视线和身体反应 |
| `camera_composition` | 能够同时显示束缚部位、固定点、主体姿态和器具走向的镜头 |
| `environment` | 地牢、卧室、牢房、展示台、固定架、墙面或其他实际承载束缚的环境 |
| `relation_narrative` | 标签无法准确表达时，明确谁束缚谁、器具连接哪个部位与固定点 |

## 完成检查

Skill Agent 必须确认每件器具都具有明确使用者、作用部位和固定位置；主体姿态必须符合器具施加的限制，身体痕迹必须与束缚部位一致。
