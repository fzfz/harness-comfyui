# 事后跨位置配方

## 用途和读取时机

用户要求事后状态、残留痕迹、服装状态、清洗、休息、离开、检查或再次行动时，Skill Agent 必须读取本文件。

本文件规定事后主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的事后内容

Skill Agent 必须确定：

- 已经结束的前序事件；
- 当前正在休息、拥抱、清洗、整理服装、检查结果、离开或开始下一项动作；
- 前序事件在身体、服装、床铺、地面、道具或环境中留下哪些可见结果；
- 每名主体当前的身体状态、表情和关系状态；
- 当前画面表现温存、疲惫、尴尬、后悔、空虚或用户指定的其他余韵。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `appearance` | 头发、皮肤、身体痕迹和其他事后可见状态 |
| `outfit` | 服装凌乱、部分穿着、散落、正在整理或已经更换的状态，以及遗留物件 |
| `action` | 躺卧、拥抱、清洗、穿衣、检查、离开、休息或再次行动的当前动作 |
| `expression_reaction` | 满足、疲惫、安静、尴尬、后悔、焦虑或用户指定的当前反应 |
| `camera_composition` | 能够同时显示主体状态、关键残留痕迹和环境结果的镜头 |
| `environment` | 床铺、浴室、散落衣物、纸巾、包装、杯子或其他前序事件留下的环境对象 |
| `detail_mood` | 余韵、疲惫、温存、空虚或其他整体情绪及残留画面效果 |
| `lighting` | 与时间和余韵相符的光源、阴影、色彩和对比度 |
| `relation_narrative` | 明确前序事件已经结束、当前动作和主体之间的事后关系 |

## 完成检查

Skill Agent 必须确认当前动作与已结束的前序事件分开表达；只有用户要求再次行动时，才把新的进行中动作写入 `action`。残留痕迹必须能够由前序事件和当前环境解释。
