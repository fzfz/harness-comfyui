# RBQ 与物化跨位置配方

## 用途和读取时机

用户要求 RBQ、人物物化、固定装置、公开使用、多人轮流使用、身体标记或被使用后的遗留状态时，Skill Agent 必须读取本文件。

本文件规定 RBQ 与物化主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的物化关系

Skill Agent 必须确定：

- 被物化主体是谁；
- 谁正在使用、管理、观看或经过该主体；
- 主体被固定成何种姿态，是否与墙体、展示台、孔洞、便器或其他装置连接；
- 物化通过身体标记、编号、价格标记、使用痕迹、固定装置还是公开环境表现；
- 当前画面显示正在使用、等待使用、多人轮替还是使用后的状态。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 被物化主体、当前使用者、其他等待者或观看者的实际数量和身份类型 |
| `appearance` | 身体文字、编号、计数标记、压痕和其他可见身体状态 |
| `outfit` | 固定器具、展示标牌、项圈、价格标记和其他与物化关系直接相关的物件 |
| `action` | 固定姿态、展示姿态、当前使用动作、轮替动作或使用后的瘫软状态 |
| `expression_reaction` | 被物化主体与使用者各自的表情、视线和身体反应 |
| `camera_composition` | 显示固定装置、公开位置、使用关系、主体数量和遗留痕迹的镜头 |
| `environment` | 公共空间、展示区、墙体装置、地牢、厕所或其他物化设施 |
| `detail_mood` | 物化、弃置、重复使用或用户指定的整体画面情绪和遗留表现 |
| `relation_narrative` | 明确谁被当作何种用途、谁正在使用或等待，以及装置与主体的连接关系 |

## 完成检查

Skill Agent 必须确认画面重点是人物被当作物件或设施使用，而不是仅有多主体互动。固定装置、主体姿态、使用关系和遗留状态必须互相一致。
