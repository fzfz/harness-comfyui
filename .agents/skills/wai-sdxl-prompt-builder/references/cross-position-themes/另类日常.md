# 另类日常跨位置配方

## 用途和读取时机

用户要求日常任务与隐藏状态、改造服装、隐蔽物件、身体暴露或成人动作同时存在，并要求主体把该状态当作日常生活的一部分时，Skill Agent 必须读取本文件。

本文件规定另类日常主题需要协调的具体画面内容。Skill Agent 继续使用已经选定的主场景和候选构图。

## 必须确定的双层内容

Skill Agent 必须同时确定：

- 主体正在完成的具体日常任务；
- 与日常任务同时存在的隐藏状态、服装状态、身体状态、物件或成人动作；
- 哪些内容对场景中的其他主体可见，哪些内容被服装、家具、画面边界或日常动作遮掩；
- 主体保持自然、专注、平静或用户指定态度的具体表现；
- 日常环境中的哪些物件证明主体确实正在完成该任务。

## 位置映射

| WAI Prompt 位置 | 本主题必须完成的内容 |
|---|---|
| `subject` | 参与日常任务和隐藏状态的主体数量与身份类型 |
| `outfit` | 改造服装、隐藏物件、局部穿着、日常服装和当前穿着状态 |
| `action` | 做饭、清洁、办公、通勤、游戏或其他日常任务，以及同时发生的隐藏动作 |
| `expression_reaction` | 与用户要求一致的自然、专注、平静或其他具体态度 |
| `camera_composition` | 同时显示日常表层和隐藏内容，或者通过遮挡与裁剪只显示必要线索的构图 |
| `environment` | 与日常任务直接相关的厨房、客厅、办公室、交通工具、家务物件或工作物件 |
| `detail_mood` | 日常表层与隐藏状态形成的反差，以及用户指定的整体画面情绪 |
| `relation_narrative` | 标签无法准确表达时，说明日常任务和隐藏状态正在同时发生 |

## 完成检查

Skill Agent 必须确认日常任务具有具体动作和环境物件，隐藏状态具有具体可见线索，两层内容发生在同一时刻。画面重点是日常化反差时，不把主题改成被发现或偷窥。
