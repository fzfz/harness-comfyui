# 构图候选与选择规则

## 用途和读取时机

本文件规定 Skill 执行者如何为当前画面构造三个完整构图候选、比较候选并选择唯一构图。构图只确定镜头、主体与对象的画面位置、可见范围、景深和运动效果，不生成 WAI Prompt 标签。

Skill 执行者使用[场景分支矩阵](composition-scenario-branches.md)选定主场景并完成画面要求的冲突处理后，完整读取本文件。

## 构图输入与来源边界

Skill 执行者使用冲突处理后保留的构图要求。每项要求继续保留其来源：当前用户消息中的明确要求、当前消息 `comfyui-context` 中的 Character 或 Style 上下文记录、已采用的 Work 或 Prompt-term 查询结果，或者 Skill 执行者补充内容。

Skill 执行者按照[当前用户消息输入合同](input-contract.md)区分当前用户消息的普通文字与 `comfyui-context`；Character 或 Style 上下文记录及其提示词字段只从当前消息的 `comfyui-context` 中读取。

Skill 执行者按照[语义查询接口与调用流程](semantic-tool-orchestration.md)取得 Work 或 Prompt-term 查询结果并读取其提示词字段。

三个候选都必须保留全部已保留构图要求及其来源身份。已保留要求指定的“画格、可变构图属性、主体或对象”具体取值项保持不变；同一属性中没有被已保留要求指定的其他具体取值项仍可改变。

本文件使用“要求合并顺序”确定画格、对象、动作和其他内容的首次出现位置。Skill 执行者依次合并：当前用户消息普通文字中从前到后的要求；当前消息中 Character 和 Style 上下文记录按照其出现顺序提供的要求；各次 Work 查询按照调用顺序返回的结果；各次 Prompt-term 查询按照调用顺序返回的结果；Skill 执行者按照本文件步骤产生的补充内容。同一次查询返回多项结果时保持返回顺序，同一结果中的提示词内容按照从前到后的顺序读取。后文的“出现顺序”“第一次出现”和“最先出现”均指要求合并顺序。

“必须可见内容”是已保留要求明确要求在画面中可辨认、但没有要求完整呈现的主体、动作、身体部位、物件或固定环境对象。“必须完整可见内容”是已保留要求明确要求完整呈现的主体、动作、身体部位、物件或固定环境对象。必须完整可见内容受到任何遮挡或裁剪时，候选不能成立；必须可见内容受到局部遮挡或裁剪时，按照候选 A 第 8 项的规则判断可辨认状态。可辨认时，候选可以成立并进入比较计数；不可辨认时，候选不能成立。

“固定环境对象”是画面中位置或形状能够单独记录的环境组成部分。“对象序列”包含全部主体、身体部位、动作、物件和固定环境对象。Skill 执行者按照每个对象在已保留要求中第一次出现的顺序，从 1 开始编号；同一明确名称、标识或指代已经确定为同一对象时合并为一个对象，无法确定为同一对象时分别编号。身体部位同时记录所属主体，动作同时记录全部动作执行对象；“动作执行对象”是执行该动作的主体、物件或固定环境对象。主焦点不改变对象编号。

“可定位对象”包括主体、物件和固定环境对象，每个可定位对象具有独立的 `x`、`y` 和 `z`。“可见实体”包括主体、身体部位、物件和固定环境对象，每个可见实体可以充当遮挡物、受到遮挡或被画面边界裁剪。身体部位的 `x`、`y` 和 `z` 使用所属主体的取值。动作没有独立的 `x`、`y`、`z` 或几何边界；动作的位置和层级使用对象编号最小的动作执行对象，动作的可辨认状态由动作组成内容的可见状态确定。

## 每个候选必须确定的十项内容

以下编号是候选内容的记录顺序。Skill 执行者构造候选 A 时，按照“主要画面目标与画格时间和状态、主焦点、主景别、观察角度、POV 与视点位置、画面对象位置与主体朝向和动作记录、前景中景背景、遮挡裁剪与可见范围、景深与运动效果、构图成立结果”的顺序计算，再按照以下编号记录结果：

1. 主要画面目标、画格时间和画格状态：主要画面目标由选定主场景名称和该主场景“内容匹配条件”对应的全部已保留内容组成。该画格同时记录已经明确的时间，以及主体、物件或固定环境对象的状态；没有对应要求时，时间或状态记录“未指定”。
2. 主景别：特写、近景、中景、全身、远景或广景。
3. 观察角度：平视、俯视、仰视、侧面或背面。
4. POV 与视点位置：第三人称外部视点、第一人称、越肩或监视器画面，以及镜头相对该 POV 参照对象的方向和距离。每种 POV 的视点所属对象和参照对象按照“可变属性、派生内容和对象顺序”确定。
5. 主焦点：该候选首先吸引注意力的主体、动作、身体部位、物件或固定环境对象。
6. 画面对象位置、主体朝向和动作记录：每名主体、每个物件和每个固定环境对象的横向坐标 `x` 与纵向坐标 `y`，每名主体的身体朝向，以及每个动作的名称、所属画格、全部动作执行对象、空间变化类型、方向或移动路径和目标。空间变化类型只能是“主体全身位移、身体部位移动、物件移动、固定环境对象位置变化、固定环境对象形状变化、无空间变化”之一。横向的“左侧边缘、左侧、中央左侧、中央、中央右侧、右侧、右侧边缘”依次对应 `x=0、0.25、0.33、0.5、0.67、0.75、1`；纵向的“上方边缘、上方、中央、下方、下方边缘”依次对应 `y=0、0.25、0.5、0.75、1`。身体部位使用所属主体的 `x` 和 `y`；动作使用对象编号最小的动作执行对象的 `x` 和 `y`。动作没有方向、移动路径或目标时，对应内容记录“无”。目标是主体、物件或固定环境对象时记录该目标的位置；目标是身体部位时记录身体部位及其所属主体的位置；目标是另一动作时记录目标动作及其全部动作执行对象的位置。
7. 前景、中景和背景：各层包含的主体、物件和固定环境对象，以及充当遮挡物的主体、身体部位、物件或固定环境对象。身体部位使用所属主体的层级；动作使用对象编号最小的动作执行对象的层级。动作目标是物件或固定环境对象时，本项同时记录该目标所在层级。
8. 遮挡、裁剪和可见范围：记录哪个可见实体遮挡哪个可见实体、画面边界裁掉哪个可见实体、每名主体、每个身体部位、每个物件和每个固定环境对象仍然可见的部分，以及每个动作的组成内容和可辨认状态。动作的可辨认状态按照其组成内容的可见状态计算。
9. 景深和运动效果：清晰范围，以及每项背景虚化、运动模糊和速度线的画格、效果类型、施加对象和受影响对象。已保留要求指定其他景深或运动效果时，该候选按照相同四项记录这些效果。
10. 构图成立结果：第 1—9 项能够同时成立时记录“无冲突”。已保留要求彼此冲突时，记录失败类型“已保留要求冲突”、不能同时成立的要求、各项要求的来源身份和受影响的第 1—9 项编号。实际采用值缺少成立所需的对象或信息时，记录失败类型“实际采用值缺少前提”、实际采用值、缺少的对象或信息、该取值的来源身份和受影响的第 1—9 项编号；该取值没有对应的已保留要求时，同时记录“无对应已保留要求”。实际采用值没有满足一项已保留要求时，记录失败类型“实际采用值违反已保留要求”、实际采用值、没有满足的要求、该取值与该要求各自的来源身份和受影响的第 1—9 项编号。

分镜请求的每个候选都必须包含完整分镜。分镜要求明确给出画格数量时使用该数量；没有直接给出数量，但分别描述了两个或更多画格时，画格数量等于可分别识别的画格描述数量；两者都没有时，候选 A 不能成立。画格名称已经明确时保留该名称；没有明确名称时，按照各画格描述在已保留要求中的出现顺序命名为“画格 1”至“画格 n”。阅读顺序已经明确时保留该顺序；没有明确顺序时按照画格编号从小到大阅读，并把该顺序记录为 Skill 执行者补充内容。

Skill 执行者为每个画格分别确定上述十项内容。八项可变构图属性分别记录为按照阅读顺序排列的逐画格取值序列；比较候选的八项可变属性组合时，使用这八个完整序列。

非分镜请求只有一个画格，该画格固定记录为“画格 1”。

下列逐格内容归属规则适用于非分镜和分镜请求。动作及直接描述该动作的身体部位、物件、目标和可见性要求优先跟随该动作：已经指定所属画格时只纳入指定画格，没有指定所属画格时纳入阅读顺序中的第一格，并把该画格分配记录为 Skill 执行者补充内容。其余主体、身体部位、物件、固定环境对象或可见性要求已经指定所属画格时只纳入指定画格，没有指定所属画格时纳入每个画格。每个画格的时间和状态使用已保留要求中的对应内容；没有指定所属画格的时间或状态纳入每个画格；没有对应内容时记录“未指定”，来源记录为 Skill 执行者补充内容。

Skill 执行者把每个具有独立动作名称的身体姿态、身体运动、物件运动或固定环境对象状态变化记录为一个动作。身体姿态或身体运动的动作执行对象是对应主体，物件运动的动作执行对象是该物件，固定环境对象状态变化的动作执行对象是该固定环境对象。动作执行对象是主体并且动作记录包含起点和终点时，空间变化类型记录为“主体全身位移”；动作明确指定身体部位改变位置时记录为“身体部位移动”；动作执行对象是物件并且该物件改变位置时记录为“物件移动”；固定环境对象改变位置或形状时分别记录为“固定环境对象位置变化”或“固定环境对象形状变化”；其余动作记录为“无空间变化”。动作身份由“所属画格、动作名称、全部动作执行对象、空间变化类型、方向或移动路径、目标”六项组成；同一画格中六项完全相同的多次描述合并为一个动作并保留全部来源身份，任一项不同或者所属画格不同时分别记录。同一个动作名称同时作用于左右对称身体部位，并且方向和目标都相同时记录为一个动作；方向或目标不同时分别记录。

## 可变属性、派生内容和对象顺序

候选可以改变的构图属性只有：主景别、观察角度、POV、主体画面位置、前景中景背景、主焦点、遮挡与裁剪、景深与运动效果。已保留要求明确指定的主景别值、观察角度值、POV 类型、视点所属对象、参照对象、镜头方向、镜头距离、主体、物件或固定环境对象的坐标、对象层级、主焦点、遮挡关系、裁剪范围、效果类型、效果施加对象、效果受影响对象和清晰范围分别保持不变。没有被已保留要求指定的默认值或备选值，只在扫描其所属可变构图属性时替换。候选改变一个可变构图属性后，所有依赖该属性且未被已保留要求指定的取值都重新计算；这些派生变化不算作第二项可变构图属性变化，但必须写入该候选的完整逐画格取值序列。重新计算的结果与任一固定值不能同时成立时，当前备选值无效。主要画面目标由选定主场景的内容匹配条件及其对应的全部已保留内容决定，身体朝向按照每个候选的第 6 条确定，构图成立结果由该候选的第 1—9 项计算得出，这三项都不是可变构图属性。

已保留要求直接指定镜头方向、距离或清晰范围时，候选保持指定值。未指定时，平视对应与参照对象同高并朝向参照对象，俯视对应从参照对象上方向下拍摄，仰视对应从参照对象下方向上拍摄，侧面对应从参照对象左侧拍摄，背面对应从参照对象后方拍摄；特写距离使面部或指定局部充满画面，近景距离呈现头部至胸部，中景距离呈现头部至腰部，全身距离呈现完整身体，远景距离呈现完整主体及邻近环境，广景距离呈现全部主体、物件和整体环境尺度；全部清晰使全部可见实体保持清晰，背景虚化使主焦点清晰并使记录中的受影响对象虚化，运动模糊使记录中的受影响对象模糊并使其他可见实体清晰，速度线使全部可见实体清晰。候选改变观察角度、主景别、POV 或景深与运动效果时，Skill 执行者重新计算依赖该属性且未被已保留要求指定的取值。POV 改变时，Skill 执行者按照新 POV 类型重新计算未固定的视点所属对象、参照对象、肩侧、摄像设备、拍摄对象、镜头方向和镜头距离；景深与运动效果改变时，重新计算未固定的清晰范围、施加对象和受影响对象。重新计算结果不能与保持不变的指定值同时成立时，当前备选值无效。定义为“朝向镜头”且未被已保留要求固定为绝对方向的身体朝向，按照改变后的镜头位置重新计算。

第三人称外部视点的视点所属对象固定记录为“无”，该值记录为 Skill 执行者计算结果并同时记录 POV 的来源身份；已保留要求指定参照对象时使用该对象，否则使用当前画格的主焦点。第一人称视点的所属主体由已保留要求指定；未指定时使用当前画格中对象编号最小的主体，当前画格没有主体时该 POV 不能成立。第一人称参照对象由已保留要求指定；未指定时，从当前画格中视点所属主体正在观看或作用的对象中选择，主焦点属于这些对象时选择主焦点，否则选择对象编号最小者。没有此类对象，并且当前画格的主焦点不是视点所属主体时，选择当前画格的主焦点；没有此类对象，并且主焦点就是视点所属主体时，该 POV 不能成立。越肩视点的所属主体、左肩或右肩位置以及参照对象分别使用已保留要求指定的值；未指定所属主体时使用当前画格中对象编号最小的主体，当前画格没有主体时该 POV 不能成立；未指定肩侧时使用右肩后上方。未指定越肩参照对象时，从当前画格中该主体正在观看或作用的对象中选择，主焦点属于这些对象时选择主焦点，否则选择对象编号最小者；未指定越肩参照对象并且当前画格没有观看对象和作用对象时，该 POV 不能成立。摄像设备是已保留要求明确表示能够拍摄画面的物件或固定环境对象。监视器画面的摄像设备和拍摄对象分别使用已保留要求指定的值；未指定摄像设备时使用当前画格中按照要求合并顺序最先出现的摄像设备，未指定拍摄对象时从当前画格中该设备拍摄的对象中选择，主焦点属于这些对象时选择主焦点，否则选择对象编号最小者；当前画格没有摄像设备或拍摄对象时，该 POV 不能成立。第一人称或越肩视点会使必须完整可见的视点所属主体无法完整呈现时，对应 POV 不能成立。

已保留要求明确指定上述列表以外的主景别、观察角度或 POV 时，候选 A 保留该值。列表外主景别还必须提供镜头距离，并分别说明画面中每名主体的可见身体范围、每个动作和身体部位是否可辨认、每个物件和固定环境对象是完整可见、局部可见还是位于画外；局部可见时还必须说明可见部分。列表外观察角度还必须提供镜头相对参照对象的方向；列表外 POV 还必须提供视点所属对象、参照对象、镜头方向和距离。缺少这些信息时，候选 A 不能成立。有效备选值的固定列表不扫描已被明确指定的主景别值、观察角度值、POV 类型或主焦点；主体画面位置、前景中景背景、遮挡与裁剪只改变尚未固定的具体取值；已保留要求指定效果类型时不扫描其他效果类型。每个方案都保留其他固定值，并按照上一段重新计算派生值。

“运动可见实体集合”从当前画格动作记录的空间变化类型取得。“主体全身位移”加入动作执行对象中的主体及其持有、穿戴或固定在身体上的物件；“身体部位移动”加入动作明确指定的移动身体部位及附着在该部位的物件；“物件移动”加入动作执行对象中的物件；“固定环境对象位置变化”或“固定环境对象形状变化”加入动作执行对象中的固定环境对象；“无空间变化”不加入任何实体。

“有效备选值”是当前检查画格中一个可变构图属性的新取值。Skill 执行者先把该取值写入候选副本，再按照本节的派生值重算规则更新第 1—10 项内容及其来源身份，形成不改变原候选的临时候选。临时候选中的新取值必须与候选 A 同一画格的对应取值不同，临时候选必须保留全部已保留要求、第 1—9 项必须能够同时成立，并且八个逐画格取值序列组合不得与已完成候选相同；同时满足这些条件的新取值才是有效备选值。

## 候选取值的来源身份

直接采用已保留要求的取值时，该取值记录这项要求的全部来源身份。一个取值由多项已保留要求共同确定时，该取值记录所有相关要求的来源身份。

已保留要求没有指定取值时，候选 A 采用的默认画格名称、阅读顺序、内容所属画格、时间、状态、景别、角度、POV、第一人称或越肩视点所属对象、参照对象、肩侧、摄像设备、主焦点、布局方案、布局坐标、对象层级、遮挡与裁剪方案、景深与运动效果，以及候选 B 或候选 C 采用的备选值，记录为 Skill 执行者补充内容。

Skill 执行者计算选定主场景、主要画面目标和对象序列编号；已保留要求没有直接指定对应取值时，Skill 执行者还按照本文件规则计算镜头方向、镜头距离、清晰范围、身体朝向、动作方向、动作空间变化类型、运动可见实体集合、三个关系有向图分别产生的 `x`、`y`、`z` 坐标计算顺序、按照这些顺序计算得到的 `x`、`y`、`z`、根据 `z` 得到的前景中景背景层级、画面边界裁剪、实际可见范围、动作可辨认状态、效果施加对象、效果受影响对象和构图成立结果。计算得到的取值记录为 Skill 执行者计算结果，并同时记录参与计算的全部取值及其来源身份；直接采用的同名取值继续按照上一段保留原始来源身份。计算依据包含 Skill 执行者补充内容时，该补充内容继续作为计算依据的来源身份记录。

## 有效备选值的固定顺序

1. 主景别：按照“特写、近景、中景、全身、远景、广景”的顺序，从候选 A 的取值之后一项向列表末尾扫描；没有可用取值时，从候选 A 的取值之前一项向列表首项反向扫描。
2. 观察角度：按照“平视、俯视、仰视、侧面、背面”的顺序，从候选 A 的取值之后一项向列表末尾扫描；没有可用取值时，从候选 A 的取值之前一项向列表首项反向扫描。
3. POV：按照“第三人称外部视点、越肩、第一人称、监视器画面”的顺序，从候选 A 的取值之后一项向列表末尾扫描；没有可用取值时，从候选 A 的取值之前一项向列表首项反向扫描。
4. 主体画面位置：扫描一个布局方案前，Skill 执行者清除当前画格中来源为候选 A 默认布局或先前备选布局的主体 `x` 和 `y`，保留已保留要求或关系图确定的坐标。布局方案按照“居中布局、左右分离布局、上下分离布局、画面边缘布局”的顺序尝试；每个方案完成后，当前画格全部主体位置的组合构成一个备选值。主焦点是主体时，该主体是主焦点主体；主焦点是身体部位时，该身体部位的所属主体是主焦点主体；主焦点是动作且动作执行对象中包含主体时，对象编号最小的对应主体是主焦点主体；主焦点是物件、固定环境对象或没有主体作为执行对象的动作时，没有主焦点主体。Skill 执行者先处理主焦点主体，再按照对象编号处理其他主体；没有主焦点主体时，直接按照对象编号处理全部主体。居中布局依次使用 `(0.5,0.5)`、`(0.33,0.5)`、`(0.67,0.5)`、`(0,0.5)`、`(1,0.5)`、`(0.5,0.25)` 和 `(0.5,0.75)`。左右分离布局依次使用 `(0.25,0.5)`、`(0.75,0.5)`、`(0.33,0.5)`、`(0.67,0.5)`、`(0,0.5)`、`(1,0.5)`、`(0.5,0.25)` 和 `(0.5,0.75)`。上下分离布局依次使用 `(0.5,0.25)`、`(0.5,0.75)`、`(0.25,0.25)`、`(0.75,0.25)`、`(0.25,0.75)`、`(0.75,0.75)` 和 `(0.5,0.5)`。画面边缘布局依次使用 `(0,0.5)`、`(1,0.5)`、`(0.5,0)`、`(0.5,1)`、`(0.33,0.5)`、`(0.67,0.5)` 和 `(0.5,0.5)`；每个坐标对依次表示 `(x,y)`。每个布局的坐标游标从第一项开始。主体的 `x` 和 `y` 都已确定时，该主体不使用坐标，游标保持不变。主体只缺少一个或两个坐标时，从游标指向的坐标开始向后检查：保留已经确定的坐标，只采用当前布局坐标提供的缺失坐标；结果与已处理主体的 `(x,y)` 相同时，游标移到下一项并继续检查；结果未被占用时采用该结果，并把游标移到所用坐标的下一项。游标越过列表末尾仍无法为当前主体取得未占用结果时，对应布局不是有效备选值。
5. 前景、中景和背景：按照“中景方案、前景方案、背景方案”的顺序从第一项到最后一项扫描。扫描一个层级方案前，Skill 执行者清除当前画格中来源为候选 A 默认层级、先前备选层级或附着关系计算结果的可定位对象 `z`，只保留已保留要求直接指定或前后关系图计算的 `z`。具有附着关系且 `z` 未由已保留要求或前后关系图确定的物件不参与层级方案分配。主焦点是主体、物件或固定环境对象时，对应可定位对象就是该对象；主焦点是身体部位时，对应可定位对象是所属主体；主焦点是动作时，对应可定位对象是对象编号最小的动作执行对象。中景方案把全部参与层级方案分配且层级尚未确定的可定位对象放在中景。前景方案把当前画格中对象编号最小、参与层级方案分配、层级尚未确定且不等于主焦点对应可定位对象的可定位对象放在前景，其余参与层级方案分配且层级尚未确定的可定位对象放在中景。背景方案按照同一条件选择对象并放在背景，其余参与层级方案分配且层级尚未确定的可定位对象放在中景。方案分配完成后，Skill 执行者按照候选 A 的附着物件坐标规则计算这些附着物件的 `z`。没有符合条件的可定位对象时，前景方案或背景方案不是有效备选值。
6. 主焦点：按照[场景分支矩阵](composition-scenario-branches.md)中选定主场景行的“内容匹配条件”从左到右检查条件中的内容类别，只保留当前画格实际包含且符合当前类别的对象或动作，再按照要求合并顺序选择第一项。需要其他取值时，按照同一顺序选择下一项；当前画格没有符合任何内容类别的对象或动作时，该主焦点取值不能成立。
7. 遮挡与裁剪：按照“无遮挡且无裁剪、前景实体局部遮挡、画面边缘局部裁剪”的顺序从第一项到最后一项扫描。无遮挡且无裁剪方案不增加遮挡或裁剪。前景实体局部遮挡方案先确定当前画格的被遮挡实体：主焦点是主体、身体部位、物件或固定环境对象时使用该可见实体，主焦点是动作时使用当前画格中对象编号最小的动作执行对象；再使用当前画格中对象编号最小、不属于必须完整可见内容、位于前景且不等于被遮挡实体的可见实体遮挡其左侧边缘。被遮挡实体的中央和右侧保持可见。画面边缘局部裁剪方案裁剪当前画格中对象编号最大、不属于必须完整可见内容的非主焦点可见实体左侧边缘，该实体的中央和右侧保持可见。没有符合条件的遮挡实体、被遮挡实体或裁剪实体时，对应方案不是有效备选值。
8. 景深与运动效果：按照“全部清晰、背景虚化、运动模糊、速度线”的顺序从第一项到最后一项扫描。全部清晰不创建效果实例。当前画格的背景虚化以镜头为施加对象，并为当前画格中每个最终记录为背景的可定位对象分别记录一个受影响对象；受影响对象按照对象编号从小到大排列，当前画格没有最终记录为背景的可定位对象时不是有效备选值。当前画格的运动模糊和速度线选择运动可见实体集合中对象编号最小的实体作为施加对象和受影响对象；集合为空时不是有效备选值。每个效果实例都记录当前画格、效果类型、施加对象和受影响对象。

## 候选 A 的十项基准内容

1. 候选 A 按照“每个候选必须确定的十项内容”第 1 项记录主要画面目标、时间和状态。候选改变主焦点时，主要画面目标保持不变。
2. 已保留要求指定主景别时使用该景别。未指定时，面部、指定身体部位或一个物件对应特写，头部至胸部对应近景，头部至腰部、两个或更多物件以及没有命中其他映射的必须可见内容对应中景，完整身体或完整动作范围对应全身，完整主体与邻近环境或一个固定环境对象对应远景，全部主体、物件与整体环境尺度对应广景；多项可见范围同时存在时，按照“特写、近景、中景、全身、远景、广景”的顺序使用排在最后的对应景别。没有明确的必须可见内容或必须完整可见内容时，Skill 执行者按照选定主场景名称确定默认主景别：“单主体肖像”“双主体互动”“遮挡与深度”或“分镜与状态变化”使用中景；“动作展示”“多主体群像”或“NSFW”使用全身；“环境叙事”使用广景。
3. 已保留要求指定观察角度时使用该角度；未指定时使用平视。
4. 已保留要求指定 POV、镜头方向或镜头距离时分别使用对应指定值。未指定 POV 时使用以主焦点为中心的第三人称外部视点；未指定镜头方向或距离时，按照“可变属性、派生内容和对象顺序”的映射规则确定。
5. 已保留要求指定主焦点时使用该主焦点。未指定时，按照“有效备选值的固定顺序”第 6 条选择第一项。
6. Skill 执行者为当前画格中的每个动作记录动作名称、全部动作执行对象、方向或移动路径和目标；移动路径同时记录其起点和终点。已保留要求指定动作方向或移动路径时记录对应内容；移动路径具有起点和终点但没有另行指定方向时，方向从起点指向终点；没有方向、移动路径或目标时，对应内容记录“无”。目标是主体、物件或固定环境对象时记录该目标的位置；目标是身体部位时记录身体部位及其所属主体的位置；目标是另一动作时记录目标动作及其全部动作执行对象的位置。

只有主体、物件或固定环境对象之间的关系明确包含方向、相对位置、画面位置或前景中景背景层级时，该关系才决定候选 A 的第 6 或第 7 项。物件被主体持有、穿戴或固定在身体上时，按照本节的附着物件坐标规则计算。注视、追逐及其他没有指定上述空间信息的关系不改变候选 A 的默认位置和层级。

Skill 执行者分别为当前画格中明确具有左右、上下或前后关系的可定位对象建立三个关系边列表，并分别复制为用于排序的有向图：左侧对象指向右侧对象，上方对象指向下方对象，前方对象指向后方对象。每个用于排序的有向图都重复选择当前未处理对象中入度为零且对象编号最小的对象，把该对象加入计算顺序，再从用于排序的有向图中删除该对象及其发出的边；每个对象只能加入计算顺序一次。用于排序的有向图中仍有对象却没有入度为零的对象时，Skill 执行者把形成循环的空间关系要求记录为“已保留要求冲突”，同时记录各项关系要求的来源身份及受影响的第 6、7、10 项。没有进入某个关系边列表的对象不参与对应方向的计算。

Skill 执行者按照计算顺序和对应的关系边列表求坐标。当前对象没有固定坐标时，下界使用已经取得坐标的直接前驱坐标最大值；没有直接前驱时下界为 `0`。上界使用从当前对象沿关系边能够到达的固定坐标最小值；没有能够到达的固定坐标时上界为 `1`。下界小于上界时，当前对象的坐标等于两者平均值。下界大于或等于上界时，Skill 执行者把对应空间关系要求与固定坐标要求记录为“已保留要求冲突”，同时记录各项要求的来源身份及受影响的第 6、7、10 项。当前对象已有固定坐标时保持该值，并检查该值是否大于全部直接前驱坐标且小于全部沿关系边能够到达的固定坐标；任一条件不成立时，按照同一失败类型和记录结构处理。左右关系边列表计算 `x`，上下关系边列表计算 `y`，前后关系边列表计算 `z`。

已保留要求中的“前景、中景、背景”依次对应 `z=0、0.5、1`。已保留要求同时指定层级名称和数值深度，但两者没有使用该映射得到相同 `z` 时，Skill 执行者把这两项要求记录为“已保留要求冲突”，同时记录两项要求的来源身份及受影响的第 7、10 项。前后关系边列表计算出的 `z=0` 记录为前景，`z=1` 记录为背景，`0<z<1` 记录为中景并同时记录具体 `z`。候选 A 对没有被已保留要求或左右、上下关系边列表确定 `x` 或 `y` 的主体采用居中布局；主体布局方案只补充尚未确定的 `x` 或 `y`，并且不改变已经确定的坐标。

Skill 执行者分别补齐物件和固定环境对象尚未确定的坐标。物件被一名主体持有、穿戴或固定在身体上时，每个尚未确定的 `x`、`y` 或 `z` 使用该主体的对应坐标；物件同时与多名主体建立上述关系时，每个尚未确定的坐标使用这些主体对应坐标的算术平均值。没有附着关系的物件，未确定的 `x`、`y`、`z` 分别使用 `0.5、0.5、0.5`。固定环境对象未确定的 `x`、`y`、`z` 分别使用 `0.5、0.5、1`。已经由已保留要求或关系图确定的坐标保持不变。

主体、物件和固定环境对象的 `x` 与 `y` 全部确定后，Skill 执行者计算每名主体的身体朝向。身体朝向的参照点按照以下规则取得：主体使用该主体的 `(x,y)`；身体部位使用所属主体的 `(x,y)`；动作使用对象编号最小的动作执行对象的 `(x,y)`；物件或固定环境对象使用该对象的 `(x,y)`；移动终点是主体、身体部位、物件或固定环境对象时使用该对象的参照点，移动终点是已保留要求指定的画面坐标时使用该坐标；没有对应固定环境对象的整体环境使用 `(0.5,0.5)`。已保留要求指定身体朝向时记录该朝向；未指定时，依次选择该主体在已保留要求中第一次出现的动作目标、移动终点、观看目标或与该主体建立关系的另一名主体，并使该主体朝向对应参照点。没有这些内容的主焦点主体朝向当前候选的镜头；其余主体朝向主焦点的参照点。参照点与该主体的 `(x,y)` 相同时，该主体朝向当前候选的镜头。
7. Skill 执行者补齐主体、物件和固定环境对象的 `z` 后，按照“`z=0` 为前景、`z=1` 为背景、`0<z<1` 为中景”记录每个可定位对象的层级。没有由已保留要求、前后关系图或附着关系确定 `z` 的主体和物件使用 `z=0.5`，固定环境对象使用 `z=1`；没有内容的层级记录“无”。
8. 第 8 项为每个可见实体分别记录左侧区域、中央区域和右侧区域的可见状态，并记录遮挡或画面边界裁掉的具体部分。三个横向区域都不可见时记录“位于画外”；三个横向区域都可见，并且没有任何身体范围或其他具体部分受到遮挡或裁剪时，才记录“完整可见”。每名主体同时按照第 2 项主景别记录实际可见身体范围；主景别没有呈现该主体的完整身体时，该主体不得记录为“完整可见”。已保留要求指定遮挡、裁剪或可见范围时，Skill 执行者必须能够确定每个相关可见实体的三个横向区域和受影响的具体部分，以及每名相关主体的实际可见身体范围；缺少任一必要信息时，记录“实际采用值缺少前提”。未指定时不增加额外遮挡或裁剪。没有附着关系，并且已保留要求没有指定其遮挡、裁剪或可见范围的物件和固定环境对象，放在画面边界内并记录为完整可见。物件附着、穿戴或固定在身体部位上时，使用该身体部位最终确定的可见状态；物件由主体持有但没有指定身体部位时，使用该主体最终确定的可见状态。身体部位位于所属主体的实际可见身体范围内，并且没有受到遮挡或裁剪时，记录为完整可见；位于实际可见身体范围外时记录为位于画外；受到遮挡或裁剪时记录三个横向区域的状态和受影响的具体部分。

主体、身体部位、物件或固定环境对象的中央区域可见时，该可见实体记录为“可辨认”，中央区域不可见时记录为“不可辨认”。Skill 执行者使用已访问动作集合取得动作的组成内容：先加入当前动作，再递归加入其目标动作；将已经位于集合中的动作跳过，并把集合内全部动作执行对象、明确涉及的身体部位和非动作目标各保留一次。动作不包含接触时，每项组成内容至少有一个区域可见才记录为“可辨认”。动作包含接触时，Skill 执行者先把动作明确指定的全部接触身体部位和接触物件加入接触可见实体集合；集合少于两个可见实体时，再加入该动作的全部动作执行对象。动作目标是主体、身体部位、物件或固定环境对象时，把该目标加入集合；动作目标是另一动作时，把目标动作已经去重的全部组成内容加入集合。Skill 执行者按照对象编号对接触可见实体去重；集合少于两个可见实体时，把当前动作记录为“实际采用值缺少前提”。集合包含两个或更多可见实体时，全部接触可见实体的中央区域都可见才把该动作记录为“可辨认”，否则记录为“不可辨认”。必须完整可见的动作只有在全部组成内容完整可见时才记录为完整可见。每个受到遮挡或裁剪的动作同时记录受影响的组成内容及其三个区域可见状态。
9. 已保留要求明确指定景深或运动效果时逐项记录。背景虚化没有指定施加对象时使用镜头；没有指定受影响对象时，为当前画格中每个最终记录为背景的可定位对象分别建立效果记录，受影响对象按照对象编号从小到大排列；当前画格没有最终记录为背景的可定位对象时，该效果缺少成立前提。运动模糊或速度线缺少施加对象或受影响对象时，先确定效果目标：已经指定受影响对象时使用该对象，未指定受影响对象但指定了施加对象时使用该施加对象，两者都未指定且运动可见实体集合非空时使用集合中对象编号最小的实体；两者都未指定且集合为空时，该效果缺少成立前提。取得效果目标后，缺少的施加对象或受影响对象分别使用该目标。已保留要求指定其他效果但没有提供施加对象或受影响对象时，该效果缺少成立前提。没有指定景深或运动效果时记录全部清晰，不加入背景虚化、运动模糊或速度线。
10. Skill 执行者检查第 1—9 项能否同时成立，并按照“每个候选必须确定的十项内容”第 10 条记录结果。

## 候选 B 和候选 C 的构造方法

候选 B 复制候选 A，依次检查“主景别、观察角度、POV、主体画面位置、前景中景背景、主焦点、遮挡与裁剪、景深与运动效果”。每个属性都按照阅读顺序逐格检查，并在当前画格内按照“有效备选值的固定顺序”扫描；当前画格没有有效备选值时继续检查下一个画格，当前属性的全部画格都没有有效备选值时继续检查下一个属性。候选 B 采用找到的第一个有效备选值后停止扫描。一次变更只改变当前画格的当前属性，其他画格和属性保持候选 A 的取值。Skill 执行者完成变更后，重新记录受该变更影响的第 1—10 项内容及每项取值的来源身份；十项内容和来源身份全部完成后，候选 B 构造完成。全部属性和画格都没有有效备选值时，执行“候选 B 或候选 C 不能成立”的结果。

候选 C 复制候选 A，依次检查“主体画面位置、前景中景背景、主焦点、遮挡与裁剪、景深与运动效果、主景别、观察角度、POV”。每个属性都按照阅读顺序逐格检查，并在当前画格内按照“有效备选值的固定顺序”扫描；当前画格没有有效备选值时继续检查下一个画格，当前属性的全部画格都没有有效备选值时继续检查下一个属性。候选 C 排除候选 A 和候选 B 已使用的八个逐画格取值序列组合，并采用固定顺序中第一个尚未使用的有效备选值。一次变更只改变当前画格的当前属性，其他画格和属性保持候选 A 的取值。Skill 执行者完成变更后，重新记录受该变更影响的第 1—10 项内容及每项取值的来源身份；十项内容和来源身份全部完成后，候选 C 构造完成。全部属性和画格都没有有效备选值时，执行“候选 B 或候选 C 不能成立”的结果。

## 候选检查、比较和唯一结果

Skill 执行者只把已经记录十项内容、每项取值的来源身份、全部已保留要求以及“无冲突”结果的候选 A、候选 B 和候选 C 带入本节。检查和比较过程不补写或改变候选内容。

Skill 执行者按照以下顺序筛选三个有效候选。前两项分别只保留该项计数最少的候选；只剩一个候选时立即选定，仍有两个或三个候选时继续比较下一项。

1. 每个画格分别统计必须可见但被遮挡或裁剪的主体、动作、身体部位、物件和固定环境对象；同一画格中的同一项同时被遮挡和裁剪时只计一项。总项数更少者优先。
2. 效果类型的来源身份是 Skill 执行者补充内容时，该效果实例属于候选自行加入的效果；已保留要求指定效果类型、但施加对象或受影响对象由 Skill 执行者计算得到时，不属于候选自行加入的效果。候选自行加入的效果按照“画格、效果类型、施加对象、受影响对象”四项组成的记录分别计数，四项中任一项不同即计为另一个效果实例。总项数更少者优先。
3. 完成前两项后仍有多个候选时，按照候选 A、候选 B、候选 C 的顺序选择排在最前的候选。

Skill 执行者记录被选候选的名称、十项内容以及每项取值的来源身份，并把这些记录交给后续画面设计和 WAI Prompt 位置映射。

## 无法构造三个有效候选时的结果

候选 A 的第 1—9 项在下列任一实际采用的取值不能成立时，执行“候选 A 不能成立”的结果：两个或更多已保留构图要求彼此冲突；分镜要求既没有明确画格数量，也没有两个或更多可分别识别的画格描述；画格名称、阅读顺序或逐格内容归属存在互相冲突的要求；候选 A 实际采用的第一人称 POV 没有主体或合格参照对象；实际采用的越肩 POV 没有主体或合格参照对象；实际采用的监视器画面没有摄像设备或拍摄对象；当前画格没有符合主场景内容匹配条件的对象或动作可作为主焦点；候选 A 的居中布局没有足够的未占用位置；对象关系图存在循环，或者已保留位置使任一对象关系不能成立；已保留要求指定的遮挡或裁剪没有给出相关可见实体的三个横向区域、受影响具体部分或相关主体的实际可见身体范围；已保留要求指定背景虚化、没有指定受影响对象并且当前画格没有最终记录为背景的可定位对象；已保留要求指定运动模糊或速度线、没有指定施加对象和受影响对象并且运动可见实体集合为空；必须可见的内容记录为不可辨认；必须完整可见内容没有完整呈现；已保留要求指定的列表外主景别、观察角度或 POV 缺少规定的派生信息；已保留要求指定的其他效果缺少施加对象或受影响对象；已保留要求指定的其他取值与候选其余第 1—9 项不能同时成立。Skill 执行者按照第 10 项定义的结构记录每个失败：两项要求不能同时成立时使用“已保留要求冲突”；实际采用值缺少对象或信息时使用“实际采用值缺少前提”；实际采用值没有满足可见性、完整性、空间关系或其他已保留要求时使用“实际采用值违反已保留要求”。Skill 执行者等待用户补充缺少内容、修改要求或取消要求；用户回复前停止构图选择。

候选 A 能够成立，但候选 B 或候选 C 在全部属性和画格中都没有有效备选值时，执行“候选 B 或候选 C 不能成立”的结果。Skill 执行者列出不能成立的候选、已经检查的画格和可变构图属性、每项备选值不能成立的具体原因，以及无法提供有效备选值的可变构图属性。Skill 执行者等待用户指定可以改变的已有构图要求；用户回复前停止构图选择。
