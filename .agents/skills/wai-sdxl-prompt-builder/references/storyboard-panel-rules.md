# 分镜规则

## 用途和读取时机

本文件规定 Skill Agent 如何设计多个画格，以及如何把画格之间的时间、状态、动作、镜头和因果关系映射到十五个 WAI Prompt 位置。

用户要求以下任一内容时，Skill Agent 必须在选定候选构图后读取本文件：

- 多个画格、漫画分格或并列画面；
- 同一主体的变化前后；
- 一个动作的多个阶段；
- 时间推进、状态对比或结果对比；
- 连续镜头、镜头切换或同一事件的多个视角。

本文件中的“画格”指最终画面中具有独立边界、独立镜头或独立时间状态的一个画面区域。

## 三个候选构图与画格的区别

构图决策阶段生成的候选 A、候选 B 和候选 C 是三套互相替代的完整方案，不是三个画格。

单幅请求中，每个候选包含一幅完整画面。分镜请求中，每个候选包含一套完整分镜；同一候选中的全部画格共同组成该候选方案。Skill Agent 比较并选定一个候选后，只继续设计被选中候选中的画格。

## 画格数量和画格关系

用户指定画格数量时，Skill Agent 必须采用该数量。用户只要求变化、过程或对比而没有指定数量时，Skill Agent 根据需要展示的不同状态确定画格数量。

每两个相邻画格之间必须至少具有一种明确关系：

- 时间关系：前一时刻与后一时刻；
- 动作关系：动作开始、动作进行或动作完成；
- 状态关系：变化前与变化后；
- 因果关系：原因与结果；
- 镜头关系：同一时刻的不同视角、景别或焦点；
- 空间关系：同一场景的不同区域或同时发生的不同位置。

## 每个画格必须确定的内容

Skill Agent 必须为每个画格分别确定：

1. 该画格中出现的主体及其身份。
2. 每名主体在该画格中的外貌和服装状态。
3. 每名主体的核心动作、动作目标、姿态和动作阶段。
4. 每名主体的表情、视线和对当前动作或结果的反应。
5. 该画格的景别、角度、POV、焦点、主体位置、景深、遮挡、裁剪和可见范围。
6. 该画格的地点、前景、中景、背景和环境状态。
7. 该画格的画面细节、整体情绪和需要显示的动作结果。
8. 该画格的光源、阴影、色彩、对比度和与相邻画格的光线连续或光线变化。
9. 该画格与前一画格、后一画格或并列画格之间的关系。

## 跨画格不变内容与变化内容

Skill Agent 必须先确定跨画格保持不变的内容，再确定每个画格发生变化的内容。

同一事件的连续画格通常保持以下内容不变：

- 角色身份；
- 没有发生变化的外貌特征；
- 没有换装、破损或状态变化的服装内容；
- 没有转移的关键道具；
- 没有切换的地点、时间和主要环境；
- 没有改变的画师和普通画面风格。

每个画格只改变该画格需要表达的动作阶段、姿态、表情、物体位置、服装状态、镜头、环境状态、画面细节或光线。变化必须能够指出具体主体和具体内容，例如“角色 A 从站立改为跪姿”或“法杖尖端从蓄力改为释放法焰”。

## 动作阶段与结果状态

动作过程包含多个画格时，Skill Agent 必须使每个画格显示一个明确阶段：

- 开始前：主体姿态、目标位置和环境条件已经能够说明即将发生的动作；
- 进行中：核心动作、动作方向、接触状态和主体反应清楚可见；
- 完成后：动作造成的位置、服装、道具、身体、环境或关系结果清楚可见。

用户只要求其中一个阶段时，Skill Agent 只设计该阶段。用户要求前后对比但不需要完整过程时，Skill Agent 可以省略中间阶段。

同一动作跨越多个画格时，动作主体和动作目标必须保持一致，除非画格明确显示目标转移、动作中断或新的主体接替动作。

## 镜头连续与镜头切换

同一事件使用连续镜头时，Skill Agent 必须说明相邻画格之间改变了哪一项镜头内容，例如：

- 从全身景推进到近景；
- 从正面改为侧面；
- 从第三人称视角改为越肩视角；
- 从角色 A 的动作焦点切换到角色 B 的反应焦点。

镜头位置或方向改变后，Skill Agent 必须重新判断画面左右位置、前后关系、遮挡、裁剪和可见范围。镜头变化不能沿用上一画格基于不同相机位置得出的空间方向。

## 时间、状态和因果表达

单个画格内部的主体状态进入相应的标签位置。两个或多个画格之间的时间、状态或因果关系由 `relation_narrative` 表达。

`relation_narrative` 必须明确指出涉及的画格和变化内容，例如：

- 第一格显示动作开始，第二格显示动作结果；
- 左侧画格显示变化前，右侧画格显示变化后；
- 上方画格中的事件导致下方画格中的状态；
- 两个画格显示同一时刻的不同视角。

如果面板顺序、箭头、分隔线或画面布局已经能够表达关系，`relation_narrative` 仍只补充标签和布局无法准确表达的时间、主体归属或因果内容。

## 十五位置映射

| 画格内容 | WAI Prompt 位置 |
|---|---|
| 画格中的主体数量和主体类别 | `subject` |
| 画格中的角色身份 | `character` |
| 画格中的外貌状态 | `appearance` |
| 画格中的服装及服装状态 | `outfit` |
| 画格中的姿态、核心动作、动作目标和动作阶段 | `action` |
| 画格中的表情、视线和反应 | `expression_reaction` |
| 画格布局、每格景别、角度、POV、焦点、主体位置、遮挡和裁剪 | `camera_composition` |
| 每格地点、前景、中景、背景和环境变化 | `environment` |
| 每格画面细节、整体情绪、动作结果和变化表现 | `detail_mood` |
| 每格光线以及跨格光线连续或光线对比 | `lighting` |
| 标签不能准确表达的画格顺序、时间关系、状态关系、因果关系和跨格主体归属 | `relation_narrative` |

## 完成检查

Skill Agent 必须在进入 Prompt 自检前确认：

- 候选构图与画格没有混为同一层级；
- 每个画格都具有明确的主体、状态、核心动作、动作目标、镜头、环境和光线；
- 每两个相邻画格之间具有明确的时间、动作、状态、因果、镜头或空间关系；
- 跨画格不变的角色身份、外貌、服装、道具和环境没有无故改变；
- 每项变化都指出具体主体和具体内容；
- 镜头变化后的左右位置、前后关系、遮挡、裁剪和可见范围已经重新判断；
- 前一画格没有提前出现后一画格才成立的结果；
- 后一画格保留了仍然存在的主体、道具和环境；
- `relation_narrative` 已经表达标签和画格布局无法准确表达的跨格关系。
