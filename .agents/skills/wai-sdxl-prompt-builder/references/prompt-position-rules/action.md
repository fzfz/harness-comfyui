# `action` 位置规则

## 用途和读取时机

本文件规定 Skill Agent 如何完成 `action` 位置。当前主场景、用户要求或跨位置配方需要说明姿态、动作、动作目标、接触、支撑、移动方向或身体朝向时，Skill Agent 必须读取本文件和[动作结构](../action-structure.md)。

`action` 的唯一职责由 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)统一定义。

## 每名主体的动作

Skill Agent 必须为每名参与动作的主体确定：

- 当前姿态；
- 一个核心动作；
- 动作目标；
- 身体、四肢、道具或效果的动作方向；
- 身体朝向和局部朝向；
- 接触点、支撑点或持有关系；
- 当前动作阶段；
- 动作造成的可见结果。

同一主体在同一画面或同一画格中只保留一个核心动作。局部动作、视线、道具运动和结果状态必须服务该核心动作。

## 多主体动作归属

画面包含多名主体时，Skill Agent 必须分别确定谁执行动作、动作指向谁、谁受到动作影响，以及双方各自的姿态和反应。

共享动作不能依靠无主语标签表示。标签不能准确表达动作主体和动作目标时，Skill Agent 在 `relation_narrative` 中写明动作归属。

## 动作与其他位置的边界

- 表情、视线和身体反应进入 `expression_reaction`。
- 道具、服装和穿着结果进入 `outfit`。
- 景别、相机角度、POV、画面位置和可见范围进入 `camera_composition`。
- 法术、冲击、烟尘或运动造成的画面效果进入 `detail_mood`。
- 动作造成的光源、阴影、色彩和对比度进入 `lighting`。

## 完成检查

Skill Agent 必须确认 `action`：

- 每个动作都具有明确主体；
- 需要动作目标的动作具有明确目标；
- 姿态、动作方向、身体朝向、接触和结果能够同时成立；
- 多主体动作不会交换主体和目标；
- 动作与选定镜头的可见范围一致；
- 标签无法准确表达的动作归属已经进入 `relation_narrative`。
