# `outfit` 位置规则

## 用途和读取时机

本文件规定 Skill Agent 如何完成 `outfit` 位置。当前主场景、用户要求或跨位置配方需要说明服装、配饰、穿着状态或随身物件时，Skill Agent 必须读取本文件。

`outfit` 的唯一职责由 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)统一定义。

## 每名主体的服装内容

Skill Agent 必须根据选定构图和可见范围，为每名主体确定：

- 服装种类和主要结构；
- 服装材质和颜色；
- 服装完整、敞开、脱下、破损、湿润、凌乱或其他当前状态；
- 鞋袜、手套、帽子、首饰和其他配饰；
- 武器、法杖、包、书、乐器或其他随身物件。

## 多主体归属

画面包含多名主体时，Skill Agent 必须把服装、配饰和随身物件分别对应到具体主体。不能使用一组共享服装内容让多名主体的穿着归属不明。

相同制服或相同装备可以作为共同内容，但每名主体的颜色差异、穿着状态、损坏状态或持有物仍必须能够与对应主体匹配。

## 与角色 Prompt 的关系

采用角色提示词后，Skill Agent 在 `outfit` 中只补充 Character 来源内容尚未准确表达的服装、配饰、随身物件或当前穿着状态。Skill Agent 不重复写入 Character 来源内容已经准确表达的服装。

用户本轮明确修改或排除角色服装时，Skill Agent 按照 [`character` 位置规则](character.md)处理 Character 来源内容，并把用户要求写入 `outfit`。

## 物件与动作的边界

物件本身及其外观进入 `outfit`；主体如何握持、使用、脱下、拉扯、交接或损坏该物件进入 `action`。动作完成后留下的服装状态仍进入 `outfit`。

例如，法杖的类型和外观进入 `outfit`，角色举起法杖进入 `action`；外套敞开的状态进入 `outfit`，角色正在脱下外套进入 `action`。

## 完成检查

Skill Agent 必须确认 `outfit`：

- 每件服装、配饰和随身物件都对应具体主体；
- 服装内容与镜头可见范围一致；
- 穿着状态与动作阶段和结果状态一致；
- 物件外观与物件使用动作没有混在同一位置；
- 没有重复角色提示词已经准确表达的服装、配饰或随身物件；
- 没有混入身体外貌、表情、镜头或环境内容。
