# `lighting` 位置规则

## 用途和读取时机

本文件规定 Skill Agent 如何完成 `lighting` 位置。当前主场景、用户要求、跨位置配方或选定候选构图需要说明光源、阴影、色彩或对比度时，Skill Agent 必须读取本文件。

`lighting` 的唯一职责由 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)统一定义。

## 光线设计

Skill Agent 必须根据主体位置、动作方向、主焦点、环境和时间确定：

- 主光源及其位置、方向和范围；
- 环境光、补光、轮廓光、道具光、法术光或其他次要光源；
- 阴影方向、软硬和覆盖范围；
- 画面主要色彩、光色和色温关系；
- 明暗对比、色彩对比和主体与背景的分离方式。

## 主体、动作和环境

光线必须让主焦点、主体轮廓、动作路径、接触关系和前中后景清楚可见。动作或道具自身发光时，Skill Agent 必须确定该光源如何照亮主体、目标和附近环境。

环境中的太阳、月亮、窗户、灯具、火焰或显示屏作为具体对象进入 `environment`；这些对象产生的照明结果进入 `lighting`。

## 多画格处理

分镜请求必须明确各画格的光线保持连续，或者通过光源、色彩和对比度的有意变化显示时间、状态或情绪差异。镜头切换不能造成没有画面依据的光线方向变化。

## 位置边界

- 媒介质感、摄影效果、数字效果、运动表现和整体画面情绪进入 `detail_mood`。
- 普通画风和媒介风格进入 `non_artist_style`。
- 时间、天气和具体发光对象进入 `environment`。

## 完成检查

Skill Agent 必须确认 `lighting`：

- 每个主要光源具有明确来源或画面依据；
- 阴影方向与光源位置一致；
- 色彩和对比度服务主焦点和空间层次；
- 发光动作或道具对主体和环境产生可见影响；
- 多画格的光线连续或变化具有明确原因；
- 没有混入媒介质感、摄影效果、整体情绪或普通画风。
