# `expression_reaction` 位置规则

## 用途和读取时机

本文件规定 Skill Agent 如何完成 `expression_reaction` 位置。当前主场景、用户要求或跨位置配方需要说明表情、视线或身体反应时，Skill Agent 必须读取本文件。

`expression_reaction` 的唯一职责由 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)统一定义。

## 每名主体的表情和反应

Skill Agent 必须根据该主体的身份、核心动作、动作阶段和当前处境确定：

- 面部表情；
- 眼睛睁闭状态和视线目标；
- 头部朝向与视线方向的关系；
- 紧绷、放松、颤抖、退缩、僵住或其他身体反应；
- 对另一名主体、动作目标、环境事件或动作结果的即时反应。

## 多主体归属

画面包含多名主体时，Skill Agent 必须分别设计每名主体的表情、视线和身体反应。不同主体不能共享一组无法判断归属的反应内容。

主体之间存在对视、回避视线、观察或被观察关系时，Skill Agent 必须明确视线主体和视线目标。标签不能准确表达视线关系时，在 `relation_narrative` 中补充。

## 与动作的边界

`action` 表达主体主动完成的姿态、动作和身体朝向；`expression_reaction` 表达主体对当前动作、目标或结果产生的表情、视线和身体反应。

身体反应导致明确的新姿态或位移时，新姿态和位移进入 `action`；反应的情绪和身体状态仍进入 `expression_reaction`。

## 完成检查

Skill Agent 必须确认 `expression_reaction`：

- 每项表情、视线和身体反应都对应具体主体；
- 反应与该主体的动作、目标和当前阶段一致；
- 视线方向与头部朝向和相机可见范围一致；
- 多主体的反应没有互相交换；
- 没有把整体画面情绪、镜头效果或光线内容写入本位置。
