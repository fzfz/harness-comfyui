# `environment` 位置规则

## 用途和读取时机

本文件规定 Skill Agent 如何完成 `environment` 位置。当前主场景、用户要求、跨位置配方或选定候选构图需要说明地点、空间结构、时间、季节、天气或环境对象时，Skill Agent 必须读取本文件。

`environment` 的唯一职责由 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)统一定义。

## 场景内容

Skill Agent 必须根据选定构图确定：

- 具体地点；
- 室内、室外或跨越内外边界的空间结构；
- 前景、中景和背景中的环境对象；
- 与主体动作直接相关的地面、家具、建筑、门窗、容器或其他支撑条件；
- 时间、季节和天气；
- 用户要求的环境变化或环境事件。

## 环境与主体动作

环境必须能够容纳画面中的主体数量、动作范围、道具、相机位置和可见范围。动作依赖墙面、地面、桌椅、门窗、水面或其他环境对象时，`environment` 必须包含对应对象。

环境对象本身进入 `environment`；主体如何接触、跨越、倚靠、坐在或站在该对象上进入 `action`。

## 纯环境画面

环境叙事主场景可以不包含主体。纯环境画面使用 `camera_composition` 确定镜头与空间层次，使用 `environment` 确定地点和环境对象，使用 `detail_mood` 与 `lighting` 完成画面表现。

## 位置边界

- 相机位置、景别、焦点、主体布局、遮挡和裁剪进入 `camera_composition`。
- 雨、雪、雾、风、云层和其他实际天气或环境状态进入 `environment`。
- 天气或环境造成的运动表现、摄影效果和整体情绪进入 `detail_mood`。
- 光源、阴影、色彩和对比度进入 `lighting`。

## 完成检查

Skill Agent 必须确认 `environment`：

- 地点和空间结构具体明确；
- 环境对象能够支撑主体动作和相机位置；
- 前中后景中的环境对象与选定构图一致；
- 时间、季节和天气没有互相冲突；
- 没有把相机属性、主体动作、整体情绪或光线内容写入本位置。
