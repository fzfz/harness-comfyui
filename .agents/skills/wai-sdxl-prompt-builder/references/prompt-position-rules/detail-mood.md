# `detail_mood` 位置规则

## 用途和读取时机

本文件规定 Skill Agent 如何完成 `detail_mood` 位置。当前主场景、用户要求或跨位置配方需要说明媒介质感、摄影效果、数字效果、运动表现或整体画面情绪时，Skill Agent 必须读取本文件。

`detail_mood` 的唯一职责由 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)统一定义。

## 选择画面细节和整体情绪

Skill Agent 按照 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)确定位置归属，再根据选定构图、主体动作、环境和画面目的选择本位置实际需要的内容：

- 纸张、胶片、颗粒、笔触或其他可见媒介质感；
- 景深之外的摄影表现、镜头污渍、散景形态或其他摄影效果；
- 色散、故障、扫描线、叠影或其他数字效果；
- 与主体动作一致的运动表现；
- 紧张、宁静、压迫、欢快、梦幻或其他整体画面情绪。

## 与普通画风的边界

`non_artist_style` 表达画面采用哪一种非画师画风或媒介风格；`detail_mood` 表达该画面实际显示的质感、效果、运动表现和整体情绪。

同一内容不能同时作为风格名称写入 `non_artist_style`，又作为同义画面效果写入 `detail_mood`。Skill Agent 必须根据该内容在当前画面中的实际作用选择一个位置。

## 与光线的边界

光源、阴影、色彩和对比度只进入 `lighting`。`detail_mood` 可以表达由完整画面产生的情绪，但不能用情绪词代替具体光线设计。

例如，“压迫感”进入 `detail_mood`；形成压迫感的低位光源、深阴影、冷色和高对比度进入 `lighting`。

## 多画格处理

分镜请求必须分别确定各画格的画面细节和情绪是否保持连续、逐步变化或形成对比。跨画格关系无法通过各格标签准确表达时，Skill Agent 在 `relation_narrative` 中补充。

## 完成检查

Skill Agent 必须确认 `detail_mood`：

- 每项内容属于媒介质感、摄影效果、数字效果、运动表现或整体画面情绪；
- 内容服务选定构图和当前画面目的；
- 没有重复 `non_artist_style` 中的普通画风或媒介风格；
- 没有混入光源、阴影、色彩或对比度；
- 没有使用整体情绪替代具体主体的表情和反应。
