# 动作结构

## 用途和读取时机

本文件负责明确每个动作由谁执行、指向谁、如何发生、由什么支撑、产生什么可见结果，以及镜头和环境如何显示该动作。

当前画面包含姿态、动作、动作目标、身体接触、支撑关系、动作阶段或结果状态时，Skill Agent 在完成选定构图后、映射 WAI Prompt 位置前读取本文件。

## 基础动作关系

每个动作按照以下顺序理解：

`动作主体 → 核心动作 → 动作目标 → 姿态 → 局部动作 → 视线 → 身体朝向 → 接触与支撑 → 结果状态 → 镜头可见内容 → 场景支撑条件 → relation_narrative`

- 动作主体：执行核心动作的具体主体。
- 核心动作：当前画格首先需要辨认的一个动作。
- 动作目标：动作指向的人、物件、身体部位、位置或环境对象；没有目标的动作写明“不适用”。
- 姿态：站、坐、跪、躺、悬空、俯身或其他承载动作的全身状态。
- 局部动作：与核心动作同时发生的头部、手部、腿部、躯干或道具动作。
- 视线：主体看向镜头、动作目标、其他主体、画外或闭眼。
- 身体朝向：主体正面、侧面、背面以及主体之间的相对朝向。
- 接触与支撑：接触主体、接触目标、接触部位、接触方式、支撑主体和支撑面。
- 结果状态：当前画格已经能够看见的姿态、表情、服装、物件或环境变化。
- 镜头可见内容：动作主体、目标、关键部位、接触、支撑和结果中必须出现在画面里的内容。
- 场景支撑条件：动作需要的空间容量、地面、墙面、家具、道具和环境位置。

## 单主体、双主体和多主体

| 主体数量 | 需要明确的动作内容 |
|---|---|
| 单主体 | 唯一动作主体、一个核心动作、动作目标或不适用、姿态、局部动作、视线、身体朝向、当前结果、镜头可见内容和场景支撑条件。 |
| 双主体 | 两名主体各自的身份锚点；每个动作的主体、目标、接触部位、支撑关系；双方姿态、视线、朝向、反应和镜头可见内容。 |
| 多主体 | 精确主体数量；每名主体各自的身份锚点、动作身份、动作目标、接触或支撑关系、姿态、视线、朝向、反应和画面位置；能够容纳全部主体的共享镜头和场景。 |

双主体和多主体先分别完成每名主体的动作归属，再合并共享镜头和环境。

## 同一主体的多个动作

单幅画面为同一主体选择一个核心动作。与核心动作同时发生且物理兼容的动作作为局部动作或结果状态。例如，“角色奔跑时回头挥手”以奔跑为核心动作，回头和挥手为局部动作。

前后连续发生的动作使用多个画格，每个画格分别设置一个核心动作。动作并发或先后关系无法由标签准确表达时，使用 `relation_narrative`。

## 动作内容到 WAI Prompt 位置的映射

| 动作内容 | WAI Prompt 位置 |
|---|---|
| 主体数量、主体类别和组合关系 | `subject` |
| 角色身份 Prompt | `character` |
| 每名主体的稳定外观锚点 | `appearance` |
| 服装、穿着状态、配饰和随身物件 | `outfit` |
| 动作主体、核心动作、目标、姿态、局部动作、方向、朝向、接触和支撑 | `action` |
| 表情、视线和身体反应 | `expression_reaction` |
| 景别、角度、POV、主体位置、焦点、裁剪、遮挡和关键部位可见范围 | `camera_composition` |
| 地点、支撑面、空间容量、道具位置和环境状态 | `environment` |
| 运动表现、摄影效果和整体画面情绪 | `detail_mood` |
| 光源、阴影、色彩和对比度 | `lighting` |
| 标签无法准确表达的动作归属、主体关系、空间关系、画格关系和时间关系 | `relation_narrative` |

结果状态按照实际改变的画面对象进入对应位置：姿态和动作变化进入 `action`，表情和身体反应进入 `expression_reaction`，服装和随身物件变化进入 `outfit`，环境变化进入 `environment`。

## 动作类型需要补充的内容

| 动作类型 | 除基础动作关系外需要明确的内容 |
|---|---|
| 单人展示姿态 | 眼神、口唇、手部、身体姿态、服装互动、辅助道具和展示方向。 |
| 单人暴露或露出 | 动作诱因、可见部位、地点、结果状态和观看渠道。 |
| 单人自慰 | 动作目标、工具、姿态、支撑面、视线和当前阶段。 |
| 单人隐秘展示、自拍或直播 | 展示部位、展示方式、观看媒介、辅助道具、情绪、空间和观察方向。 |
| 双人口部动作 | 执行者、目标、深度阶段、双方姿态、支撑动作、双方反应和镜头焦点。 |
| 双人足部动作 | 足部所属主体、动作目标、足部支撑、另一主体姿态、反应和道具。 |
| 双人腿部夹持动作 | 双方腿部姿态、接触关系、支撑关系、材质状态和场景。 |
| 双人手部动作 | 手部所属主体、动作目标、另一只手的支撑、双方姿态和结果位置。 |
| 双人胸部与躯干动作 | 接触者、目标、接触部位、躯干朝向、手势、双方反应和服装状态。 |
| 双人调戏或触碰 | 动作主体、动作目标、接触方式、双方反应、观看关系和空间关系。 |
| 双人面对面躺姿 | 上方主体、下方主体、腿部姿态、支撑、抓握、面对方向和景别。 |
| 双人站立姿态 | 支撑方式、面对方向、重心、墙面或其他支撑面和全身可见范围。 |
| 双人坐姿 | 坐姿主体关系、面对方向、道具归属、遮挡、共享场景和可见范围。 |
| 双人前后姿态 | 前后位置、动作主体、动作目标、支撑主体、身体朝向、速度阶段和镜头方向。 |
| 双人悬空携带姿态 | 携带者、被携带者、抱持方式、离地状态、面对方向、力量表现和全身可见范围。 |
| 双人全身覆盖姿态 | 覆盖者、被覆盖者、腿部支撑、覆盖程度、结果状态和俯视焦点。 |
| 双人骑乘姿态 | 上方主体、下方主体、面对方向、支撑关系、主导动作、观察角度和速度阶段。 |
| 特殊状态与主导关系变化 | 当前状态、动作主体、动作目标、反应、身体反应、前后差分和镜头变化。 |
| 多主体动作 | 精确人数、每名主体的动作身份、目标、等待或协作关系、结果状态和全员镜头。 |
| 双女性互动 | 两名主体的独立身份、互相动作、姿态、道具、第三主体关系、双方反应和交错构图。 |

## 动作阶段、反应和结果

- 动作阶段：确定当前画格展示动作开始、进行、完成或结束后的哪个阶段。
- 反应联动：每名主体的表情、视线和身体反应与该主体当前承受或执行的动作阶段一致。
- 镜头联动：动作阶段改变时，重新确认关键接触、动作目标、可见范围、景别和主焦点。
- 结果归属：明确结果由谁产生、作用于谁或落在什么环境表面，并让镜头显示用户要求的结果。
- 前后差分：动作跨越两个以上阶段时，按照 [分镜规则](storyboard-panel-rules.md)分别设计每个画格。

## `relation_narrative` 使用条件

视觉标签能够准确表达单项动作、姿态、表情、镜头或环境时，使用对应标签。标签无法准确表达动作主体与目标、接触与支撑、主体相对位置、并发关系、时间顺序、画格关系或因果关系时，使用位于全部标签之后的简洁英文关系句。
