# Prompt 冲突规则

## 用途和读取时机

本文件规定 Skill Agent 如何处理本轮十五位置内容之间不能同时成立的要求。

Skill Agent 完成 [Prompt 自检](prompt-self-check.md)后必须完整读取并执行本文件。发现冲突时，Skill Agent 返回定义相关内容的场景分支、构图、画面设计、动作、空间、分镜、画师或位置规则修改内容，然后重新执行 Prompt 自检和本文件。

## 冲突处理顺序

Skill Agent 必须按照以下顺序决定保留内容：

`用户本轮意图 > UI 已选内容 > 语义工具结果 > Skill Agent 自主设计内容`

同一优先级的两项内容不能同时成立时，Skill Agent 根据用户画面目的、选定构图和完整画面设计保留能够形成连贯画面的内容。

## 主体与角色冲突

- 主体数量与构图中的实际主体数量不一致时，修改 `subject` 或构图，使两者一致。
- 两个角色内容被分配给同一主体，但用户没有要求身份融合或变化时，保留符合采用优先级的角色内容。
- 同一角色在多个位置出现不兼容的外貌或身份特征时，保留符合采用优先级和当前可见状态的内容。

## 外貌与服装冲突

- 用户本轮明确修改或排除 Character 来源内容中的外貌或服装时，Skill Agent 按照 [`character` 位置规则](prompt-position-rules/character.md)处理该冲突。
- 同一身体部位具有互相排斥的外貌内容时，保留符合采用优先级的内容。
- 同一件服装同时被描述为完整穿着、脱下和不存在时，根据当前动作阶段保留一个能够成立的状态。
- 服装状态与镜头可见范围不一致时，修改服装内容或镜头，使画面能够显示用户要求的状态。

## 动作与反应冲突

- 同一主体同时执行无法在当前姿态中完成的核心动作时，保留一个核心动作，把其他内容改为局部动作、前后阶段或删除。
- 动作目标、接触点、支撑点或持有关系互相矛盾时，按照动作结构重新确定主体、目标和方向。
- 表情、视线或身体反应与当前动作阶段不一致时，修改反应或动作阶段。

## 镜头与空间冲突

- 景别无法容纳用户要求的主体、动作或环境时，修改用户未锁定的镜头属性。
- 同一主体相对同一目标同时位于互相排斥的左右、前后、上下、内外或远近位置时，按照最终相机位置保留一个关系。
- 主体被完全遮挡或完全出画，却又被描述为完整可见时，修改遮挡、裁剪或可见范围。
- POV、相机角度和画面中的相机位置不能同时成立时，返回构图决策重新选择候选。

## 环境、时间和光线冲突

- 地点、时间、季节或天气不能共同成立时，保留符合采用优先级和画面目的的组合。
- 光源位置与阴影方向不一致时，修改 `lighting`。
- 画面色彩、对比度或光线变化与分镜时间关系不一致时，修改各画格光线或跨格关系。

## 画师与普通风格冲突

- 多个画师方向不能共同形成目标画面时，按照画师采用规则重新比较候选或减少采用画师。
- 普通画风、媒介风格、摄影效果和光线互相排斥时，根据各内容在完整画面中的职责保留能够共同成立的组合。
- 用户明确排除的画师或风格重新出现在 UI 选择、语义结果或自主设计内容中时，删除被排除内容。

## 关系短句冲突

- `relation_narrative` 与标签表达不同主体、动作目标、空间位置或画格顺序时，返回产生冲突的具体规则修改内容。
- `relation_narrative` 重复标签已经准确表达的内容时，删除重复短句内容。
- `relation_narrative` 没有明确主体或目标时，改写为能够唯一确定关系的完整英文短句。

## 完成条件

所有位置内容能够同时成立，且 `relation_narrative` 与前十四个位置一致时，冲突处理完成。
