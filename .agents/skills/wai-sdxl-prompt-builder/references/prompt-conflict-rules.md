# WAI Prompt 冲突处理

## 执行顺序与完成条件

1. Skill 执行者先把本轮采用的全部输入内容写入对应 Prompt 位置，再按照本文件的章节顺序检查并处理冲突。每次删除、改写或移动 Prompt 内容后，Skill 执行者从“冲突判断和来源优先级”开始重新检查全部十五个 Prompt 位置。仅当全部 Prompt 内容能够同时成立，并且 `relation_narrative` 与其他十四个 Prompt 位置一致时，冲突处理完成；Skill 执行者随后执行权重设计。

## 冲突判断和来源优先级

1. 两个或多个 Prompt 内容无法在同一画格、同一主体状态或同一环境状态下同时成立时，这些内容互相冲突。冲突包括同一属性具有互斥取值，以及身份、外貌、服装、动作、反应、位置、环境状态、光线或风格之间形成互斥约束。能够同时成立的补充描述全部保留。

2. Skill 执行者按 [SKILL.md 第 1 节第 3 项](../SKILL.md#1-读取本轮输入)的来源优先级处理冲突。

3. 同一最高优先级仍有互斥内容时，列出内容、来源、冲突属性和可保留组合，请用户选择或修订。收到回复前，停止本次构造。
4. 用户回复后，采用选定或修订的内容，处理其余冲突，再从本节开始检查全部位置。
5. 内容重复或语义相同时，只保留来源优先级最高的一项。

## 主体与角色冲突

1. `subject` 中的主体总数与 `camera_composition` 安排的主体数量不一致时，Skill 执行者按照来源优先级保留主体数量，并修改另一位置中的主体数量和主体安排。
2. 两个角色 Prompt 被分配给同一主体时，Skill 执行者先检查当前用户消息是否要求身份融合或身份变化。当前用户消息要求身份融合或身份变化时，Skill 执行者保留相应角色内容并写明身份关系或变化结果。当前用户消息将两个角色描述为不同主体时，Skill 执行者把两个角色 Prompt 分别分配给对应主体，并同步修改 `subject` 和 `camera_composition` 中的主体数量与安排。两个互斥角色 Prompt 确实竞争同一主体身份时，Skill 执行者按照来源优先级保留一个角色 Prompt，并删除或改写另一个角色 Prompt。
3. 同一主体在 `character`、`subject` 或 `appearance` 中具有互相冲突的身份或外貌时，Skill 执行者按照来源优先级保留一项身份或外貌，并修改其他位置中的冲突内容。

## 外貌与服装冲突

1. 用户修改角色外貌或服装时，按 [Character 来源内容](wai-prompt-position-order.md#character-来源内容)处理。
2. 同一主体的同一身体部位具有互相冲突的外貌描述时，Skill 执行者按照来源优先级保留最高优先级描述，并删除或改写其他冲突描述，使该身体部位只包含能够同时成立的外貌内容。
3. 同一件服装在同一画格中同时被描述为完整穿着、部分穿着、脱下或不存在时，Skill 执行者按照来源优先级保留最高优先级的服装状态，并删除或改写其他冲突状态，使该服装在该画格中只有一个最终状态。
4. 用户要求入画的外貌或服装超出取景范围或被遮挡时，按“镜头与空间冲突”第 1 项处理。

## 动作、反应和主体关系冲突

1. 同一主体的两个核心动作无法在同一姿态中同时完成时，Skill 执行者按照来源优先级保留一个核心动作。另一个动作能够由该主体的局部肢体同时完成时，Skill 执行者将它改写为局部动作；该动作属于分镜中的其他画格时，Skill 执行者将它移至对应画格；其他情况下，Skill 执行者删除该动作。
2. 动作执行主体、动作对象、接触部位、支撑部位、持有物或运动方向的描述互相冲突时，Skill 执行者按照来源优先级逐项保留能够同时成立的描述，并删除或改写其余冲突描述，使每个动作中的执行主体、动作对象、接触部位、支撑部位、持有物和运动方向彼此一致。
3. `expression_reaction` 中的表情、视线或身体反应与 `action` 中的动作阶段无法同时成立时，Skill 执行者按照来源优先级保留一项内容，并修改优先级较低的反应或动作阶段，使两项内容能够同时成立。
4. 主体关系对动作执行主体或动作对象的描述与 `action` 中的对应描述冲突时，Skill 执行者按照来源优先级保留优先级较高的描述，并修改优先级较低的主体关系、动作执行主体或动作对象，使主体关系与动作角色一致。

## 镜头与空间冲突

1. 取景或遮挡不能呈现用户要求的可见内容时，先调整用户未要求固定的镜头属性。仍无法呈现时，将可见要求、固定镜头要求与遮挡组成冲突组，按“冲突判断和来源优先级”处理。

2. 同一主体相对同一目标同时具有互相冲突的左右、前后、上下或远近关系时，Skill 执行者把这些空间关系与相关相机位置、相机朝向和主体位置作为一个冲突组，并按照来源优先级确定保留内容。空间关系的优先级较高时，Skill 执行者只修改优先级较低的相机位置、相机朝向或主体位置；镜头或主体位置的优先级较高时，Skill 执行者删除或改写优先级较低的空间关系。
3. 同一主体或环境对象同时具有互相冲突的内外关系或包含关系时，Skill 执行者把这些空间关系与相关空间结构和对象位置作为一个冲突组，并按照来源优先级确定保留内容。空间关系的优先级较高时，Skill 执行者只修改优先级较低的 `environment` 空间结构或对象位置；空间结构或对象位置的优先级较高时，Skill 执行者删除或改写优先级较低的空间关系。
4. 主体被描述为可见，同时又被描述为完全遮挡或完全位于取景范围外时，Skill 执行者按照来源优先级确定最终可见状态。最终状态为可见时，Skill 执行者只修改优先级较低的遮挡物位置、裁剪范围或主体位置，使主体进入取景范围且不被完全遮挡。最终状态为不可见时，Skill 执行者删除或改写优先级较低的可见描述。
5. POV、相机角度和相机位置无法同时成立时，Skill 执行者把三项内容作为一个冲突组，并按照“冲突判断和来源优先级”处理；Skill 执行者只修改来源优先级较低的冲突内容，使最终保留的 POV、相机角度和相机位置能够同时成立。

## 环境、时间和光线冲突

1. 地点、时间、季节或天气无法同时成立时，Skill 执行者按照来源优先级保留最高优先级内容，并修改或删除其他冲突内容，直至四类内容能够同时成立。
2. `lighting` 中的光源位置与阴影方向冲突时，Skill 执行者按照来源优先级保留光源位置或阴影方向。保留光源位置时，Skill 执行者修改阴影方向，使阴影从受光物体向背离光源的位置延伸；保留阴影方向时，Skill 执行者修改光源位置，使光源位于阴影延伸方向的相反一侧。
3. 分镜中某个画格的色彩、明暗对比或光线与该画格标明的时间冲突时，Skill 执行者按照来源优先级保留时间或光线内容，并修改优先级较低的内容，使该画格的时间与光线能够同时成立。

## 画师与其他视觉内容冲突

1. 多个画师的 `style_description` 对同一视觉属性提出互斥要求时，将对应画师组成冲突组，按“冲突判断和来源优先级”处理。
2. 冲突处理后未保留的画师，删除其 `artist` 元素。`style_description` 只用于判断冲突，内容保持不变。

## `relation_narrative` 冲突

1. `relation_narrative` 与其他十四个 Prompt 位置对主体、动作对象、空间位置或画格顺序的描述冲突时，Skill 执行者按照来源优先级保留优先级较高的内容，并修改优先级较低的关系短句或其他 Prompt 位置中的冲突内容，使两处描述一致。
