# 画师画风查询预置词

## 用途

本文件为未指定具体画师的 Style 查询目标提供稳定的视觉描述词。画师方向设计和候选采用由[画师采用规则](artist-adoption.md)规定。

## 线条与渲染

可用查询词：`极简细线`、`带色纤细线稿`、`纤细线稿`、`纤细平面化线条`、`利落彩色线稿`、`深色彩线`、`色偏移线稿`、`无轮廓色块`、`平滑无笔触`、`半厚涂水彩`、`厚涂写实肌理`、`写实油画笔触`、`素描/涂鸦质感`、`商业赛璐璐`、`进阶赛璐璐`、`韩系半写实`、`概念艺术风格`、`印象派光影`。

## 色彩

可用查询词：`高明度高纯度`、`低饱和度`、`高饱和`、`糖果色`、`马卡龙色`、`莫兰迪色背景`、`冷灰蓝绿空气感`、`冷暖对比`、`冷暖邻近色`、`青蓝樱粉对比`、`紫黑白冷调`、`靛青暖金碰撞`、`粉紫白冷暖调`、`极光色`、`虹彩撞色`、`荧光补色`。

## 光影

可用查询词：`极致逆光`、`强逆光`、`柔和光晕`、`丁达尔空气感`、`边缘光`、`水波焦散`、`窗影体积感`、`百叶窗切光`、`次表面散射温暖光`、`黄金时刻侧光`、`单侧强光源`、`电影氛围光`、`漫反射`、`光晕（Bloom）`、`色散边缘溢光`。

## 材质与画面质感

可用查询词：`玻璃质感`、`透明材质`、`水体丝绸金属质感`、`金属晶体反光`、`丝绸液体质感`、`手工颗粒感`、`胶片质感`、`厚涂肌理`、`陶瓷通透肌`、`果冻釉面质感`、`液体折射`、`玻璃金属般的透明感`。

## 镜头与构图表现

可用查询词：`大景深广角透视`、`鱼眼广角`、`生活化 POV`、`极深远景纵深`、`高俯仰角`、`对角线构图`、`中心肖像景深`、`大角度斜构图`、`大透视动态`、`仰角广角`、`电影级广角风景`、`近景俯视`、`第一人称视角`、`强景深`、`大景小人`、`大量留白`、`重装饰满溢构图`、`互动 POV`。

## 整体观感与叙事气质

可用查询词：`治愈梦幻`、`华丽商业感`、`唯美湿润梦幻`、`治愈清新`、`清冷病娇`、`私密慵懒色气`、`青春忧郁`、`废墟美学`、`静默史诗`、`神圣感`、`颓废唯美`、`现代潮流商业插画感`、`清凉梦幻`、`梦幻甜美治愈`、`电影感叙事`、`生活化叙事`、`意识流`、`富有诗意的氛围`、`非常舒适的氛围`。

## 人物造型表现

可用查询词：`极幼 2—3 头身`、`圆脸大眼`、`九头身修长`、`极简幼态五官`、`写实骨骼肌肉`、`巨瞳多层虹膜`、`宝石瞳`、`纤细少女`、`圆润关节`、`写实渲染混幼态造型`。

## 题材与装饰方向

可用查询词：`幻想哥特`、`赛博军事`、`赛博冷色调`、`医疗宗教符号`、`古典主义`、`波普故障`、`传统与奇幻结合`、`赛博幻想`、`现代战术与机能风`、`赛博霓虹`、`现代波普`、`花卉纹理`、`几何秩序`、`复杂服饰建筑纹理`、`时尚军事`、`亚文化`、`水下梦幻感`。

- `厚涂肌理，冷灰蓝绿空气感，极深远景纵深，废墟美学，神圣感`

- `低饱和度，柔和光晕，平滑无笔触，生活化 POV，非常舒适的氛围`
