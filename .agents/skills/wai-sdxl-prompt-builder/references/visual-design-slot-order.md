# 画面设计检查顺序

## 用途和读取时机

本文件负责检查选定构图是否具备生成完整画面所需的信息。它规定检查顺序和每一步需要明确的画面内容。

Skill Agent 从三个候选构图中选出唯一构图后、映射 WAI Prompt 位置前读取本文件。

## 检查顺序

### 1. 主体数量和主体类别

明确画面中的主体总数，以及每名主体属于人物、动物、非人主体、物件或其他用户指定类别。多人或多物体画面分别确认每个主体。

### 2. 主体身份

明确每名主体是否为用户指定角色、作品中的角色、原创主体或没有专名的普通主体。用户只提供作品时，角色名称在后续语义查询阶段取得。

### 3. 外貌

分别明确每名主体需要显示的头发、眼睛、脸部、体型、肤色、标记和非人特征。选定构图裁掉某个部位时，只设计镜头中能够显示的外貌内容。

### 4. 服装和随身物件

分别明确每名主体的服装、材质、颜色、穿着状态、配饰和随身物件。服装和物件状态与当前动作阶段保持一致。

### 5. 动作

明确每个动作的执行主体、核心动作、动作目标、姿态、局部动作、动作方向、身体朝向、接触、支撑和当前结果。具体处理方式由 [动作结构](action-structure.md)定义。

### 6. 表情、视线和身体反应

分别明确每名主体的表情、视线目标和身体反应，并使其与该主体的动作和当前结果一致。

### 7. 镜头与构图

使用选定构图已经确定的主景别、观察角度、POV、视点位置、主焦点、主体位置、前中后景、遮挡、裁剪、可见范围、景深和运动效果。

### 8. 环境

明确地点、空间结构、时间、季节、天气、支撑面、环境道具和空间容量。环境必须能够容纳全部主体、动作和镜头范围。

### 9. 画面细节与整体观感

明确媒介质感、摄影效果、数字效果、运动表现和整幅画面的情绪。该步骤处理画面表现，不承担主体身份、动作归属或光源设计。

### 10. 光线

明确主光、补光、轮廓光、阴影、色彩和对比度。光线与时间、天气、环境结构、主体位置和动作效果保持一致。

### 11. 关系补充

检查标签能否准确表达动作主体与目标、主体关系、空间关系、画格关系、时间关系和因果关系。标签不能准确表达的关系在后续映射到 `relation_narrative`。

## 检查结果

完成检查后，Skill Agent 得到一份与选定构图一致的完整画面设计。已有内容直接进入 WAI Prompt 位置映射；需要角色、画师或规范视觉标签的内容在后续语义查询阶段取得。
