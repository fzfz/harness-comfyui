# 游戏服装多样性库（Game Clothing Diversity Library · 50 款）

> **用途**：为 anime 少女角色提示词工程技能「本技能」（ComfyUI Krea2 / 动漫风格 / 动作迁移源图）提供跨国产二次元/国风/女性向游戏的**女性服装原型参考**，突破「只会写实常服」的局限，让生成的年轻少女角色在服装、背景、颜色上更丰富多样。
>
> **构建方式**：基于 WebSearch + WebFetch 对 50 款国内流行手游/网游逐一检索（萌娘百科、BWIKI、灰机 wiki、官方设定集、17173、百度百科等），每条目均锚定真实角色与公开资料，未虚构服饰。
>
> **如何与 本技能 配合**：
> 1. 先按下方分类或正文选「游戏原型锚点」（如「战舰少女R 泳装+和风」「物华弥新 青铜纹古风」「剑网3 七秀水袖」）。
> 2. 叠加具体 descriptor：材质（蕾丝/皮革/金属/薄纱/丝绸）、配饰（金铃/锁链/羽织/舰装/假面/发簪）、发型（双卷/马尾/紫长发/恶魔角/岛田髷）、色板（蓝白/黑红/粉紫/青绿）。
> 3. 套用本技能 的 Route B 动作迁移铁律（垂直 T-pose、双脚并拢、鞋履四要素入镜、头≤25%、腿≥60%、8 词防切）生成全身立绘。
>
