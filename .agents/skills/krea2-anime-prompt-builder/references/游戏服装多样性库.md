# 游戏女性服装原型和色板

## 选择和组合服装原型

用户明确指定本文件中的游戏或女性角色时，Skill 执行者采用对应条目的服装原型。用户只指定服装题材时，Skill 执行者从题材相同的条目中选择一个服装原型作为主体服装。

每个服装原型只提供服装形制、服装部件、材质、穿戴配饰和颜色。角色名称只用于定位服装原型；用户没有指定该角色时，Skill 执行者不把角色名称或身份写入 Prompt。Skill 执行者先采用一个完整服装原型，再从同一条目的其他原型中选择最多两个与主体服装材质和颜色兼容的服装细节。用户明确指定的服装、材质、配饰或颜色替换对应预设内容。
