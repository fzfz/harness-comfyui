# 背景多样性库（Background Diversity Library · 本技能 配套）

> **用途**：为 anime 少女角色提示词工程技能「本技能」（ComfyUI Krea2 / 动漫风格 / **动作迁移源图**）提供**背景多样性**参考。
> **核心约束（用户确认）**：你生成的图**直接就是迁移用到的底图**——背景既要多样，又必须保证动作迁移时姿态/轮廓可干净分离或被替换。
>
> **构建方式**：基于 WebSearch + WebFetch 对 50 款国内流行手游/网游逐一检索场景美术（官方资料站、BWIKI、灰机 wiki、美术分析长文），加上 Danbooru 通用背景 tag 常识。每条目均锚定真实游戏场景，未虚构。

## 〇、迁移安全度分级（选背景的铁律）

| 等级 | 含义 | 对迁移的影响 | 用法 |
|------|------|------------|------|
| 🟢 **安全** | 纯色/渐变/虚化/留白/低对比/单一室内 | pose 零干扰，骨架识别最稳，易抠图替换 | **迁移底图默认选这一档** |
| 🟡 **半安全** | 有辨识度但不过载（云海远景/花海虚化/夜空/深海/数据空间） | 可用，但需注意不遮挡四肢、不抢主体 | 谨慎用，建议远景+降饱和度 |
| 🔴 **仅展示** | 复杂场景（神社鸟居/哥特教堂/城市街景/森林/浮空岛/舞台） | 细节密集、易与角色抢视觉、干扰识别 | **只给 Route A 纯展示版**，迁移时另换背景 |

> ⚠️ **一句话规则**：迁移底图只用 🟢（或 🟡 谨慎）；🔴 一律留给展示版立绘。多样≠复杂——多样性在 🟢 池里靠下方「三轴」铺开。

## Danbooru 通用背景标签参考

> 基于公开动漫背景 tag 常识。标注适用度：🟢=适合迁移底图(简洁类)；🔴=仅展示(复杂类)。

### 🟢 适合动作迁移底图（简洁类，强推）
- `solid color background` — 纯色幕布，最安全，pose 零干扰
- `gradient background` — 渐变背景，柔和不抢主体
- `simple background` — 简单背景，留白足
- `white background` — 纯白幕布，商用立绘常用
- `blurred background` — 虚化背景，主体突出
- `abstract background` — 抽象背景（几何/光斑），不干扰
- `bokeh` — 散景光点，虚化氛围，迁移友好
- `transparent background` — 透明底（PNG 素材向）

### 🟡 中等（可作氛围底图，谨慎使用）
- `sky` / `blue sky` — 蓝天，简单自然背景
- `night sky` / `starry sky` — 夜空/星空，氛围强但较干净
- `milky way` / `galaxy` — 银河，可作抽象星空底
- `cloud` / `clouds` — 云朵，轻盈
- `sunset` / `sunrise` — 朝霞暮色，色块干净
- `aurora` — 极光，彩带但偏简洁
- `underwater` — 深海，蓝调统一
- `particle` / `light particles` — 粒子光，抽象感

### 🔴 仅展示（复杂类，不宜作迁移底图）
- `cherry blossoms` — 樱花（繁复花海，遮挡姿态）
- `forest` — 森林（纵深复杂）
- `cityscape` — 城市景观（细节密集）
- `flowers` / `flower field` — 花田（前景干扰）
- `temple` / `torii` — 神社鸟居（结构复杂）
- `ruins` — 废墟（构图杂乱）
- `floating island` — 浮空岛（视觉重量大）
- `mountain` — 山峰（体积感强）
- `ocean` / `sea` — 海面（反射干扰）
- `castle` — 城堡（建筑细节多）
- `gothic` — 哥特建筑（繁复）
- `stage` — 舞台（装置复杂）
- `rain` / `snow` — 雨雪（动态干扰识别）
- `fireworks` — 烟花（高对比干扰）

> 实践建议：作 Krea2 动作迁移底图时，优先 `solid color / gradient / simple / blurred / abstract / bokeh`；若需氛围，用 `sky / night sky / aurora / underwater` 等色块统一类；复杂场景(tag 带 🔴)建议仅用于「展示版」立绘，迁移时另做背景替换。
