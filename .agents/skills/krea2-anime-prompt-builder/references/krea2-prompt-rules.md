# Krea2 动漫 Prompt 规则

## 正向 Prompt 合同

Skill 执行者必须构建一条描述一幅画面的 Prompt 正文。Prompt 可以混合清晰的中文自然语言、通用英文视觉短语和必要的括号权重，但必须保持连贯叙事，不能写成互相无关的标签堆叠。

成功构建 Prompt 时，内部 `positive_prompt` 只能包含这一条 Prompt 正文，并且必须直接以画面质量、动漫媒介或主体描述开头。Skill 执行者不在 Prompt 正文前后写“根据规则”“已读取资料”“完成自检”“以下是 Prompt”或其他引导句，也不附带标题、序号、路线名称、设计解释、生成参数、负向 Prompt、检查清单或多个候选版本。Skill 执行者按照 `generation-output-contract.md` 把 `positive_prompt` 写入最终结构化结果。

## 内容顺序

Skill 执行者按照下列顺序组织 Prompt；用户没有要求且画面不需要的内容可以省略：

1. 画面质量、动漫媒介和整体视觉方向；
2. 主体数量、身份、年龄感和第一印象；
3. 面容、眼睛、发型、发色和非人特征；
4. 服装整体设计、主色、材质、结构、饰品和鞋履；
5. 姿态、手臂、双腿、视线、主体关系和动作结果；
6. 景别、相机方向、主体在画面中的位置和可见范围；
7. 具体背景空间、前中后景、光源方向、色彩层次和氛围；
8. 最多四个用于稳定全身、线稿、上色或细节表现且含义互不重复的英文短语。

服装必须被描述为一个协调的整体设计。Skill 执行者必须让服装形制、材质、颜色、饰品和鞋履属于同一个视觉方向，不能把互不相干的散件直接并列。

## Krea2 默认设计

用户没有明确指定媒介、主体、构图、光线、背景或画质短语时，Skill 执行者按类别采用以下默认值补齐未指定的内容：

- 媒介使用精致动漫插画、干净线稿、赛璐璐上色和柔和层次阴影；
- 主体使用单人构图，身份、年龄感和外观由用户主题决定；
- 构图使用人物完整可读的竖向全身画面，鞋履完整出现并保留脚下空间；
- 光线使用明确的主光方向、柔和轮廓光和可区分主体与背景的明暗关系；
- 背景使用具体、绚丽、静态且具有前中后景的场所，背景色彩与服装主色协调；
- 画质短语使用 `(masterpiece:1.2), (best quality:1.2), high resolution, ultra-detailed`；用户明确指定含义相同的画质要求时，指定内容替换对应的默认短语。

用户明确指定半身、特写、多主体、其他动漫媒介或其他画面比例时，当前明确要求覆盖对应默认值。

## 展示路线

展示路线允许用户指定自由站姿、坐姿、倚靠、行走、跳跃、战斗或其他动作。Skill 执行者必须让肢体动作、衣物受力、视线方向和场景空间形成同一瞬间，不能同时描述互斥姿势。

用户没有指定动作时，Skill 执行者使用自然、稳定、能够展示服装轮廓的全身站姿。用户没有指定镜头时，Skill 执行者使用接近标准焦段的正面或轻微三分之四视角，避免夸张广角造成身体比例失真。

## 动作迁移路线

用户明确要求舞蹈、姿态或动作迁移源图时，Skill 执行者必须完整读取 `motion-migration-constraints.md`。该文件的垂直站姿、四肢轮廓、鞋履、人物比例、镜头和背景规则覆盖展示路线的自由动作默认值。

动作迁移路线仍然使用绚丽静态场景。Skill 执行者降低远景饱和度，保留主体轮廓光，减少人物轮廓附近的背景高对比细节，并移除具有明显运动线索的背景元素，使人物轮廓和四肢姿态能够与背景清楚区分。Skill 执行者使用具体静态场景，不使用纯色、白底、渐变留白或简单背景代替场景。

## 背景规则

背景必须描述一个具体地点，并至少包含空间层次、主要静态景物、主光来源和整体色调。适合的静态元素包括建筑、山体、岩石、雕塑、固定灯具、静止花田、结晶、星图、壁画和水面倒影。

动作迁移路线不得加入会与人物一起产生错误运动线索的飞鸟、游鱼、飘带群、落叶、暴雨、翻涌云海、火焰浪潮或其他显著移动元素。展示路线可以按照用户要求采用动态环境，但必须保持主体可读。

## 冲突与去重

Skill 执行者必须采用以下优先级：当前消息普通文字中的明确画面要求、修改和排除内容高于用户明确选定的历史正向 Prompt；历史正向 Prompt 高于当前消息 Character/Style 记录中的 `data.prompt_text`；Character/Style `data.prompt_text` 高于语义目录查询选中结果的 `prompt_text`；语义目录查询结果高于条件参考资料；条件参考资料高于本文件的默认设计。

高优先级内容替换低优先级内容时，Skill 执行者必须删除被替换内容，不能同时保留旧值。相同含义的中文描述、英文短语和括号权重只保留一个最清楚的表达。两个当前明确要求无法同时满足时，Skill 执行者必须请用户选择，不能自行引入第三种折中设计。

## 最终自检

Skill 执行者提交 Prompt 前必须确认：

- Prompt 只描述一幅画面和一个确定时刻；
- 主体数量、身份、外观、服装、姿态和镜头相互一致；
- 服装、饰品、鞋履、背景和光线属于同一个色彩与题材方向；
- Prompt 正文中能逐项找到每一项用户明确要求的对应描述，并且没有出现用户明确排除的内容；
- Prompt 不包含负向词表、参数设置、内部流程、文件路径或人类可读备注；
- 动作迁移路线满足 `motion-migration-constraints.md` 的每一项检查。
