# Krea2 动漫动作迁移源图约束

## 适用条件

用户明确要求舞蹈迁移、姿态迁移、动作迁移或迁移源图时，Skill 执行者必须把本文件的全部约束写入同一条 Krea2 动漫 Prompt 的画面设计。其他请求不读取本文件。

## 人物姿态与轮廓

- 人物从头顶到鞋底完整出现在竖向画面中，头顶和鞋底外侧都保留可见余量。
- 人物垂直站立并正对镜头，头部保持正向，下巴自然微收，躯干不扭转或前后倾斜。
- 双臂自然下垂在身体两侧，双手与腰胯轮廓分离，手指放松且清楚可见。
- 双腿自然伸直，双脚平行或并拢，重心居中；两条腿的轮廓不能被长裙、披帛、武器或背景高对比边缘完全遮挡。
- Prompt 不加入腾空、跳跃、奔跑、交叉腿、单腿站立、夸张舞姿或其他改变中立骨架的动作。

## 鞋履与地面

- 鞋履必须同时包含颜色、材质、款型和一个可见细节。
- 左右两只鞋完整出现，鞋头、鞋跟和鞋底边缘清楚可辨；画面不能在脚踝、鞋面或鞋底处裁切。
- 鞋底完全接触同一静态地面，人物不悬空；鞋底下方保留一段可见地面，鞋履不接触画面底边。
- Prompt 必须包含 `standing, full-body shot, feet fully visible, no cropping at the feet, shoes clearly shown, visible ground below the feet, feet not touching bottom edge`。

## 人物比例与镜头

- 从头顶到下巴的头部高度不超过人物从头顶到鞋底总高度的 25%。
- 腰线到鞋底的长度不低于人物总高度的 65%，腿部修长但保持动漫人物的自然关节比例。
- 镜头采用接近 50mm 标准焦段的正面视角，使人物头部、躯干和四肢不因透视产生局部拉伸或压缩；Prompt 不使用鱼眼、超广角、强烈俯拍或强烈仰拍。
- 服装结构必须清楚表现肩、肘、腕、腰、膝和踝的位置。大袖、长披帛、裙撑或武器不能横穿四肢轮廓。

## 动漫画风与静态背景

- 人物使用清晰的动漫线稿。上色采用赛璐璐上色或用户指定的动漫上色方式。四肢轮廓与相邻背景形成清楚的明暗对比。
- 背景必须是具体、绚丽、静态且具有前中后景的场所，例如月下琉璃宫殿、固定灯阵的霓虹街区、结晶洞窟、敦煌穹顶或静止花田。
- 人物轮廓邻近区域的背景色彩饱和度和纹理细节密度低于人物主体；轮廓光使头发、手臂、躯干、双腿和鞋履的边缘与背景清楚分开。
- 背景不得包含显著移动的飞鸟、游鱼、落叶、暴雨、翻涌云海、火焰浪潮或遮挡人物四肢的前景元素。

## 完成检查

Skill 执行者必须在提交 Prompt 前逐条核对“人物姿态与轮廓”“鞋履与地面”“人物比例与镜头”和“动漫画风与静态背景”中的每项要求，并确认每项要求都能在 Prompt 正文中找到含义唯一的对应描述。
