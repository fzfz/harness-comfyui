# 本技能 · 国内站爬取大纲与来源（无 VPN）

> 目的：把"本技能 生成词库太小"的问题彻底解决——把**国内可访问站点**的真实词表爬下来，
> 与原生成库 + 参考库合并成 `references/anime_big_lib.py`，让生成器能产出**任意数量唯一提示词**。
> 做法：先按维度筛选候选国内站（大纲）→ 逐批翻页爬取 → 去重整理 → 并入词库。

---

## 一、爬取策略（大纲）

1. **按 6 维度分组**筛选国内站：背景 / 服装 / 颜色 / 服装款式 / 饰品 / 靴鞋。
2. **候选站筛选**：国内站点极多，按"权威度 + 结构化词条密度"优先，先锁定高价值源
   （百科类、专业色彩站、汉服/洛丽塔/和风垂类站、电商类目词、考据向长文）。
3. **逐批翻页**：每个站点"一个一个找、页面翻来翻去找"，把分散在各小节/分页的词条抽全。
4. **去重整理**：跨站同名词合并；按维度归入 `anime_big_lib.py` 的 `COLORS` / `FAMILIES`。
5. **背景过滤**：剔除含移动物/动物者（海河湖溪雨/云海/飘落植物/鸟兽鱼蝶/火焰/极光），
   用星/月/霞/光/山/建筑/珊瑚/花/竹/苔/冻等静态绚丽意象替代，避免被动作迁移一并带走。
6. **可继续扩充**：若词库仍不够，按本大纲的下一批候选站继续爬（见第五节）。

## 四、去重与整理规则

- 跨站同名词只留一条（如 ttpeise 与 5300 的 163 色合并）。
- 颜色统一为「单色名」，不带色值/解释。
- 服装/款式/饰品/鞋履按家族归类，保证**家族内协调、不混搭**。
- 背景按静态场景规则整理（见第一节第 5 条），移动元素不纳入背景池。
- 人物人设固定（瓜子脸+大圆眼+黑长直+沙漏身材），不随机换脸（人物迁移同脸）。
