# 本地图片读取

## 1. 取得图片与观察要求

1. 执行者从用户消息和用户指代的附件中取得本地图片绝对路径。执行者保留输入顺序与重复路径。没有可用路径时，执行者询问图片路径并等待补充。
2. 用户指定观察重点、返回格式或读图提示词时，执行者将要求写成完整的 `prompt`。用户只要求一般识别、描述或分析时，执行者采用当前图片读取配置的默认提示词。
3. 同一观察要求适用于多张图片时，执行者使用同一份提示词。用户为不同图片指定要求时，执行者分别记录图片与提示词的对应关系。

## 2. 读取帮助并逐图调用

1. 首次使用受管 CLI 前，执行者通过官方前台 shell 读取根帮助：

   ```sh
   ELECTRON_RUN_AS_NODE=1 "$DSH_HARNESS_COMFYUI_NODE_EXECUTABLE" --expose-internals "$DSH_HARNESS_COMFYUI_CLI" --help
   ```

2. 执行者将末尾的 `--help` 替换为 `image inspect --help`，读取图片调用合同，再按图片顺序逐图调用。`file_path` 来自第 1 节的图片列表，观察要求来自该图片对应的提示词。
3. 执行者复用仍在上下文中的帮助。压缩后缺少调用依据时，执行者在调用前重新读取帮助。
4. 单张图片读取失败时，执行者记录图片路径、错误码与错误消息，并继续处理其余图片。用户或宿主取消调用时，执行者结束本次执行。

## 3. 交付观察结果

1. 执行者按输入顺序返回图片路径、实际 Provider 与模型，以及观察文本或读取错误。
2. 执行者根据成功取得的观察文本回答用户问题。
