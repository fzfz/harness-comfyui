# Harness ComfyUI v0.30.8

v0.30.8 修复“插入上下文”图片画廊的箭头定位、关闭按钮可见性和大图查看问题，同时保持封面预览与记录选择的独立交互。

## 主要变更

- 画廊 Modal 让 header 不参与 flex 收缩，并让画廊 body 只占用 header 之外的剩余高度。右上角关闭按钮不会再被图片区域挤出或裁剪。
- 画廊 stage 使用稳定的可用高度；左右箭头按钮在横图与竖图之间切换时保持原位置，箭头 SVG 在按钮内水平和垂直居中。
- 图片查看区域按图片固有尺寸显示内容。当图片宽度超过查看区域宽度时，该区域提供水平滚动条；当图片高度超过查看区域高度时，该区域提供垂直滚动条；两个方向都超出时同时提供两条滚动条。
- 封面预览按钮与记录选择按钮继续作为同级独立按钮。打开、切换或关闭图片画廊不会改变待确认选择集合，确认插入仍只使用记录选择按钮产生的 `CatalogContext`。

## 验证

- 新增画廊布局回归测试，覆盖 Modal header/body 高度分配、stage 尺寸约束、箭头居中、图片固有尺寸和双轴滚动容器。
- 原有 Client 回归继续覆盖封面预览与选择隔离、准确 `CatalogContext` 插入、左右按钮、键盘方向键、首尾禁用、图片错误、焦点恢复、单图和无封面记录。
- 真实浏览器在 1280×720 和 480×420 viewport 中切换横图与竖图后，两个箭头按钮的中心位置不变，箭头 SVG 中心偏差为 0px，关闭按钮完整位于 viewport 内；2400×1600 横图与 1600×2400 竖图均产生水平和垂直滚动范围。
- 完整 `pnpm quality` 已通过：324 项 unit/integration、22 项 contract/security、14 项 production 和 27 项 prototype 测试全部通过；函数覆盖率为 100%。
- 本版本只发布 Git tag 与 GitHub Release 记录，不附加产品包。
