# character 位置规则审计

## 审计范围

1. 本次已逐行审计 `.agents/skills/wai-sdxl-prompt-builder/references/prompt-position-rules/character.md` 第 1—60 行；以下条目以该文件当前行号定位。

## 需修改项

1. **第 1—5 行：补充 YAML 头并合并用途说明。** 当前用途和读取时机写在正文中，文件缺少规定的 YAML 字段。将第 1—5 行完整替换为：

   ```markdown
   ---
   文档用途: 规定 Skill Agent 构造 character 位置内容时的来源选择、角色对应和标签处理规则。
   读取时机: 用户指定角色或作品，或 Skill Agent 采用 Character Prompt 来源时读取。
   ---

   # `character` 位置规则

   ## 职责与输入定义
   ```

2. **第 13 行：统一缺少角色 Prompt 时的处理入口。** 本句允许直接省略该角色的 `character` 内容，第 28—31 行却要求查询素材，并在仍缺少 Prompt 时停止执行。执行者可以据此选择两种不同的完成条件。将第 13 行完整替换为：

   ```markdown
   1. Skill Agent 先确定画面中的每个角色，再按照 [WAI Prompt 位置顺序与职责](../wai-prompt-position-order.md)的“Character 和 Style Prompt 来源”一节，为每个角色确定一条已采用 Character Prompt 来源。当前输入来源未提供角色 Prompt 时，Skill Agent 按本文件“查询作品与角色素材”一节处理；用户只提供作品名称时，Skill Agent 按本文件“用户只提供作品时”一节处理。
   ```

3. **第 28、35 行：明确只提供作品时的优先入口。** 第 28 行规定既无角色 ID 也无角色名称时停止处理角色，第 35 行规定相同输入仍应查询作品并请求角色名称。仅靠章节先后无法确定应先执行哪项规则。将第 28 行完整替换为：

   ```markdown
   1. 用户只提供作品名称时，Skill Agent 按本文件“用户只提供作品时”一节处理。其他输入来源未提供角色 Prompt 时，Skill Agent 通过 NoobAI MCP 获取角色素材。已有角色 ID 时优先获取对应记录；没有 ID 时按角色名称及已提供的作品信息查找。既没有 ID 也没有角色名称时，Skill Agent 请求用户提供角色名称，并等待用户回复。
   ```

4. **第 43、45—46、50—60 行：删除重复规则，保留去重要求。** 第 43 行重述第 19—21 行；第 45—46 行与第 19—20 行重复分配外貌和服装的位置，但随身物件的位置仅在第 46 行明确。第 52—58、60 行再次重述来源、顺序、角色标识、标签处理和输入保留规则；第 54 行还将第 39 行针对补充位置的角色标识要求扩展到 `character`，与第 15 行原样保留的要求产生冲突。建议将第 41—60 行完整替换为以下内容，保留尚未单独规定的主体、随身物件和去重规则：

   ```markdown
   ## 位置边界

   1. Skill Agent 将整幅画面的主体总数和主体类别写入 `subject`。
   2. Skill Agent 将用户明确要求且本轮 Character Prompt 未包含的新增或替换随身物件写入 `outfit`。
   3. Skill Agent 向 `appearance` 或 `outfit` 写入内容前，核对 `character` 中已保留的标签和具体内容；同一标签或同一项具体内容只保留在 `character` 中。
   ```

5. **第 7、9、15、19—24、35、39 行：统一使用有序列表组织同级规则。** 当前正文段落和无序列表承载独立执行要求，未使用规定的有序列表。保留这些行的规则内容，将各节规则按出现顺序编号；第 19—24 行的六个列表标记依次改为 `1.` 至 `6.`。本报告其他条目提供的替换文字已包含对应编号，无需重复修改。
