2. **第 5—160 行：统一使用有序列表组织节内内容。** 第 15、33—38、71—73、91—94、110—114 行使用无序列表；第 16—17 行和第 52 行直接接续前一列表项，三个独立调用条件以及 Prompt 来源因而无法清晰区分。请将上述无序列表改为有序列表，将第 15—17 行分别编号为 1—3，将第 52 行编号为第 7 项；其他节内正文也应作为独立有序列表项，代码块缩进归属其引导项。同一节内连续编号，子节重新编号。该项仅调整组织方式，其余需改文字见下列各项。
