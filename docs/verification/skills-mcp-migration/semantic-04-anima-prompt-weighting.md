   2. Skill 执行者每次构建 Prompt 时先完整读取 `prompt-weight-policy.json`，再读取本文件。
   3. Skill 执行者完成槽位内容并删除互斥内容和重复内容后，按本文件选择权重形式。槽位顺序决定内容分类和排列，权重外层改变单个 payload 的条件强度。

7. 修改项 G，第 31 行删除，不替换；其必要内容由修改项 B 提前定义。
8. 修改项 H，第 35 至 48 行替换为以下文字。该替换将自主权重限制与来源权重保留分开，并对固定前缀和关系文本的冲突给出动作：

   ```markdown
   1. Skill 执行者自主选择加权内容时，遵守本节各 tag 槽位的范围限制；来源权重按“权重来源优先级”保留。来源权重与固定质量前缀或关系文本的形式要求冲突时，Skill 执行者向用户说明冲突并取得取舍后继续。
   2. `quality`：`recommendations.unweighted_quality.content` 中的固定前缀保持未加权。Skill 执行者只为用户新增且明确要求强调的质量 payload 自主加权。
   3. `artist_style`：Skill 执行者按“权重来源优先级”为主要或辅助画师选择权重；没有适用权重来源的画师使用未加权 `@payload`。
   4. `count_gender`：用户明确把主体数量或主体类别指定为主要内容时，Skill 执行者可以自主加权一个对应 payload。
   5. `character_series`：具体角色或系列身份决定画面识别时，Skill 执行者可以自主加权一个身份 payload。
   6. `appearance`：Skill 执行者最多自主加权一个决定角色识别或用户明确要求的外貌锚点。
   7. `clothing_state`：Skill 执行者只为用户明确指定为画面主题的一项服装或穿着状态自主加权，并将表达该项服装或穿着状态的多个 payload 作为同一个视觉决定处理。
   8. `pose_action_sex`：Skill 执行者可以将核心动作或姿势选为主视觉锚点，自主设计的辅助动作保持未加权。
   9. `expression_reaction`：Skill 执行者可以自主加权一个表示用户明确要求的主表情或关键身体反应的 payload。
   10. `camera_shot`：Skill 执行者可以自主加权一个决定构图的景别、观察视点（POV）、角度或焦点 payload。
   11. `scene_environment`：场所本身是主叙事对象时，Skill 执行者可以自主加权一个环境 payload；自主设计的普通背景保持未加权。
   12. `detail_mood`：Skill 执行者可以自主加权一个决定整体媒介质感或观感的核心效果。
   13. `natural_language`：Skill 执行者在该槽位保存关系文本，在承担相应职责的 tag 槽位表达需要强调的视觉内容。
   ```
