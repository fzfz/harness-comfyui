# 中文 Caption 修改前后对照

## 1. 成图差异

1. **古籍修复，种子 271828。** 修改前，两层纸主要靠颜色和透明度区分。修改后，旧书页能看到散开的长纤维，修补纸的纹理更细密。两图都画出了窄湿带。修改后的薄纸盖住了裂口下半段，但上半段仍然露出，镊尖也落在纸片内部。[基线原图](baseline/bookbind/271828/image.png) · [修改后原图](candidate/bookbind/271828/image.png)
2. **古籍修复，种子 314159。** 修改前，笔尖落在两片纸交叠的深色区域。修改后，笔尖接触薄纸右缘，更接近“沿边刷水”的要求。两图的湿痕都扩成了色块，裂口都在书脊右侧。这个种子下，两层纸的纤维差异仍然不清楚。[基线原图](baseline/bookbind/314159/image.png) · [修改后原图](candidate/bookbind/314159/image.png)
3. **白瓷杯，种子 271828。** 两图都保留了单只白杯、杯口细蓝边和无道具的白色背景。基线图中的杯子居中。修改后的杯子较小、位置偏下，上方留白更多。[基线原图](baseline/cup/271828/image.png) · [修改后原图](candidate/cup/271828/image.png)

## 2. 提示词和写作规则

1. 古籍修复的中文 Caption 从 849 个字符变为 782 个。两稿都写到了纸纤维、湿带和反光。修改后的描述明确写出了裂口方向、薄纸中央保持干燥，以及笔尖与纸边的接触位置。[基线提示词](baseline/bookbind/prompt.txt) · [修改后提示词](candidate/bookbind/prompt.txt)
2. 白瓷杯的两稿均为 31 个字符、一个句子，都明确要求杯子居中。该项在提示词中得到保留，在修改后的成图中出现偏差。[基线提示词](baseline/cup/prompt.txt) · [修改后提示词](candidate/cup/prompt.txt)
3. 建议保留本次写作条款。新增条款说明详细中文 Caption 何时可以写过 500 字，也保留用户对短句的要求。每个版本只为每项任务写了一稿。两处局部细节更贴近要求，白瓷杯的居中构图则出现偏差。对照结论限于这三对图片。

## 3. 如何核对对照条件

1. 两轮使用模板 47 及其默认模型 DirtyMOSS。每张图均为 880 × 1184 像素，使用 8 步、CFG 1、Euler 采样器和 simple 调度器。逐对比较提交给 ComfyUI 的 API 工作流，三对都只有节点 3 的正向提示词发生变化。[任务、种子和评审项目](cases.json) · [基线运行记录](baseline/runs.json) · [修改后运行记录](candidate/runs.json)
2. 两名独立评审者各负责一个场景。评审用图保留原始像素，移除了提示词和版本标识。评审者逐图记录可辨认的特征，评分结束后再与版本和种子对应。古籍图中工具位于画面哪一侧可以判断，人物解剖学上的左右手仍难以确认。[匿名逐项评审与工作流差异](blind-review.json) · [并排对照图](comparison.jpg)
3. 官方 Desktop 在隔离工作区加载了候选插件中的 Skill。真实模型读取编译器帮助并调用编译器，生成的提示词与草稿正文一致。两轮使用的隔离 Desktop 实例均已停止并释放端口。[候选插件验收记录](candidate/desktop-acceptance.json)

## 4. 人物与复杂场景

1. 人物实验覆盖男女主角、室内车站、室外码头、纪实摄影画风和二次元画风。每个组合使用两个种子，按人体、手脚动作、光照和空间层次等八项要求比较两版成图。[人物实验结果](people/results.md) · [32 张配对原图](people/gallery.html)
