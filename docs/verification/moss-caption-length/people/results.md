# MOSS 中文 Caption 人物成图对照

## 1. 详细中文 Caption 应写多长

1. 建议保留 Skill 对详细中文 Caption 的篇幅要求。详细中文 Caption 还有需要交代的画面细节时，可以超过约 500 字。画面要求及其关系写清后即可收笔。两版收到的八条中文任务相同，均未指定字数。基线写出 321–368 个汉字，修改后写出 545–687 个汉字。字数只计汉字。[Skill 的 Caption 条款](../../../../.agents/skills/moss-prompt-builder/SKILL.md) · [两版提示词与原图](gallery.html)
2. 16 对图共有 128 项配对比较，其中 116 项的两张图都能判定，且两个评审会话对每张图的评分一致。修改后有 5 项改善、3 项退步、108 项持平。本轮结果支持按画面需要继续写细节，统一规定最低字数缺少成图依据。
3. 两版都已交代左右手分工和脚位。室内女性二次元稿在修改后补写了双鞋接触台阶的位置，室外女性摄影稿补写了提箱手臂的受力姿态。室外男性摄影稿还自行规定远处的船比人物略小。扩写时应优先交代用户关心的接触点、光向和空间关系，用户未指定的比例应给构图留出余地。[室内女性二次元稿](candidate/hall-f-anime/prompt.txt) · [室外女性摄影稿](candidate/quay-f-photo/prompt.txt) · [室外男性摄影稿](candidate/quay-m-photo/prompt.txt)

## 2. 哪些画面要求出现变化

1. 每张图由两个独立的视觉模型会话按八项要求评分。下表每行对应 16 对图片。“均符合”和“均不符合”表示基线与修改后得到同一结论。“待定”包括两个会话判分有分歧或画面不足以判断的配对。[评分条件](cases.json) · [逐图判分与配对记录](review.json)

   | 画面要求 | 改善 | 退步 | 均符合 | 均不符合 | 待定 |
   |---|---:|---:|---:|---:|---:|
   | 人物与服装 | 0 | 0 | 16 | 0 | 0 |
   | 全身与肢体 | 0 | 1 | 15 | 0 | 0 |
   | 提箱与握栏 | 0 | 0 | 16 | 0 | 0 |
   | 左右脚位置与着地 | 1 | 0 | 0 | 13 | 2 |
   | 主光与投影方向 | 0 | 0 | 8 | 0 | 8 |
   | 前、中、后景 | 0 | 0 | 16 | 0 | 0 |
   | 背景人物数量与位置 | 4 | 2 | 2 | 6 | 2 |
   | 指定画风 | 0 | 0 | 8 | 8 | 0 |

2. 在女性车站场景中，使用同一个种子 271828 时，两种风格的背景人数出现了不同变化。二次元基线图只看得见一名旅客，修改后左右各有一人，符合要求。摄影基线图有两名坐客，修改后又画出了其他旅客。[二次元基线](baseline/hall-f-anime/271828/image.png) · [二次元修改后](candidate/hall-f-anime/271828/image.png) · [摄影基线](baseline/hall-f-photo/271828/image.png) · [摄影修改后](candidate/hall-f-photo/271828/image.png)
3. 在男性码头摄影图中，种子 271828 的基线图把左脚画成悬空，后景多于两名工人。修改后，右脚踩高阶、左脚踩低阶，后景能数出两名工人。两图都看得见右侧暖光，潮湿地面的反光使人物投影的方向难以辨认。[基线原图](baseline/quay-m-photo/271828/image.png) · [修改后原图](candidate/quay-m-photo/271828/image.png)
4. 所有摄影图都符合纪实摄影画风。16 张二次元图均未同时画好动画人物的分块明暗与手绘背景，常见情况是人物带有动画轮廓，站台或码头仍有照片质感。室内的八对图都能辨认左侧主光和朝右的投影。室外的八对图在光照这一项均为待定。评审者往往无法从潮湿地面的反光中确认朝左的投影。[室内二次元](hall-anime.jpg) · [室外二次元](quay-anime.jpg) · [室外摄影](quay-photo.jpg)

## 3. 如何查看配对原图

1. 室内组让男性和女性检修员在车站登阶。左侧窗光应使阴影向右，左下的行李推车和后景的两名旅客提供空间参照。[室内摄影对照图](hall-photo.jpg) · [室内二次元对照图](hall-anime.jpg)
2. 室外组让同样装束的检修员登上雨后码头的石阶。右侧夕阳应使阴影向左，左下的缆绳和后景渔船旁的两名工人提供空间参照。[室外摄影对照图](quay-photo.jpg) · [室外二次元对照图](quay-anime.jpg)
3. 图库按人物、风格和种子配对。左侧为基线，右侧为修改后。每张图都可打开原图、提示词和 ComfyUI 工作流。[全部 32 张图](gallery.html)

## 4. 对照条件和适用范围

1. 两版 Skill 分别取自提交 `ffc1d16` 和 `f053e90`。官方 Desktop 使用相同模型 `gpt-6.1-terra`，每项任务、每个版本各开一个独立会话。16 次调用均读取了对应的 Skill 和编译器帮助，调用了编译器，输出与草稿正文一致。[基线写词会话](baseline/author-sessions.json) · [修改后写词会话](candidate/author-sessions.json)
2. 各组均采用模板 47、DirtyMOSS、8 步、CFG 1、Euler 和 simple 调度器，输出为 880 × 1184 像素。两版均使用种子 271828 和 314159。逐对比较送入 ComfyUI 的工作流，16 对都只有正向提示词不同。[基线 Run 与工作流](baseline/runs.json) · [修改后 Run 与工作流](candidate/runs.json)
3. 室内和室外各安排两个评审会话。评审时保留原始像素，随机编号，移除提示词与版本信息。256 项单图评分中，两个会话在 248 项上判分一致，在 8 项上存在分歧。在配对比较中，7 项包含评分分歧，另有 5 项因两个会话均无法确认其中至少一张图而待定。
4. 摄影组使用模型生成的写实人物。每个版本在每项任务上只有一份提示词，两个种子复用该稿。字数、措辞和细节一同变化。每类环境只有一个地点和一个主光方向。本轮结果适用于这两处场景和这套生成配置。
