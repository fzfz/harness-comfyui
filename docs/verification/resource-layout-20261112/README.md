# 资源页布局验收

## 1. 验收环境

1. 验收日期为 2026-11-12，插件版本为 `0.54.1`，官方 DeepSeek Harness Desktop 版本为 `0.2.1-rc.3`。
2. 验收者在独立 worktree 构建插件，通过官方插件管理界面安装，并在重启后测量实际界面。
3. 对照原型来自独立 worktree 的 `prototype/experiment-workbench/index.html`，本页保存对应截图和测量值。原型使用 Chrome 157 渲染；官方 Desktop 使用 Electron 44.7.0、Chromium 152。

## 2. 页面几何

1. 验收者在 1024、1280、1440、1920 像素窗口中切换资源、任务、经验和收藏页，分别测量左栏、中栏、右栏及导航按钮的位置和宽度。测量值见 [Desktop 界面](desktop-measurements.json)与[原型界面](prototype-measurements.json)。
2. 各页共用三栏边界，布局宽度如下，单位为像素。

   | 窗口宽度 | 左栏 | 中栏 | 右栏 |
   | --- | --- | --- | --- |
   | 1024 | 208 | 496 | 320 |
   | 1280 | 244 | 686 | 350 |
   | 1440 | 244 | 846 | 350 |
   | 1920 | 260 | 1280 | 380 |

3. 跨页回归通过实际界面操作验证导航位置、三栏边界和横向溢出。实现见[官方 Desktop 布局夹具](../../../tests/desktop/fixtures/official-workbench-layout.mjs)，运行记录见 [Desktop 回归测量](official-business-workbench-layout.json)。

## 3. 样式测量

1. 分类按钮使用 12 像素字号、上下 13 像素内边距和 6 像素圆角。选中背景为 `#eaf2e9`，边框为 `#d5e1d3`，文字为 `#356c52`。
2. 卡片说明区最小高度为 52 像素，最多显示 3 行；标签行允许换行，间距为 6 像素。
3. 横图和竖图均已加载，封面采用 `contain`，背景为 `#edf1eb`。截图见[图片卡片](image-cards.png)，原图尺寸与显示样式见[图片测量](image-cards.json)。
4. [逐项对照](comparison.json)保存三栏、标题、分类按钮及卡片的计算样式。在每种窗口宽度下，Desktop 与原型的三栏和标题位置、尺寸一致；分类按钮的颜色、字号、间距和边框一致。

## 5. 对照范围

1. 资源页保留底模和生成模型两个筛选控件；原型包含一个底模筛选。1024 像素窗口中，两个控件分行显示，卡片区域相应下移。
2. 工作选择器按工作名称确定宽度。同名条件下，Desktop 与原型导航横坐标相差约 `0.008` 像素。同一 Desktop 工作内切换四页时，导航位置保持一致。
3. 相同 HTML 和 CSS 在 Chromium 152 与 157 中渲染的原生选择框高度分别为 34 和 35 像素。单变量对照见[原生控件测量](native-control-diagnostics.json)。
