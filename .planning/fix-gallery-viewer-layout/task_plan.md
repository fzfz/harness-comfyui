# 图片画廊布局缺陷修复计划

## 必须要实现的目标

- Client Module 必须让上一张、下一张箭头图标在各自按钮中稳定水平和垂直居中。
- Client Module 必须让图片画廊右上角关闭按钮在所有受支持窗口尺寸和图片尺寸下保持可见且可点击。
- Client Module 必须完整保留图片原始比例；当图片尺寸超过可视区域时，图片查看区域必须提供水平和垂直滚动条。
- 记录选择按钮与封面预览按钮必须继续保持独立交互。

## 当前阶段

Phase 5：完成独立语义复验、v0.30.8 发布和生产部署。

## 实施阶段

- [x] Phase 1：建立并运行能够捕获三个视觉症状的快速回归测试。
- [x] Phase 2：检查画廊 DOM、primitive Modal 结构与当前 CSS，形成并验证原因假设。

## 验收清单

- [ ] 左右箭头图标在按钮中心的水平和垂直偏差均不超过 1px。
- [ ] 关闭按钮在宽窗口、窄窗口、横图和竖图场景均位于 viewport 内。
- [ ] 大图不再被 `object-fit: contain` 缩小为只能看到适配结果；查看区域对溢出图片提供双轴滚动。
- [ ] 首尾箭头禁用、键盘方向键、图片计数、错误状态和焦点恢复保持原行为。
- [ ] 封面点击不改变记录选择状态。
