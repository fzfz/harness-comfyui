# 模板 39 输出节点身份校验失败调查计划

## 必须要实现的目标

- 调查者必须在独立 Git worktree 中复现 `SOURCE_PROTOCOL_ERROR: ComfyUI template output node identities are invalid.`。
- 调查者必须定位错误码的产生位置、模板 39 的数据来源、输出节点身份字段的生成位置与校验位置。
- 调查者必须用可反驳的证据确定根因，区分模板记录损坏、恢复过程丢失字段、协议升级不兼容与运行时转换错误。
- 调查者必须形成包含修改文件、回归测试、数据修复方式、发布步骤和风险边界的修复方案。
- 调查者必须在用户批准修复方案前停止产品代码、模板数据、生产状态和发布状态的修改。
