# 本会话媒体查看页导航与提示词展示方案

## 必须要实现的目标

- 计划编写者必须在独立 worktree 中核对右侧“媒体结果”标签页、媒体查看页、会话媒体排序规则和正面提示词数据来源。
- 计划编写者必须制作一个静态 UI 原型。原型必须展示媒体左右切换箭头、键盘左右键切换行为、当前媒体在本会话媒体序列中的位置和媒体正面提示词。
- 计划编写者必须产出可供用户审批的需求方案。用户批准前，计划编写者不得修改生产功能代码。
- 用户批准后，计划执行者必须根据同一份已批准方案实现功能、各分支测试、版本发布和生产部署。

## 验收清单

- [x] 用户能够打开静态原型并查看媒体详情页设计。
- [x] 静态原型左右两侧显示垂直居中的方向箭头图标。
- [x] 静态原型支持点击方向箭头切换本会话媒体。
- [x] 静态原型支持键盘 `ArrowLeft` 和 `ArrowRight` 切换本会话媒体。
- [x] 静态原型按照方案定义的时间顺序切换媒体。
- [x] 静态原型在媒体底部显示当前媒体生成时的正面提示词。
- [x] 需求方案定义首个媒体和末个媒体的导航行为。
- [x] 需求方案定义当前系统支持的图片和视频媒体类型。
- [x] 需求方案定义提示词缺失时的明确界面状态。
- [x] 需求方案定义实现阶段需要覆盖的单元测试、组件测试和浏览器测试分支。
- [x] 独立语义审核员确认需求方案不存在 blocker 或 medium 级别的主体不清、对象不具体、定义缺失或要求不可追踪问题。
- [x] 用户批准前没有生产功能代码改动。

## 非本次目标

- 本次方案不增加跨会话媒体导航。
- 本次方案不增加媒体删除、下载、收藏、编辑或重新生成能力。
- 本次方案不展示负面提示词、工作流 JSON、模型参数或其他生成元数据。
