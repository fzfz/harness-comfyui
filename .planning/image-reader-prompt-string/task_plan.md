# 图片识别 Tool 接口调整方案调研与实施跟踪计划

## 必须要实现的目标

- 计划编写者必须定位当前图片识别 Tool 的公开输入结构、默认读图提示词、模型请求结构、模型响应解析和 Harness Tool 返回结构。
- 计划编写者必须判断 JSON 返回要求来自 Harness Tool 接口、项目实现、模型 Provider 接口或仅来自当前提示词约定，并保存可定位的源码或官方文档证据。
- 计划编写者必须设计一个可选读图提示词参数；调用者传入该参数时，图片识别 Tool 使用调用值覆盖默认读图提示词，调用者不传时继续使用唯一默认提示词。
- 计划编写者必须确认并固定“视觉模型返回普通字符串、Tool 把该字符串包装为结构化 JSON 对象”的分层合同。
- 计划编写者必须把设置页保存合同改为只保存当前选中的一份图片读取配置；其他配置不参与请求且不能阻止保存。
- 计划编写者必须设计具体到当前配置输入项的稳定错误码、中文原因与修正动作，替换无法定位失败输入项的 `IMAGE_READER_SETTINGS_INVALID` 总括错误。
- 计划编写者必须列出实现文件、各分支测试、文档影响、兼容性影响、验证命令和用户批准门禁。
