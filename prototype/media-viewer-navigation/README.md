# 本会话媒体查看页导航静态原型

## 名词和执行角色定义

- “Harness Session”指 DeepSeek Harness 中的一次会话。“本会话媒体”指同一个 Harness Session 保存的全部媒体。
- “用户”也是本方案的“计划审批者”。计划审批者负责选择界面方案，并明确批准或拒绝需求方案。
- “计划编写者”指用户批准前负责调查现状、编写需求方案、制作静态原型、启动静态原型和运行原型结构检查的 Agent。计划编写者不得修改生产功能代码。
- “计划执行者”指用户批准后负责实现生产功能、运行生产测试、发布版本和部署生产提交的 Agent。
- “ComfyUI 工作流 JSON”指使用 JSON 对象记录 ComfyUI 节点、节点连接和节点参数的生成工作流数据。

## 必须要实现的目标

本原型比较三个媒体查看页结构。每个结构都在页面左右两侧提供垂直居中的方向箭头，使用鼠标点击或键盘左右键切换本会话中时间相邻的媒体，并在当前媒体底部显示该媒体生成时保存的正面提示词。

原型使用五项按时间从新到旧排列的静态媒体。左箭头切换到较新的媒体，右箭头切换到较早的媒体。第一项禁用左箭头，第五项禁用右箭头，导航不循环。

## 启动方式

计划编写者在仓库根目录运行：

```bash
python3 -m http.server 4187 --directory .
```

计划审批者打开以下地址：

- 方案 A“原页增强”：`http://127.0.0.1:4187/prototype/media-viewer-navigation/?variant=A&media=3`
- 方案 B“时间边轨”：`http://127.0.0.1:4187/prototype/media-viewer-navigation/?variant=B&media=3`
- 方案 C“画册说明”：`http://127.0.0.1:4187/prototype/media-viewer-navigation/?variant=C&media=3`

底部原型切换器可以切换三个方案。裸 `ArrowLeft` 和 `ArrowRight` 切换媒体；`Shift + ArrowLeft` 和 `Shift + ArrowRight` 切换原型方案。URL 中的 `variant` 和 `media` 参数保存当前方案和当前媒体。

## 验收清单

- [ ] 页面显示五项本会话媒体中的当前位置。
- [ ] 页面左右两侧的方向箭头保持垂直居中。
- [ ] 鼠标点击方向箭头能够切换媒体。
- [ ] 键盘左右键能够切换媒体。
- [ ] 页面按照最新媒体在前的顺序切换媒体。
- [ ] 首项和末项禁用越界方向箭头。
- [ ] 首项禁用箭头显示“当前媒体已是本会话最新媒体”，末项禁用箭头显示“当前媒体已是本会话最早媒体”。
- [ ] 图片和视频都保持完整媒体比例。
- [ ] 当前媒体底部显示对应正面提示词。
- [ ] 缺少正面提示词时，页面显示明确的“没有保存”状态。

## 非本次目标

- 本原型不连接本机运行中的 DeepSeek Harness 服务端进程、本地 SQLite 数据库、ComfyUI 实例或任何网络服务。
- 本原型不实现下载、删除、收藏、编辑或重新生成媒体。
- 本原型不显示负面提示词、ComfyUI 工作流 JSON、模型参数或其他生成元数据。
- 本原型代码不能直接作为生产实现合并到主分支。

## 已获得的授权

- 用户尚未授权计划执行者修改生产功能代码。
